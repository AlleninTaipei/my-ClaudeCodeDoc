修正安裝或登入 Claude Code 時的 command not found, PATH, 權限, 網路與驗證錯誤

快速找到你的錯誤

用篩選晶片快速找到症狀對應的解法分類。

依症狀分類: PATH / 找不到指令 下載 / 網路 Windows 專屬 二進位檔不相容
command not found: claude安裝目錄不在 PATH 中, 需加入 ~/.local/bin
PowerShell 找不到 claude加入 %USERPROFILE%\.local\bin 到 User PATH 後重開終端機
syntax error near '<'安裝腳本回傳 HTML, 可能是地區限制或暫時性服務中斷
curl: (56) Failure writing output下載中斷, 檢查連線穩定性或改用替代安裝方式
TLS connect error更新系統 CA 憑證, 或設定 --cacert 指向公司憑證
irm is not recognized你在 CMD 而非 PowerShell, 開啟 PowerShell 執行原指令
The process cannot access the file刪除 %USERPROFILE%\.claude\downloads 後重新安裝
不支援 32-bit Windows確認開啟的是 Windows PowerShell 而非 x86 版本
Illegal instructionCPU 缺少 AVX 指令集支援, 常見於 2013 年前的處理器或未透傳 AVX 的虛擬機
dyld: cannot load (macOS)macOS 版本過舊, 需要 13.0 以上
Exec format error (WSL1)已知 WSL1 迴歸問題, 轉換到 WSL2 或透過動態連結器呼叫

curl -sI https://downloads.claude.ai/claude-code-releases/latest

看到 HTTP/2 200 代表已連上伺服器; 若逾時或無回應, 網路正在阻擋連線, 檢查防火牆或代理設定。

echo $PATH | tr ':' '\n' | grep -Fx "$HOME/.local/bin"

沒有輸出代表安裝目錄不在 PATH, 需加入 shell 設定檔並重新載入。

which -a claude

檢查是否有多個安裝來源: 原生安裝, 舊版 npm local install, 或 npm 全域安裝, 只保留原生安裝。

test -w ~/.local/bin && echo "writable" || echo "not writable"

若目錄不可寫入, 建立目錄並設定使用者為擁有者。

ldd "$(command -v claude)" | grep "not found"

Linux 上檢查是否缺少共享函式庫, Alpine 等 musl 系統需要另外安裝套件。

常見安裝問題

Homebrew cask 找不到執行 brew update 刷新索引後重新安裝
低記憶體 Linux 伺服器 KilledOOM killer 終止程序, 需增加 2GB swap 空間再重試
Docker 中安裝掛起以 root 從 / 執行安裝會掃描整個檔案系統, 設定 WORKDIR 限制範圍
Claude Desktop 覆蓋 claude 指令舊版 Desktop 註冊的 Claude.exe 佔用 PATH 優先權, 更新 Desktop 即可
Linux musl/glibc 二進位不符安裝器誤判系統類型, 檢查 ldd --version 後手動下載對應版本

常見陷阱

看到 "This organization has been disabled" 時, 通常是舊的 ANTHROPIC_API_KEY 環境變數蓋過了訂閱憑證, unset 該變數即可改用訂閱登入。

WSL2, SSH, 容器中登入時瀏覽器可能開在錯誤主機上, 這時直接把顯示的登入碼貼進終端機提示即可完成驗證。

仍然卡關怎麼辦

1. 查 GitHub Issues或附上作業系統, 安裝指令與完整錯誤輸出開新 issue
2. claude doctor若 claude --version 正常但其他功能異常, 執行自動診斷報告
3. /feedback若能啟動 session, 在 Claude Code 內回報問題
