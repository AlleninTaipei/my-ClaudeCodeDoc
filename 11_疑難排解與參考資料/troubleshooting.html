Troubleshooting

先找到你該去哪一頁

本頁涵蓋 Claude Code 執行起來之後的效能, 穩定性, 搜尋問題。若是其他狀況, 從對應症狀找到正確的頁面。

還是不確定?

在 Claude Code 內執行 /doctor 進行安裝, 設定, MCP servers, context 用量的自動化檢查。若 claude 完全無法啟動, 改在 shell 中執行 claude doctor。

效能與穩定性

取得更多協助

  1. 執行 /doctor 一次檢查安裝健康狀態, 設定有效性, MCP 設定, 與 context 用量
  2. 在 Claude Code 內用 /feedback 直接向 Anthropic 回報問題
  3. 查看 GitHub repository 的已知問題
  4. 直接詢問 Claude 它的能力與功能, Claude 內建了自己的文件存取能力
