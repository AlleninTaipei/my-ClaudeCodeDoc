Tools reference

Claude Code 可用工具的完整參考, 包含權限需求與各工具的行為細節

工具總覽表

工具名稱是你在 permission rules, subagent tool 列表, 以及 hook matcher 中使用的確切字串。搜尋或依權限篩選找到你要的工具。

篩選:
工具描述需要權限

用權限規則與 hooks 設定工具

多數情況下 Claude 會自行決定何時使用這些工具, 但在定義權限與其他設定時你會直接參照工具名稱, 使用同一種規則格式 ToolName(specifier)。

Bash(npm run *)Bash, Monitor 共用命令樣式比對
Read(~/secrets/**)Read, Grep, Glob, LSP 共用路徑樣式比對
Edit(/src/**)Edit, Write, NotebookEdit 共用路徑樣式比對, 也會一併授予對應路徑的讀取權
Skill(deploy *)Skill 名稱比對
Agent(Explore)Subagent 類型比對
WebFetch(domain:example.com)網域比對
WebSearch不需要 specifier, 整體允許或拒絕
