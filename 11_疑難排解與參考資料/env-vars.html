環境變數參考

控制 Claude Code 行為的環境變數: 模型選擇, 驗證, 請求路由, 功能開關

設定環境變數

在 shell 設定的變數只在該終端機 session 有效, 在 settings 檔案設定的變數每次執行 claude 都會套用。

Shell (macOS/Linux)
PowerShell
Settings 檔案
export API_TIMEOUT_MS="1200000"
claude
$env:API_TIMEOUT_MS = "1200000"
claude
// ~/.claude/settings.json
{
  "env": {
    "API_TIMEOUT_MS": "1200000"
  }
}
步驟 1 / 3
~/.claude/settings.json你, 在每個專案
.claude/settings.json所有參與此專案的人, 需提交到版本控制
.claude/settings.local.json你, 只在此專案 (需加入 gitignore)
受管理設定組織內所有人, 由管理員部署

優先順序

同一個行為若同時有環境變數與 settings 欄位, 環境變數優先。settings 欄位只在環境變數未設定時生效。

範例

ANTHROPIC_MODEL 覆蓋 model 設定; --model 與 /model 又覆蓋 ANTHROPIC_MODEL。CLAUDE_CODE_EFFORT_LEVEL 覆蓋 /effort。Claude Code 在啟動時讀取環境變數, 所以變更需要重新啟動 claude 才會生效。

依分類瀏覽變數

Claude Code 支援近三百個環境變數, 以下依前綴分類, 每類挑選代表性項目呈現。完整清單請參照原始文件表格。

選擇分類: ANTHROPIC_* CLAUDE_CODE_DISABLE_* CLAUDE_CODE_ENABLE_* CLAUDE_CODE_USE_* DISABLE_* / OTEL_* MCP_* / 其他
ANTHROPIC_API_KEY
API 金鑰, 以 X-Api-Key 標頭送出, 設定後會取代訂閱驗證
ANTHROPIC_BASE_URL
覆蓋 API 端點, 用於透過代理或 gateway 路由
ANTHROPIC_MODEL
要使用的模型設定名稱
ANTHROPIC_CUSTOM_HEADERS
加入請求的自訂標頭, Name: Value 格式
ANTHROPIC_VERTEX_PROJECT_ID
Vertex AI 請求用的 GCP 專案 ID
ANTHROPIC_WORKSPACE_ID
workload identity federation 用的 workspace ID
CLAUDE_CODE_DISABLE_CRON
停用排程任務, /loop 與 cron 工具變成不可用
CLAUDE_CODE_DISABLE_ARTIFACT
停用 Artifact 工具
CLAUDE_CODE_DISABLE_AUTO_MEMORY
停用 auto memory, Claude 不再建立或載入記憶檔案
CLAUDE_CODE_DISABLE_FILE_CHECKPOINTING
停用檔案 checkpointing, /rewind 無法還原程式碼變更
CLAUDE_CODE_DISABLE_BUNDLED_SKILLS
移除隨附的 skills 與 workflows
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC
等同同時設定自動更新, 錯誤回報與遙測停用
CLAUDE_CODE_ENABLE_TELEMETRY
啟用 OpenTelemetry 資料收集
CLAUDE_CODE_ENABLE_AUTO_MODE
讓 auto mode 在 Bedrock, Vertex AI, Foundry 上可用
CLAUDE_CODE_ENABLE_FINE_GRAINED_TOOL_STREAMING
控制工具輸入是否隨產生過程串流
CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY
從 gateway 的 /v1/models 端點填入模型選單
CLAUDE_CODE_USE_BEDROCK
使用 Amazon Bedrock
CLAUDE_CODE_USE_VERTEX
使用 Google Vertex AI
CLAUDE_CODE_USE_FOUNDRY
使用 Microsoft Foundry
CLAUDE_CODE_USE_ANTHROPIC_AWS
使用 Claude Platform on AWS
CLAUDE_CODE_USE_POWERSHELL_TOOL
控制是否啟用 PowerShell 工具
DISABLE_TELEMETRY
選擇退出遙測, 同時停用 feature-flag 抓取
DISABLE_AUTOUPDATER
停用背景自動更新, 手動 claude update 仍可用
DISABLE_PROMPT_CACHING
停用所有模型的提示詞快取
OTEL_LOG_USER_PROMPTS
在 OpenTelemetry 記錄中包含使用者提示詞文字
OTEL_LOG_TOOL_CONTENT
在 span 事件中包含工具輸入輸出內容
MCP_TIMEOUT
MCP server 啟動逾時, 預設 30000 毫秒
MCP_TOOL_TIMEOUT
MCP 工具執行逾時, 預設約 28 小時
MAX_THINKING_TOKENS
覆蓋 extended thinking 的 token 預算
BASH_DEFAULT_TIMEOUT_MS
長時間 bash 指令的預設逾時, 預設 120000 毫秒
HTTP_PROXY / HTTPS_PROXY
指定網路連線使用的代理伺服器
摘要說明

原始文件的變數表格包含近三百個項目 (ANTHROPIC_*, CLAUDE_*, CLAUDE_CODE_*, DISABLE_*, OTEL_*, VERTEX_REGION_* 等), 此處僅依分類呈現代表性子集, 完整清單需查閱原始 env-vars.md。

Vertex AI 區域覆蓋變數

每個模型世代都有對應的 VERTEX_REGION_CLAUDE_* 變數, 用來覆蓋該模型在 Vertex AI 上使用的區域。

VERTEX_REGION_CLAUDE_5_SONNET覆蓋 Claude Sonnet 5 在 Vertex AI 的區域
VERTEX_REGION_CLAUDE_4_8_OPUS覆蓋 Claude Opus 4.8 在 Vertex AI 的區域
VERTEX_REGION_CLAUDE_FABLE_5覆蓋 Claude Fable 5 在 Vertex AI 的區域
VERTEX_REGION_CLAUDE_HAIKU_4_5覆蓋 Claude Haiku 4.5 在 Vertex AI 的區域

標準 OpenTelemetry 變數

除了 Claude Code 專屬變數外, 也支援標準 OpenTelemetry exporter 變數。

OTEL_METRICS_EXPORTER指標匯出器類型
OTEL_LOGS_EXPORTER日誌匯出器類型
OTEL_EXPORTER_OTLP_ENDPOINTOTLP 端點位址
OTEL_RESOURCE_ATTRIBUTES資源屬性標籤

詳細設定方式請參照 Monitoring 頁面, 這些變數同時支援 signal-specific 的變體。
