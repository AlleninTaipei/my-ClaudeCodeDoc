進階安裝設定

系統需求, 平台專屬安裝方式, 版本管理, 以及移除 Claude Code 的完整參考。

系統需求

作業系統
macOS 13.0+, Windows 10 1809+, Ubuntu 20.04+, Debian 10+, Alpine 3.19+
硬體
4GB+ RAM, x64 或 ARM64 處理器
網路
需要網際網路連線
Shell
Bash, Zsh, PowerShell 或 CMD
依賴

ripgrep 通常已內建, 若搜尋失敗請參考疑難排解頁面。

安裝 Claude Code

選擇安裝方式:
Native
Homebrew
WinGet
curl -fsSL https://claude.ai/install.sh | bash
brew install --cask claude-code
winget install Anthropic.ClaudeCode

在 Windows 上設定

Native Windows不需管理員權限, Git for Windows 為選用, 適合 Windows 原生專案
WSL 2需啟用 WSL 2, 支援 sandboxing, 適合 Linux 工具鏈
WSL 1不支援 sandboxing, WSL 2 無法使用時的備案

Alpine Linux

apk add libgcc libstdc++ ripgrep

驗證你的安裝

claude --version
claude doctor
TIP

claude doctor 會提供更詳細的安裝與設定檢查結果。

驗證身分

Claude Code 需要 Pro, Max, Team, Enterprise 或 Console 帳號。免費的 claude.ai 方案不含 Claude Code 存取權。也可透過 Amazon Bedrock, Google Vertex AI 或 Microsoft Foundry 使用。

claude
# 依瀏覽器提示完成登入

更新 Claude Code

自動更新Native 安裝會在背景自動檢查並下載更新, 下次啟動時生效
設定發行頻道autoUpdatesChannel 設為 latest 或 stable
釘選最低版本minimumVersion 設定更新下限, 防止自動降版
停用自動更新DISABLE_AUTOUPDATER 設為 1, DISABLE_UPDATES 則封鎖所有更新途徑
手動更新執行 claude update 立即套用更新
{
  "autoUpdatesChannel": "stable",
  "minimumVersion": "2.1.100"
}

進階安裝選項

選擇主題:
安裝特定版本
Linux 套件管理器
npm 安裝
二進位完整性驗證
curl -fsSL https://claude.ai/install.sh | bash -s 2.1.89
# apt (Debian/Ubuntu)
sudo apt install claude-code

# dnf (Fedora/RHEL)
sudo dnf install claude-code
npm install -g @anthropic-ai/claude-code
警告

不要使用 sudo npm install -g, 可能導致權限問題與安全風險。

curl -fsSL https://downloads.claude.ai/keys/claude-code.asc | gpg --import
gpg --verify manifest.json.sig manifest.json

macOS 由 Anthropic PBC 簽署並經 Apple 公證, Windows 由 Anthropic, PBC 簽署。

移除 Claude Code

Native移除 ~/.local/bin/claude 與 ~/.local/share/claude
Homebrewbrew uninstall --cask claude-code
WinGetwinget uninstall Anthropic.ClaudeCode
npmnpm uninstall -g @anthropic-ai/claude-code
警告

移除設定檔會刪除所有設定, 允許清單, MCP 伺服器設定與 session 歷史紀錄。
