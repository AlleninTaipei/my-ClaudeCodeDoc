桌面版 App 快速上手

安裝 Claude Code 桌面版, 開始你的第一個編碼 session。

桌面版三個分頁

桌面版提供圖形化介面, 用於並排管理多個 session: 側邊欄, 拖放式版面配置搭配內建終端機與檔案編輯器, 視覺化差異審查, 即時應用預覽, GitHub PR 監控與自動合併, 以及排程任務。

Chat

一般對話, 不存取檔案, 類似 claude.ai。

Cowork

在雲端 VM 中自主背景執行任務, 可獨立運作。

Code

互動式編碼助手, 直接存取本機檔案, 你即時審查並核准每項變更。

NOTE

Claude Code 需要 Pro, Max, Team 或 Enterprise 訂閱方案。

安裝流程

1 · 安裝並登入
2 · 開啟 Code 分頁

在 macOS 與 Windows 下載安裝程式並執行。Linux 依照 Claude Desktop on Linux 的步驟安裝。啟動後用 Anthropic 帳號登入。

點擊上方中間的 Code 分頁。若提示升級, 需先訂閱付費方案。若提示線上登入, 完成登入後重啟應用程式。

Step 1 of 2

開始你的第一個 Session

1 · 選環境與資料夾
2 · 選模型
3 · 告訴 Claude 要做什麼
4 · 審查並接受變更

選擇 Local 在本機執行, 或 Remote 使用雲端基礎設施, 或 SSH 連線到遠端機器。Windows 上本機 session 需要安裝 Git。

在送出按鈕旁的下拉選單選擇模型, 之後隨時可以更換。

Find a TODO comment and fix it
Add tests for the main function
Create a CLAUDE.md with instructions for this codebase

預設在 Ask permissions 模式下, Claude 會提出變更並等待核准: 差異檢視畫面, 接受/拒絕按鈕, 以及即時更新。拒絕變更後 Claude 會詢問要如何改用不同方式進行。

從 CLI 過來的使用者?

INFO

桌面版執行與 CLI 相同的引擎, 只是多了圖形化介面。兩者可以同時在同一個專案上執行, 並共用設定 (CLAUDE.md, MCP 伺服器, hooks, skills 與設定檔)。
