Claude Code on the Web

在瀏覽器或手機的雲端執行 Claude Code, 連接 GitHub 儲存庫, 送出任務並審查 PR, 不需要本機設定。

Session 如何執行

1 · 複製並準備
2 · 設定網路
3 · 工作
4 · 推送分支

你的儲存庫被複製到 Anthropic 管理的 VM, 並執行你設定的 setup script。

依環境的存取層級設定網際網路存取權限。

Claude 分析程式碼, 進行修改, 執行測試並檢查成果, 你可以全程觀看或引導, 也可以離開稍後再回來。

Claude 到達停止點後推送分支到 GitHub, 你可以審查差異, 留下行內註解, 建立 PR, 或送出下一則訊息繼續。

開始一項任務

選擇儲存庫與分支可加入多個儲存庫在同一 session 中跨庫工作
選擇權限模式預設 Accept edits, 或切換到 Plan mode 先審查再動手
描述任務並送出具體指出檔案或函式, 貼上錯誤輸出, 描述預期行為

預先填入 Session

透過查詢參數預先填入 prompt, 儲存庫與環境, 用於整合像是 issue tracker 中的按鈕。

prompt / q
要預先填入輸入框的提示文字
prompt_url
從網址抓取提示文字, 適合太長無法內嵌的提示
repositories / repo
逗號分隔的 owner/repo 清單
environment
要預選的環境名稱或 ID
https://claude.ai/code?prompt=Fix%20the%20login%20bug&repositories=acme/webapp

審查與迭代

1. 開啟差異檢視例如 +42 -18 的指示器, 左側檔案清單, 右側變更內容
2. 留下行內註解選取任一行輸入意見, 會與下一則訊息一起送出
3. 建立 Pull Request開成完整 PR, draft, 或跳到 GitHub 撰寫頁面
4. PR 之後持續迭代貼上 CI 失敗輸出或審查者意見, 請 Claude 處理

疑難排解設定

選擇問題:
看不到儲存庫
只顯示 GitHub 登入按鈕
Setup script 失敗
Session 卡住或逾時

雲端 session 可使用連接帳號能看到的任何儲存庫。確認 GitHub 帳號有存取權, 若要用 Auto-fix, 需在該儲存庫安裝 Claude GitHub App。

雲端 session 需要連接 GitHub 帳號。用瀏覽器流程連接, 或用 gh CLI 執行 /web-setup。

常見原因: 套件安裝的登錄檔不在網路存取層級內, 腳本引用不存在的路徑, 或指令在 Ubuntu 上需要不同呼叫方式。加上 set -x 除錯。

setup script 可能超過約五分鐘的建置時間預算。拉大型 Docker image 或下載模型權重的步驟應改用 SessionStart hook 在背景進行。
