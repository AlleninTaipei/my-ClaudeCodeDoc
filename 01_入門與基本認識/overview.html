Claude Code 總覽

能讀取程式庫, 編輯檔案, 執行指令並整合開發工具的代理式編碼工具, 在終端機, IDE, 桌面版與瀏覽器中都能使用。

在終端機直接使用的全功能 CLI, 編輯檔案, 執行指令並管理整個專案。

curl -fsSL https://claude.ai/install.sh | bash

cd your-project
claude

VS Code 擴充套件提供行內差異比對, @-提及, 計畫審查以及編輯器內的對話紀錄。

獨立應用程式, 可在 IDE 或終端機之外使用。視覺化審查差異, 並排執行多個 session, 排定週期性任務, 啟動雲端 session。

在瀏覽器中執行, 免本機設定。啟動長時間任務並在完成後查看, 處理本機沒有的儲存庫, 或平行執行多項任務。

適用於 IntelliJ IDEA, PyCharm, WebStorm 等 JetBrains IDE 的外掛, 具互動式差異檢視與選取內容分享。

Claude Code 處理耗時的瑣碎任務: 為未測試程式碼寫測試, 修正整個專案的 lint 錯誤, 解決合併衝突, 更新依賴套件, 撰寫發行說明。

claude "write tests for the auth module, run them, and fix any failures"

用白話描述你想要的東西, Claude Code 會規劃方法, 跨多個檔案撰寫程式碼, 並驗證是否可行。針對錯誤, 貼上錯誤訊息或描述症狀, Claude 會沿著程式庫追蹤問題, 找出根本原因並實作修正。

Claude Code 直接與 git 互動, 暫存變更, 撰寫提交訊息, 建立分支, 開啟 pull request。

claude "commit my changes with a descriptive message"

Model Context Protocol 是連接 AI 工具與外部資料來源的開放標準。透過 MCP, Claude Code 能讀取 Google Drive 中的設計文件, 更新 Jira 工單, 從 Slack 拉資料, 或使用你自己的自訂工具。

CLAUDE.md 是加到專案根目錄的 markdown 檔, 用來設定程式碼標準, 架構決策與偏好的函式庫。Skills 打包可重複使用的工作流程, Hooks 讓你在動作前後執行 shell 指令。

生成多個同時處理任務不同部分的 Claude Code 代理, 由 lead agent 協調工作, 指派子任務並整合結果。Agent SDK 讓你建立完全自訂的工作流程。

Claude Code 遵循 Unix 哲學, 可組合使用。將日誌管進去, 在 CI 中執行, 或與其他工具串接。

tail -200 app.log | claude -p "Slack me if you see any anomalies"

依排程執行 Claude 來自動化重複性的工作: 每天早上審查 PR, 隔夜分析 CI 失敗, 每週依賴套件稽核, 或 PR 合併後同步文件。

Session 不綁定單一介面。用 Remote Control 從手機或瀏覽器繼續工作, 用 --teleport 把雲端或行動裝置上的任務拉進終端機, 或在 Slack 中提及 @Claude 取得 pull request。
