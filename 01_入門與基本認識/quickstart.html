Quickstart 快速上手

幾分鐘內開始使用 AI 驅動的編碼協助, 一步步走過安裝, 登入到第一次修改程式碼。

開始之前

終端機
已開啟命令列, 新手可參考 terminal guide
程式專案
一個可以練習操作的程式碼專案
帳號
Claude 訂閱 (Pro, Max, Team, Enterprise) 或 Console 帳號, 或透過支援的雲端供應商
NOTE

本指南涵蓋終端機 CLI, Claude Code 也支援 web, desktop app, VS Code, JetBrains, Slack 與 CI/CD。

Step 1: 安裝 Claude Code

選擇安裝方式:
Native (建議)
Homebrew
WinGet
# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
brew install --cask claude-code
winget install Anthropic.ClaudeCode

Step 2: 登入你的帳號

claude
Claude Pro/Max/Team建議方案, 瀏覽器完成驗證
Claude ConsoleAPI 存取搭配預付額度, 首次登入自動建立工作區
Bedrock / Vertex AI / Foundry企業雲端供應商
自架 Claude apps gateway/login 直接開啟 Cloud gateway 畫面, 用企業 SSO 登入

Step 3: 開始你的第一個 Session

cd /path/to/your/project
claude

輸入 /help 查看可用指令, 或 /resume 繼續先前的對話。

Step 4: 提出你的第一個問題

what does this project do?
what technologies does this project use?
where is the main entry point?
explain the folder structure
NOTE

Claude Code 會依需要讀取你的專案檔案, 不需要手動加入情境。

Step 5: 做出第一個程式碼修改

add a hello world function to the main file
1. 找到檔案Claude Code 找出適合的檔案
2. 顯示變更向你展示提議的修改內容
3. 請求核准等待你的同意
4. 進行編輯核准後才真正寫入檔案

Step 6: 用 Git 搭配 Claude Code

what files have I changed?
commit my changes with a descriptive message
create a new branch called feature/quickstart
show me the last 5 commits
help me resolve merge conflicts

Step 7: 修正錯誤或新增功能

add input validation to the user registration form
there's a bug where users can submit empty forms - fix it
定位相關程式碼找出問題所在位置
理解情境分析周邊程式碼與邏輯
實作解決方案寫出修正或新功能
執行測試若有測試就一併執行驗證

Step 8: 試試其他常見工作流程

選擇工作流程:
重構程式碼
撰寫測試
更新文件
程式碼審查
refactor the authentication module to use async/await instead of callbacks
write unit tests for the calculator functions
update the README with installation instructions
review my changes and suggest improvements

常用指令

Shell 指令

claude啟動互動模式
claude "task"執行一次性任務
claude -p "query"執行一次性查詢後結束
claude -c繼續目前目錄最近的對話
claude -r從清單恢復先前對話

Session 指令

/clear清除對話紀錄
/help顯示可用指令
/exit結束 Claude Code
