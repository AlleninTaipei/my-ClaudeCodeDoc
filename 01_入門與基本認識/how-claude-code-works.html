Claude Code 如何運作

理解 agentic loop, 內建工具, 以及 Claude Code 如何與你的專案互動。

The Agentic Loop

當你交給 Claude 一項任務時, 它會經歷三個階段, 這些階段會交織進行, Claude 全程都在使用工具。

1 · 蒐集情境
2 · 採取行動
3 · 驗證結果

搜尋檔案, 理解程式碼如何串接, 弄清楚要完成目標需要修改什麼。這由模型負責推理, 由 Claude Code 這個 agentic harness 提供工具, 上下文管理與執行環境。

讀取程式碼, 編輯檔案, 執行指令, 搜尋網頁, 與外部服務互動。每次工具使用都會回傳資訊, 回饋進入下一個決策。

執行測試, 檢查結果是否符合預期, 並依所學調整。重構可能牽涉大量的驗證步驟。你隨時可以中斷來調整方向。

執行環境與介面

Local

程式碼在你的機器上執行, 這是預設選項, 完整存取你的檔案, 工具與環境。

Cloud

程式碼在 Anthropic 管理的 VM 上執行, 適合卸載任務或處理本機沒有的儲存庫。

Remote Control

程式碼仍在你的機器上執行, 但由瀏覽器控制, 讓一切都留在本機。

介面

終端機, Desktop app, IDE 擴充套件, claude.ai/code, Remote Control, Slack, CI/CD 管線, 底層的 agentic loop 完全相同。

與 Session 一起工作

Claude Code 在你工作時把對話存成本機純文字 JSONL 檔案, 這讓回溯, 恢復與分支 session 成為可能。每個新 session 從乾淨的上下文視窗開始, 但 Claude 可以透過 auto memory 跨 session 保留學習內容。

跨分支工作切換分支時 Claude 看見新分支的檔案, 但對話紀錄維持不變
恢復或分支 Sessionclaude --continue 或 --resume 沿用同一 ID, --fork-session 或 /branch 複製到新 ID
上下文視窗隨著工作填滿, Claude 自動壓縮, 但早期的指示可能遺失, 持久規則請放進 CLAUDE.md
上下文填滿時先清除較舊的工具輸出, 需要時才摘要對話, 若持續填滿過快會顯示 thrashing 錯誤而非無限循環
用 Skills 與 Subagents 管理Skills 按需載入, Subagents 擁有全新且獨立的上下文, 完成後只回傳摘要

用 Checkpoint 與權限保持安全

Checkpoints (復原)

每次編輯前 Claude 都會先快照目前內容。按兩下 Esc 即可回溯到先前狀態。checkpoint 僅限於本機 session, 與 git 分開, 只涵蓋檔案變更。

Permissions (權限)

按 Shift+Tab 循環切換 Default, Auto-accept edits, Plan mode 與 Auto mode 四種模式, 也可以在 settings.json 中允許特定指令免詢問。
