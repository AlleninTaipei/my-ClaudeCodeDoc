Agent teams
多個獨立 Claude Code session 由 team lead 協調, 共用任務清單與點對點訊息, 每個成員都有自己的上下文視窗。
Agentic coding
AI 能讀取檔案, 執行指令並自主進行修改的工作流程, 而非只回覆文字等你套用。
Agentic harness
把語言模型變成有能力的編碼代理的工具, 上下文管理與執行環境。Claude Code 是 harness, Claude 是其中的模型。
Agentic loop
蒐集情境, 採取行動, 驗證結果, 重複直到完成的循環。多數擴充點都掛接在此循環的特定階段。
Artifact
Claude Code 從 session 發布到 claude.ai 私有網址的即時互動網頁, 分享範圍僅限於你的組織。
Auto memory
Claude 依你的修正與偏好自行撰寫的筆記, 存放於每個 git 儲存庫下的 ~/.claude/projects/。
Auto mode
獨立分類模型在背景審查動作的權限模式, 多數動作不需核准提示, 攔截範圍擴大, 未知基礎設施與提示注入。
Bare mode
--bare 啟動旗標, 跳過 hooks, skills, plugins, MCP 伺服器, auto memory 與 CLAUDE.md 的自動探索。
Bundled skills
內建的提示式工作手冊, 例如 /batch, /code-review, /debug, /loop, 讓 Claude 編排工作而非執行固定邏輯。
Channel
將事件推送進執行中 session 的 MCP 伺服器, 讓 Claude 能對你不在終端機時發生的事做出反應。
Checkpoint
每次送出提示時建立的還原點, Claude Code 在每次編輯前都會先快照檔案內容。
.claude directory
Claude Code 讀取專案範圍設定的目錄: 設定, hooks, skills, subagents, rules 與 auto memory。
CLAUDE.md
你為 Claude 撰寫的持久指示 markdown 檔, 在系統提示之後作為使用者訊息載入每個 session。
Command
輸入 /name 呼叫的可重複使用指令。內建指令控制 session, 也可以在 .claude/commands/ 自訂。
Compaction
上下文視窗接近上限時的自動摘要。較舊的工具輸出會先被清除, 接著才會摘要對話內容。
Context window
session 的工作記憶, 保存對話紀錄, 檔案內容, 指令輸出, CLAUDE.md, auto memory, 已載入的 skills 與系統指示。
Dispatch
從手機發起的任務路由, 當你從 Claude 行動 App 送出編碼任務時, 會在 Desktop App 中生成一個 Claude Code session。
Effort level
控制每輪使用多少自適應推理思考預算的設定, 較高的 effort 代表更多思考 token 與更深入的推理。
Extended thinking
模型回應前執行的可見逐步推理過程, 可用 effort level 調整或用 MAX_THINKING_TOKENS 限制。
Hook
在 Claude Code 生命週期特定時間點自動執行的使用者定義處理器, 確定性地觸發而非由模型自行決定。
Managed settings
由 IT 或 DevOps 全組織強制執行的設定, 使用者與專案設定無法覆寫。
MCP (Model Context Protocol)
連接 AI 工具與外部資料來源及服務的開放標準, 提供 Slack, Jira, 資料庫, 瀏覽器等數百種整合。
MCP Tool Search
延遲載入 MCP 工具結構描述的節省上下文機制, 啟動時只載入工具名稱。
Non-interactive mode
用 -p 或 --print 呼叫, 執行單一提示後不進入對話式 session 就結束, 用於 CI, 腳本與管線。
Output style
修改 Claude 系統提示以改變回應行為, 語氣或格式的設定, 會關閉預設系統提示中軟體工程專屬的部分。
Permission mode
session 的基本核准行為, 可用的模式包含 default, acceptEdits, plan, auto, dontAsk 與 bypassPermissions。
Permission rule
根據工具名稱與參數模式決定允許, 詢問或拒絕的設定項目, 依 deny → ask → allow 順序評估, 先比對到者優先。
Plan mode
Claude 研究並提出變更但不編輯原始檔案的權限模式, 提出計畫等待核准後才動手。
Plugin
將 skills, hooks, subagents 與 MCP 伺服器打包成單一可安裝單元, 以 plugin-name:skill-name 命名空間區隔。
Project trust
Claude Code 載入設定前的目錄信任對話框, 信任後 .claude/settings.json 與 .mcp.json 等設定才會生效。
Prompt injection
嵌在檔案, 網頁或工具結果中的惡意指示, 試圖將 Claude 導向你未曾要求的動作。
Remote Control
透過 claude.ai 從手機或瀏覽器繼續本機 Claude Code session, 程式碼留在本機, 只有介面是遠端的。
Rules
.claude/rules/ 中的模組化指示檔, 與 CLAUDE.md 一起載入, 可用 YAML paths 前置資料限定路徑範圍。
Sandboxing
Bash 工具的作業系統層級檔案系統與網路隔離, 讓 Claude 能在你預先定義的邊界內自由工作。
Session
綁定目前目錄的對話, 擁有獨立的上下文視窗, 可用 claude -c 恢復或用 --fork-session 分支。
Settings layers
Claude Code 讀取設定的層級順序: managed policy, 命令列參數, local settings, 專案設定, 使用者設定。
Skill
包含指示, 知識或工作流程的 SKILL.md 檔案, Claude 相關時自動載入, 也可以用 /skill-name 直接呼叫。
Subagent
在自己的上下文視窗中執行的專門 AI 助手, 擁有自訂系統提示, 特定工具存取權與獨立權限。
Surface
你存取 Claude Code 的任何地方: CLI, VS Code, JetBrains, Desktop 或 claude.ai, 所有介面共用同一套引擎。
Teleport
/teleport 指令, 把雲端 Claude Code session 拉進本機終端機, 反方向則是 --remote。
Tool
Claude 能採取的動作: 讀檔, 編輯程式碼, 執行 shell 指令, 搜尋網頁, 生成 subagent。
Turn
session 中 Claude 的一次完整回應, 從你送出訊息開始, 到 Claude 完成回應結束, 中間可有任意次工具呼叫。
Verification loop
session 如何得知工作是真的完成而非只是看起來合理, 給 Claude 一個可執行的檢查, 讓它反覆迭代直到通過。
Worktree isolation
在 .claude/worktrees/ 下獨立 git worktree 執行 Claude 的隔離模式, 讓平行代理不會互相覆寫檔案。

已棄用或改名的術語

這些術語出現在較舊的文件, 部落格文章與社群內容中, 搜尋本站時請改用目前的名稱。

Headless mode現稱 Non-interactive mode, 相同的 -p 旗標, 相同行為
Custom commands現稱 Skills, .claude/commands/ 檔案仍可運作
Slash commands現稱 Commands, 產品文案中已刪去「slash」
TIP

模型層級的概念如 tokens, temperature 與 RAG, 請參考 platform glossary。
