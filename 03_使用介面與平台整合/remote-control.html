Remote Control

從手機, 平板或任何瀏覽器繼續本機的 Claude Code session. 適用於 claude.ai/code 與 Claude 行動 app.

需求

在使用 Remote Control 之前, 確認環境符合以下條件.

訂閱方案
Pro, Max, Team, Enterprise 皆可用, 不支援 API key. Team/Enterprise 需 Owner 先在管理設定中啟用
身分驗證
執行 claude 並用 /login 透過 claude.ai 登入
API 端點
不支援 Amazon Bedrock, Google Vertex AI, Microsoft Foundry, 也不支援自訂 ANTHROPIC_BASE_URL
工作區信任
需先在專案目錄執行過一次 claude 以接受工作區信任對話框

啟動 Remote Control Session

可以從 CLI 或 VS Code 擴充套件啟動. CLI 提供三種啟動模式, VS Code 使用 /remote-control 指令.

1 · Server 模式
2 · 互動式 Session
3 · 從既有 Session
4 · VS Code
claude remote-control

程序會在終端機中以 server 模式持續執行, 等待遠端連線. 會顯示 session URL, 也可按空白鍵顯示 QR code.

--name
自訂 session 標題
--spawn
same-dir (預設), worktree, 或 session 單一模式
--capacity
最大並行 session 數, 預設 32
--sandbox
啟用或停用沙盒隔離, 預設關閉
claude --remote-control

啟動完整的互動式 session, 同時可在終端機輸入, 也能從 claude.ai 或 Claude app 遠端操控.

/remote-control

在既有 session 中繼續遠端操控, 會延續目前的對話紀錄.

/remote-control

在 VS Code 擴充套件中輸入 /remote-control 或 /rc, 連線後點選 Open in browser 前往 session.

Step 1 of 4

連線與安全性

本機的 Claude Code session 只會發出對外的 HTTPS 請求, 從不在機器上開啟入站連接埠. 所有流量透過 Anthropic API 以 TLS 傳輸, 使用多個範圍受限且各自過期的短期憑證.

Trusted Devices

Team 與 Enterprise 可啟用 Trusted Devices, 要求成員的裝置先註冊, 且登入時間需在 18 小時內, 否則會要求生物辨識再次確認身分.

Remote Control 與 Claude Code on the web 比較

Remote Control

在你自己的機器上執行, 本機 MCP 伺服器, 工具與專案設定都可使用

適合正在進行本機工作, 想從另一台裝置繼續操作時使用

Claude Code on the web

在 Anthropic 代管的雲端基礎設施中執行

適合不想做任何本機設定, 或想平行執行多個任務時使用

限制

單一遠端 session非 server 模式下, 每個互動式程序同時只支援一個遠端 session
本機程序需持續執行關閉終端機, 結束 VS Code 或停止 claude 程序都會結束 session
網路中斷逾時機器醒著但斷網超過約 10 分鐘, session 會逾時並結束程序
Ultraplan 會中斷連線啟動 ultraplan session 會中斷現有的 Remote Control 連線
