在 VS Code 中使用 Claude Code

安裝並設定 Claude Code 擴充套件, 取得行內 diff, @-mention, plan 審查與鍵盤快捷鍵等圖形化輔助.

先決條件與安裝

VS Code 版本
需要 1.98.0 以上版本
帳號
任何付費 Claude 訂閱或 Claude Console 帳號, 不需要 API key
# VS Code / Cursor 安裝連結, 或在擴充套件檢視搜尋 "Claude Code"
vscode:extension/anthropic.claude-code
提示

擴充套件內建自己的 CLI 副本供聊天面板使用. 若要在整合終端機中執行 claude 指令, 仍需另外安裝 standalone CLI.

開始使用

1 · 開啟面板
2 · 登入
3 · 送出提示
4 · 審查變更

點選編輯器右上角的 Spark 圖示最快開啟面板. 也可從 Activity Bar, Command Palette 或 Status Bar 開啟.

首次開啟面板會出現登入畫面, 點選 Sign in 並在瀏覽器完成驗證.

Claude 會自動看到選取的文字, 按 Option+K / Alt+K 插入 @-mention 參照.

Claude 要編輯檔案時會顯示並排的原始與提議變更比較, 並詢問權限.

提示框功能

Permission modes一般模式, Plan 模式, 自動接受模式三種切換
Command menu輸入 / 附加檔案, 切換模型, 開關 extended thinking
Context indicator顯示 context window 使用比例, 可手動 /compact
@-mentions用 @ 加檔案或資料夾名稱給 Claude 上下文, 支援模糊比對
Multi-line inputShift+Enter 換行不送出

自訂工作流程與管理外掛

面板位置

可拖曳到右側次要側邊欄, 左側主側邊欄, 或編輯器區域開成分頁

管理外掛

輸入 /plugins 開啟管理介面, 分為 Plugins 與 Marketplaces 兩個分頁, 安裝時可選擇使用者, 專案或本機範圍

用 Chrome 自動化瀏覽器任務

連接 Claude 到 Chrome 瀏覽器以測試網頁應用, 用 console log 除錯, 需要 Claude in Chrome 擴充套件 1.0.36 以上版本.

@browser go to localhost:3000 and check the console for errors

常用指令與快捷鍵

Cmd/Ctrl+Esc切換編輯器與 Claude 面板的焦點
Cmd/Ctrl+Shift+Esc在新分頁開啟一段新對話
Cmd/Ctrl+N開始新對話 (需啟用設定)
Option/Alt+K插入目前檔案與選取範圍的 @-mention 參照

設定

VS Code 擴充套件與 CLI 的差異

CLI

所有指令與 skills, 完整 MCP 設定, ! bash 捷徑, tab 補全

VS Code 擴充套件

指令子集, 部分 MCP 管理, 支援 checkpoint 回溯的三種選項

Checkpoint

Fork conversation from here, Rewind code to here, Fork conversation and rewind code 三種回溯方式.

Git 整合與第三方供應商

Claude 可以暫存變更, 撰寫 commit 訊息並建立 pull request. 使用 --worktree (-w) 旗標可在獨立的 git worktree 中啟動 Claude.

claude --worktree feature-auth

若組織使用 Amazon Bedrock, Google Vertex AI 或 Microsoft Foundry, 需在設定中停用登入提示並依供應商指南設定 ~/.claude/settings.json.

安全性與內建 IDE MCP 伺服器

擴充套件啟用時會執行本機 MCP 伺服器供 CLI 自動連接, 綁定於 127.0.0.1 隨機高位連接埠, 每次啟用都會產生新的驗證權杖.

mcp__ide__getDiagnostics
回傳語言伺服器診斷訊息, 不會寫入
mcp__ide__executeCode
在使用中的 Jupyter kernel 執行 Python 程式碼, 每次都會先詢問確認

疑難排解

Spark 圖示看不到需先開啟檔案, 圖示才會出現在編輯器工具列
Cmd+Esc 沒有反應macOS Tahoe 的 Game Overlay 快捷鍵攔截了按鍵, 需在系統設定中清除
擴充套件無回應確認網路連線, 開始新對話, 或改用 CLI 測試

移除擴充套件後, 在整合終端機執行 claude 會自動重新安裝. 若要保持解除安裝狀態, 需在 /config 關閉 Auto-install IDE extension.
