在 JetBrains IDE 中使用 Claude Code

透過專屬外掛程式在 IntelliJ, PyCharm, WebStorm 等 JetBrains IDE 中使用 Claude Code, 包含互動式 diff 檢視與選取內容分享。

功能特色

快速啟動Cmd+Esc (Mac) 或 Ctrl+Esc (Windows/Linux) 直接從編輯器開啟 Claude Code
Diff 檢視程式碼變更可直接顯示在 IDE 的 diff 檢視器, 而非終端機
選取內容分享IDE 中目前選取或分頁自動分享給 Claude Code, Read 拒絕規則可阻擋相符檔案
檔案參照快捷鍵Cmd+Option+K (Mac) 或 Alt+Ctrl+K 插入檔案參照如 @src/auth.ts#L1-99
診斷分享IDE 的 lint 與語法錯誤等診斷資訊自動分享給 Claude

安裝

1 · 安裝 CLI
2 · 安裝外掛

外掛程式在你的 IDE 整合終端機中執行 claude 指令並連接它, 本身不包含 CLI 副本, 所以兩者都要安裝。外掛在找不到 claude 時會顯示 "Cannot launch Claude Code" 通知。

從 JetBrains Marketplace 安裝 Claude Code 外掛程式並重啟 IDE。若 claude 安裝在 IDE 找不到的位置, 在外掛程式的 Claude command 設定中指定完整路徑。

Step 1 of 2

使用方式

情境:
從 IDE 內
從外部終端機

在 IDE 的整合終端機中執行 claude, 所有整合功能會自動啟用。

在任何外部終端機用 /ide 指令把 Claude Code 連接到 JetBrains IDE:

claude
/ide

設定

Claude Code 設定

執行 claude, 輸入 /config, 把 diff tool 設為 auto 顯示在 IDE, 或 terminal 保留在終端機

外掛設定

Settings → Tools → Claude Code [Beta] 中設定 Claude command, 通知抑制, Option+Enter 多行輸入, 自動更新

ESC 鍵設定

若 ESC 鍵無法中斷 JetBrains 終端機中的 Claude Code 操作, 到 Settings → Tools → Terminal, 取消勾選 "Move focus to the editor with Escape" 或刪除對應快捷鍵。

特殊設定

遠端開發

使用 JetBrains Remote Development 時, 外掛必須安裝在遠端主機上, 而非本機客戶端

WSL 設定

若出現 "No available IDEs detected", 通常是 WSL2 NAT 網路或 Windows 防火牆阻擋了 WSL2 與 IDE 的連線

# PowerShell 管理員權限執行, 依你的子網路調整範圍
New-NetFirewallRule -DisplayName "Allow WSL2 Internal Traffic" -Direction Inbound -Protocol TCP -Action Allow -RemoteAddress 172.21.0.0/16 -LocalAddress 172.21.0.0/16

安全考量

警告

在 acceptEdits 權限模式下, Claude Code 可能修改 IDE 會自動執行的設定檔, 這可能增加 acceptEdits 模式的風險, 並可能繞過 bash 執行的權限提示。建議使用手動核准模式, 只在可信任的提示詞中使用 Claude, 並留意 Claude Code 可存取的檔案。

重點整理

JetBrains 外掛不是獨立的 Claude 引擎, 而是把 CLI 的輸出接進 IDE 原生的 diff 檢視與選取分享機制, 這代表安裝順序很重要: 先裝 CLI, 再裝外掛, 兩者缺一不可。
