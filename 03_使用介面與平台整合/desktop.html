Claude Desktop 應用程式

平行 session, Git 隔離, 拖放版面, 整合終端機與編輯器, 側邊對話, computer use, 從手機發起的 Dispatch session, 視覺化 diff 審查, 應用預覽, PR 監控, 連接器, 企業設定, 一次看懂 Code 分頁的完整功能。

開始一個 Session

Desktop 應用有三個分頁: Chat 用於對話, Cowork 用於 Dispatch 與較長的代理工作, Code 用於軟體開發。傳送第一則訊息前需設定四項:

Environment
Local 本機, Remote 雲端, 或 SSH 連線至你管理的機器
Project folder
Claude 工作的資料夾或 repository, 雲端 session 可加入多個 repo
Model
傳送按鈕旁的下拉選單挑選模型, session 中可隨時變更
Permission mode
從模式選擇器決定 Claude 的自主程度, session 中可隨時變更

行為

auto

行為

最佳實務

複雜任務先用 Plan mode 讓 Claude 規劃方式, 核准計畫後再切換到 Auto accept edits 或 Ask permissions 執行。

預覽你的應用

Claude 可以啟動開發伺服器並開啟內嵌瀏覽器驗證變更, 適用於前端網頁應用與後端伺服器。預設情況下, Claude 會在每次編輯後自動驗證變更。

互動直接在內嵌瀏覽器與運作中的應用互動
自動驗證Claude 截圖, 檢查 DOM, 點擊元素, 填寫表單, 修正發現的問題
伺服器控制從工具列 Preview 下拉選單啟動或停止伺服器
保留 session選擇 Persist sessions 讓 cookie 與 local storage 跨伺服器重啟保留

用 Diff 檢視審查變更

Claude 修改檔案後, diff 統計指標會顯示新增與刪除行數, 例如 +12 -1。點擊可開啟 diff 檢視器, 左側是檔案清單, 右側是每個檔案的變更。

加入留言

點擊 diff 中任一行開啟留言框, 輸入回饋後按 Enter 加入

加完多筆留言後 macOS 按 Cmd+Enter, Windows 按 Ctrl+Enter 一次送出

Review code

在 diff 檢視器右上角點擊 Review code, Claude 會評估變更並直接在 diff 中留言

聚焦在編譯錯誤, 明確邏輯錯誤, 安全漏洞, 明顯錯誤, 不檢查風格或格式

安排你的工作區

Code 分頁圍繞著可任意排列的面板組成: chat, diff, preview, terminal, file, plan, tasks, subagent。

Normal
工具呼叫收合成摘要, 完整文字回應
Verbose
每個工具呼叫, 檔案讀取, 中間步驟都顯示
Summary
只顯示 Claude 的最終回應與所做變更

常用快捷鍵: Cmd+/ 顯示所有快捷鍵, Cmd+N 新 session, Cmd+Shift+D 切換 diff 面板, Ctrl+` 切換終端機面板。

Computer use 是 macOS 與 Windows 上需要 Pro 或 Max 方案的研究預覽功能, Team 或 Enterprise 方案不支援, 且 Claude Desktop 應用必須執行中。

管理 Session

平行工作每個 Git 專案的 session 使用獨立 worktree, 互不影響直到 commit

Dispatch 任務從手機訊息發起, Dispatch 判斷後可能建立一個帶有 Dispatch 標記的 Code session

環境設定

環境類型:
Local
Cloud
SSH

在你的機器上執行, 直接存取檔案。應用不一定會繼承完整 shell 環境, 開啟環境下拉選單編輯本機環境變數, 加密儲存在本機。

在 Anthropic 雲端基礎架構上執行, 即使關閉應用仍持續進行, 用量算入訂閱方案上限, 沒有額外運算費用。

透過 SSH 連到雲端 VM, dev container, 或有特定硬體需求的伺服器, 遠端機器必須是 Linux 或 macOS。

企業設定

permissions.disableBypassPermissionsMode

disableAutoMode
設為 "disable" 阻止使用者啟用 Auto 模式
sshConfigs / sshHostAllowlist
預先設定或限制可連線的 SSH 主機
managedMcpServers
在第三方部署中向所有使用者推送 MCP 伺服器設定

從 CLI 過來?

Desktop 與 CLI 執行同一套底層引擎, 可以同時在同一台機器甚至同一個專案上運行, 各自保留獨立歷史紀錄, 但共用 CLAUDE.md 與專案記憶。

用 Desktop 當

要管理平行 session, 並排面板, 視覺化審查變更

用 CLI 當

需要腳本, 自動化, 或偏好終端機工作流程

疑難排解

403 或驗證錯誤登出再登入, 確認訂閱有效, 完全結束應用後重開
畫面空白或卡住重啟應用, 檢查更新, Windows 檢查事件檢視器崩潰紀錄
Failed to load session資料夾可能不存在, 缺少 Git LFS, 或檔案權限問題
找不到已安裝工具確認工具在一般終端機可用, 檢查 shell profile 是否設定 PATH, 重啟應用

重點整理

Desktop 版 Claude Code 用視覺化面板取代終端機文字流, 核心是同一顆引擎, 差異在於權限模式的圖形化切換, 內建 diff 審查與應用預覽, 以及可以跨裝置延續工作的 Dispatch 與雲端 session。
