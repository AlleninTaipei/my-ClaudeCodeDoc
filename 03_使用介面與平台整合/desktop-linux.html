Claude Desktop on Linux (beta)

在 Ubuntu 與 Debian 上安裝與更新 Claude 桌面應用, 具備與 macOS, Windows 相同的 Chat, Cowork, Code 體驗。

系統需求

作業系統
Ubuntu 22.04 以上, 或 Debian 12 以上
架構
x86_64 或 arm64
注意

其他符合需求的 Debian 系發行版可能可運作, 但未經官方測試。

安裝

1 · 加入 apt 儲存庫
2 · 安裝套件
3 · 啟動並登入

下載 Anthropic 的簽署金鑰:

sudo curl -fsSLo /usr/share/keyrings/claude-desktop-archive-keyring.asc https://downloads.claude.ai/claude-desktop/key.asc

註冊儲存庫:

echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/claude-desktop-archive-keyring.asc] https://downloads.claude.ai/claude-desktop/apt/stable stable main" | sudo tee /etc/apt/sources.list.d/claude-desktop.list
sudo apt update && sudo apt install claude-desktop

從應用程式啟動器啟動 Claude, 或在終端機執行 claude-desktop, 用你的 Anthropic 帳號登入。

Step 1 of 3

若無法使用 apt 儲存庫, 從 claude.com/download 下載 .deb 套件後執行:

sudo apt install ./claude-desktop_*.deb

更新

桌面應用在 Linux 上不會自我更新, 更新會隨系統的常規套件更新一起到來:

sudo apt update && sudo apt upgrade

解除安裝

sudo apt remove claude-desktop

這會連同簽署金鑰一起移除, 若之前有加入儲存庫項目, 也一併移除:

sudo rm /etc/apt/sources.list.d/claude-desktop.list

Linux Beta 尚未支援的功能

Computer Use應用與畫面控制在 Linux 上尚未提供
Dictation語音輸入在 Linux 桌面應用中不可用, 請改用 CLI 的 voice dictation
Quick Entry 全域熱鍵在 X11 上可用, 原生 Wayland 需要桌面環境的 GlobalShortcuts portal
Fedora 與 RHEL目前僅支援 Debian 系發行版, 其他發行版支援將於未來推出

重點整理

Linux 版 Desktop 透過 apt 儲存庫取得與系統更新一致的維護體驗, 功能上與 macOS, Windows 版相同引擎, 只是 computer use 與語音輸入尚未支援, 這些情境仍需改用 CLI。
