從連結啟動 Session

用 URL 開啟 Claude Code 終端機 session, 把 claude-cli:// 連結嵌入 runbook, 告警, 儀表板, 點一下就能在對的 repo 中打開對的提示詞。

運作原理

claude-cli:// 前綴是 Claude Code 向作業系統註冊的自訂 URL scheme, 類似 mailto: 開啟郵件客戶端的方式。

1 · 交給作業系統瀏覽器或應用把 URL 交給你的作業系統
2 · 辨識前綴作業系統辨識 claude-cli:// 前綴, 在你機器上啟動 Claude Code
3 · 開啟終端機新終端機視窗開啟, 在連結指定的目錄執行, 提示文字已預先填入輸入框
4 · 你來確認閱讀提示, 可編輯, 按 Enter 送出
安全設計

深層連結不會自動執行任何動作, 只會選擇目錄並填入提示框。即使點擊不信任來源的連結, 提示仍是惰性的, 在你閱讀並按 Enter 前不會傳送給模型。超過 1000 字元的提示會顯示字數並提醒你完整檢視。

建立連結

每個深層連結都以 claude-cli://open 開頭, 後面接可選的查詢參數:

claude-cli://open
q
預先填入提示框的文字, 需 URL 編碼, 換行用 %0A, 最多 5000 字元
cwd
工作目錄的絕對路徑, 拒絕網路或 UNC 路徑
repo
GitHub owner/name slug, Claude Code 解析到曾見過的本地 clone

若同時傳入兩者, cwd 優先, repo 會被忽略。

claude-cli://open?repo=acme/payments&q=Investigate%20the%20failed%20deploy%20of%20payments-api.%0ACheck%20recent%20commits%20to%20main%20and%20the%20last%20successful%20build.

選擇 cwd 還是 repo

使用 cwd
使用 repo

當每個點擊連結的人都在相同絕對路徑擁有專案時使用, 例如標準化的 devcontainer 或 VM 映像。

當連結會被分享, 每人 clone 到不同位置時使用。Claude Code 會找到你最近使用過的相符路徑, clone 與 worktree 分別追蹤, 且只會在你已跑過 Claude Code 至少一次的路徑中查找。

使用範例

1 · 嵌入 Runbook
2 · 從 shell 開啟
## High 5xx rate on web-gateway

1. Acknowledge the page in PagerDuty.
2. [Open Claude Code in the gateway repo](claude-cli://open?repo=acme/web-gateway&q=...)
3. Post initial findings in #incident.

GitHub 渲染的 Markdown 會拒絕 claude-cli://, 因此在 README, issue, wiki 中只會顯示標籤文字, 無法點擊。

# macOS
open "claude-cli://open?repo=acme/payments&q=review%20open%20PRs"

# Linux
xdg-open "claude-cli://open?repo=acme/payments&q=review%20open%20PRs"

# Windows PowerShell
Start-Process "claude-cli://open?repo=acme/payments&q=review%20open%20PRs"

註冊與支援平台

macOS
~/Applications/Claude Code URL Handler.app
Linux
claude-code-url-handler.desktop, 位於 $XDG_DATA_HOME/applications
Windows
HKEY_CURRENT_USER\Software\Classes\claude-cli

要完全阻止註冊, 在 settings.json 中設定 disableDeepLinkRegistration 為 "disable", 若要組織層級強制執行, 放進 managed settings。

疑難排解

點擊連結沒反應Handler 可能尚未註冊, 在該機器上啟動一次互動式 claude session, 結束後再試
連結顯示為純文字部分 Markdown 渲染器只允許 http/https, GitHub 會移除其他 scheme, 可放進程式碼區塊供複製
開啟到家目錄而非 reporepo 參數只解析已見過的 clone, 在該 clone 中執行一次 claude, 或改用 cwd 指定絕對路徑
開啟到錯誤的終端機macOS 記住最近使用的終端機, Linux 設定 $TERMINAL 環境變數, Windows 順序固定

重點整理

深層連結把「開啟正確目錄並填好提示詞」這件事變成一次點擊, 但真正送出提示的動作永遠留給人類確認, 這個設計讓它可以安全地嵌入 runbook, 告警與腳本中。
