在 Claude Code 中使用 Chrome (beta)

把 Claude Code 連接到 Chrome 瀏覽器擴充功能, 讓 CLI 或 VS Code 具備瀏覽器自動化能力, 測試網頁, 除錯 console log, 自動填表, 擷取網頁資料。

整合概念

Claude Code 透過 Claude in Chrome 瀏覽器擴充功能取得瀏覽器自動化能力。Claude 會開啟新分頁執行瀏覽器任務, 並共享你目前瀏覽器的登入狀態, 因此可以存取任何你已登入的網站。瀏覽器動作會在真實可見的 Chrome 視窗中即時執行, 遇到登入頁或 CAPTCHA 時會暫停並請你手動處理。

BETA 限制

目前僅支援 Google Chrome 與 Microsoft Edge, 尚不支援 Brave, Arc 等其他 Chromium 瀏覽器, 也不支援 WSL。整合功能不透過 Amazon Bedrock, Google Cloud Vertex AI 或 Microsoft Foundry 提供, 若你僅透過第三方供應商存取 Claude, 需要另外準備一個 claude.ai 帳號。

在 CLI 中開始使用

1 · 啟用 Chrome
2 · 請 Claude 使用瀏覽器
3 · 設為預設啟用
4 · 管理網站權限

用 --chrome 旗標啟動 Claude Code:

claude --chrome

也可以在現有 session 中執行 /chrome 來啟用。隨時執行 /chrome 可檢查連線狀態, 管理權限, 重新連接擴充功能, 或選擇要使用哪個已連接的瀏覽器。

這個範例會導覽到頁面, 進行互動, 並回報結果, 全程都在你的終端機或編輯器中完成:

Go to code.claude.com/docs, click on the search box,
type "hooks", and tell me what results appear

若不想每次 session 都輸入 --chrome, 執行 /chrome 並選擇 "Enabled by default"。在 VS Code 擴充功能中, 只要安裝了 Chrome 擴充功能就可以直接使用, 不需額外旗標。

注意

在 CLI 中預設啟用 Chrome 會增加 context 用量, 因為瀏覽器工具會一直載入。若發現 context 用量增加, 可以停用此設定, 只在需要時使用 --chrome。

網站層級的權限繼承自 Chrome 擴充功能。到 Chrome 擴充功能設定中管理權限, 控制 Claude 可以瀏覽, 點擊, 輸入的網站範圍。

疑難排解

擴充功能未偵測到確認擴充功能已啟用, Claude Code 已更新, Chrome 正在執行, 執行 /chrome 重新連接, 仍失敗則重啟兩者
瀏覽器沒有回應檢查是否有 modal 對話框阻擋頁面, 手動關閉後請 Claude 繼續, 或請 Claude 開新分頁重試
長時間 session 連線中斷擴充功能的 service worker 閒置過久會斷線, 執行 /chrome 重新連接
Windows 專屬問題named pipe 衝突需重啟 Claude Code, native messaging host 錯誤可嘗試重新安裝 Claude Code
"Browser extension is not connected"
重啟 Chrome 與 Claude Code, 執行 /chrome 重新連接
"Extension not detected"
在 chrome://extensions 安裝或啟用擴充功能
"No tab available"
請 Claude 建立新分頁再重試
"Receiving end does not exist"
執行 /chrome 並選擇 "Reconnect extension"

重點整理

Chrome 整合讓 Claude 能在同一個工作流程中把撰寫程式碼與瀏覽器測試除錯串接起來, 共用登入狀態且動作即時可見, 遇到登入或驗證碼會主動交還控制權給你, 是目前僅限 macOS 以外, Chrome 或 Edge 上的 beta 功能。
