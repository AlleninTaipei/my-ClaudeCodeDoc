Claude Code in Slack

直接從你的 Slack 工作區委派程式開發任務給 Claude.

使用情境

臭蟲調查與修復Slack 頻道回報問題後立即請 Claude 調查並修復
快速程式碼審查根據團隊回饋實作小型功能或重構
協同除錯團隊討論中的錯誤重現或使用者回報可作為除錯的關鍵上下文
平行任務執行在 Slack 啟動任務同時繼續其他工作, 完成後收到通知

工作區管理員必須從 Slack App Marketplace 安裝 Claude app.

在 Claude App Home 中點選 Connect, 完成瀏覽器內的驗證流程, 連結 Slack 帳號與 Claude 帳號.

前往 claude.ai/code 用相同帳號登入, 連接 GitHub 帳號, 並驗證至少一個要讓 Claude 操作的儲存庫.

Code only
所有 @提及都導向 Claude Code session, 適合只做開發任務的團隊
Code + Chat
依訊息內容智慧路由到 Code 或 Chat, 也可用 Retry as Code 重新導向

安裝後 Claude 不會自動加入任何頻道, 需在頻道中輸入 /invite @Claude 才能使用.

Step 1 of 5

運作方式

@提及 Claude 時, 系統會自動分析訊息判斷是否為開發任務. 若偵測到開發意圖, 會導向 Claude Code on the web 而不是一般聊天回應.

1 · Initiation在 Slack 中 @提及 Claude 並提出開發需求
2 · DetectionClaude 分析訊息並偵測開發意圖
3 · Session creation在 claude.ai/code 建立新的 session
4 · Progress updatesClaude 在 Slack 討論串中回報進度
5 · Completion完成後 @提及使用者並附上摘要與操作按鈕
6 · Review點選 View Session 或 Create PR
安全提醒

@Claude 被呼叫時會取得對話上下文以理解需求, Claude 可能遵循上下文中其他訊息的指示, 因此只在信任的 Slack 對話中使用 Claude.

存取權限

使用者層級

每個使用者用自己的帳號執行 session, 用量計入個人方案限制, 只能存取自己已連接的儲存庫

工作區與頻道層級

管理員決定是否安裝 app, 移除 app 會立即撤銷該工作區所有使用者的存取權; 頻道需明確邀請 Claude 加入才能使用
