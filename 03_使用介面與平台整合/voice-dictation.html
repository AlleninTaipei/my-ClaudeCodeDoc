語音輸入

在 Claude Code CLI 中用 hold-to-record 或 tap-to-record 說出你的提示詞.

需求

語音輸入會將錄音串流到 Anthropic 伺服器進行轉錄, 音訊不會在本機處理. 需要滿足以下所有條件.

Claude.ai 帳號
語音轉文字服務僅在此驗證方式下可用, 使用 API key, Bedrock, Vertex AI, Foundry 皆不可用
未啟用 HIPAA
組織啟用 HIPAA 合規時 /voice 會顯示已被組織政策停用
本機麥克風
在 Claude Code on the web 或 SSH session 中不可用
WSLg
在 WSL 中執行時需要 WSLg, WSL1 請改在原生 Windows 執行
重點

轉錄不消耗 Claude 訊息或 token 額度, 也不計入 /usage 顯示的限制.

啟用語音輸入

/voice
Voice mode enabled (hold). Hold space to record. Dictation language: en (/config to change).

Hold to record 與 Tap to record

Hold 模式 (預設)

按住 Space 開始錄音, 放開即停止並將轉錄文字插入游標位置

偵測按住需要一小段暖機時間, 可切換到 tap 模式或改綁修飾鍵組合來跳過

Tap 模式

輸入框為空時點一下開始錄音, 再點一下停止並送出

轉錄字數達三個字才會自動送出, 錄音超過 15 秒靜音或總長兩分鐘會自動停止

語言與按鍵設定

語音輸入使用與 Claude 回應語言相同的 language 設定, 若為空則預設為英文.

{
  "language": "japanese"
}

可在 ~/.claude/keybindings.json 中重新綁定 voice:pushToTalk 動作:

{
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "meta+k": "voice:pushToTalk",
        "space": null
      }
    }
  ]
}

疑難排解

Voice mode requires a Claude.ai account目前以 API key 或第三方供應商驗證, 執行 /login 改用 Claude.ai 帳號
Microphone access is denied在系統設定中授予終端機麥克風權限後再次執行 /voice
No audio recording tool foundLinux 上原生模組無法載入且未安裝備援工具, 依錯誤訊息安裝 SoX
No speech detected音訊已送達但辨識不到文字, 靠近麥克風並降低背景噪音
Voice input is failing repeatedly and has been paused連續多次啟動失敗後暫停, 需確認裝置可正常擷取音訊
