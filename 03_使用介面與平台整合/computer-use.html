從 CLI 讓 Claude 使用你的電腦

在 Claude Code CLI 中啟用 computer use, 讓 Claude 開啟應用程式, 點擊, 輸入, 並在 macOS 上看見你的畫面, 測試原生應用, 除錯視覺問題, 自動化只能透過 GUI 操作的工具。

什麼是 Computer Use

研究預覽

Computer use 是 macOS 上的研究預覽功能, 需要 Pro 或 Max 方案, Team 或 Enterprise 方案不支援。需要 Claude Code v2.1.85 以上版本, 且僅限互動式 session, 非互動模式 (-p 旗標) 不可用。

Computer use 讓 Claude 能開啟應用程式, 控制你的畫面, 並以你操作的方式在你的機器上工作。從 CLI 中, Claude 可以在同一個對話裡編譯 Swift 應用, 啟動它, 點擊每個按鈕, 並截圖結果。

能做什麼

建置並驗證原生應用
請 Claude 建置 macOS 選單列應用, 撰寫 Swift, 編譯, 啟動, 並點擊每個控制項驗證可用
端對端 UI 測試
指向本地 Electron 應用, 說「測試 onboarding 流程」, Claude 逐步點擊並截圖
除錯視覺與版面問題
告訴 Claude modal 在小視窗被裁切, Claude 重現, 截圖, 修正 CSS 並驗證
操作僅有 GUI 的工具
與設計工具, 硬體控制面板, iOS Simulator, 或無 CLI/API 的專屬應用互動

Computer Use 何時被使用

Claude 有數種與應用或服務互動的方式, computer use 是最廣泛也最慢的, 所以 Claude 會先嘗試最精確的工具:

優先順序

1. 有 MCP server 就用 MCP

2. Shell 指令用 Bash

3. 瀏覽器工作且已設定 Claude in Chrome 就用它

4. 以上皆非才用 computer use

保留給誰

畫面控制保留給其他工具無法觸及的事物: 原生應用, 模擬器, 沒有 API 的工具。

啟用 Computer Use

1 · 開啟 MCP 選單
2 · 啟用伺服器
3 · 授予 macOS 權限

在互動式 Claude Code session 中執行:

/mcp

在伺服器清單中找到 computer-use, 它會顯示為已停用。

選擇 computer-use 並選 Enable。設定會依專案保留, 因此每個想使用 computer use 的專案只需設定一次。

Accessibility
讓 Claude 可以點擊, 輸入, 捲動
Screen Recording
讓 Claude 看見你的畫面內容

提示包含開啟對應系統設定面板的連結, 都授予後在提示中選擇 Try again。macOS 可能要求你在授予 Screen Recording 後重啟 Claude Code。

Claude 如何在你的畫面上工作

一次一個 sessionComputer use 持有全機鎖定, 從第一個動作到 session 結束才釋放, 另一個 session 想使用時會顯示是哪個 session 持有鎖
工作時隱藏其他應用Claude 開始控制畫面時, 其他可見應用會被隱藏, 終端機視窗保持可見且不會出現在截圖中
截圖自動縮小Claude Code 會在傳送截圖給模型前自動縮小尺寸, 不需要調整螢幕解析度
隨時可停止按 Esc 可立即中止目前動作, 或在終端機按 Ctrl+C, Claude 會停止, 取消隱藏應用並歸還控制權

安全與信任邊界

警告

與沙盒化的 Bash 工具不同, computer use 在你的實際桌面上執行, 可存取你核准的應用。Claude 會檢查每個動作並標記畫面內容中潛在的 prompt injection, 但信任邊界並不相同。

Per-app 核准
Claude 只能控制你在目前 session 中已核准的應用
Sentinel 警告
授予 shell, 檔案系統, 或系統設定存取權的應用會在核准前被標記
終端機排除在截圖外
Claude 永遠看不到你的終端機視窗, session 中的畫面提示無法回饋進模型
全域逃脫鍵
Esc 鍵可以從任何地方中止 computer use, 且按鍵會被消耗, 避免 prompt injection 用它關閉對話框

疑難排解

另一個 session 佔用中另一個 Claude Code session 持有鎖, 需結束該 session, 若已崩潰則會自動釋放
權限提示反覆出現macOS 有時需要重啟請求的處理程序, 完全結束 Claude Code 並重新開始新 session

重點整理

Computer use 是最後手段而非首選工具, Claude 會優先使用 MCP, Bash, Chrome, 只有在沒有其他方式能觸及原生應用或無 API 工具時才控制畫面, 且每個動作都有核准, 標記, 鎖定等防護機制包圍。
