平台與整合

選擇在哪裡執行 Claude Code, 以及要連接哪些工具. 比較 CLI, Desktop, VS Code, JetBrains, Web, 行動裝置, 以及 Chrome, Slack, CI/CD 等整合.

在哪裡執行 Claude Code

Claude Code 在每個介面上都使用相同的底層引擎, 但每個介面針對不同的工作方式做了調整. 點選下方平台查看適合場景與提供的功能.

重點

CLI 是終端機原生工作的最完整介面, 腳本化與 Agent SDK 僅限 CLI 使用. 第三方供應商也能在 VS Code 中使用. 企業版 Desktop 部署支援 Vertex AI 與 gateway 供應商; Bedrock 或 Foundry 請改用 CLI 或 VS Code.

可以在同一個專案中混用多種介面. 設定, 專案記憶與 MCP 伺服器會在本機介面之間共用.

連接你的工具

整合功能讓 Claude 能與程式碼庫以外的服務協同運作.

Chrome用你已登入的瀏覽器工作階段控制瀏覽器, 用於測試網頁應用, 填寫表單, 自動化沒有 API 的網站
GitHub Actions在 CI 流程中執行 Claude, 用於自動化 PR 審查, issue 分流, 排程維護
GitLab CI/CD與 GitHub Actions 相同功能, 適用於 GitLab 上的 CI 驅動自動化
Code Review自動審查每一個 PR, 在人工審查前先抓出錯誤
Slack回應頻道中的 @Claude 提及, 把團隊聊天中的臭蟲回報轉成 pull request
延伸

對於這裡沒有列出的整合, MCP 伺服器與連接器可以連接幾乎任何服務: Linear, Notion, Google Drive, 或你自己的內部 API.

不在終端機前也能工作

Claude Code 提供多種方式讓你在不使用終端機時也能推進工作. 它們的差異在於觸發方式, Claude 在哪裡執行, 以及需要多少設定.
