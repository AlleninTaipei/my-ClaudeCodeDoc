Artifacts

將 Claude Code 工作階段的輸出, 發布成一個私有連結上的即時互動頁面, 方便在組織內分享。

範圍標示 UNIVERSAL 通用概念 TOOL-SPECIFIC Artifacts 專屬

何時該使用 Artifact TOOL-SPECIFIC

當終端機文字不是適合呈現輸出的媒介時, 就該使用 artifact, 也就是那些看一眼比逐行閱讀更容易理解的內容。

帶註解的 PR 走查用有註解的 diff 帶審查者看過整個變更
資料儀表板用工作階段已抓取的資料呈現視覺化儀表板
方案並列比較把數個設計或實作選項並排呈現
調查時間軸在長任務執行期間持續補上內容的調查記錄
分享連結取代貼文字傳一個連結給同事, 而不是把輸出貼進 Slack
Artifact 不是什麼

Artifact 是工作成果的擷取, 不是一個應用程式。它是沒有後端的單一自包含頁面, 因此無法儲存表單輸入, 也無法在檢視當下呼叫 API。若需要有後端的內部工具, 請部署在自己的基礎設施上。

建立 Artifact

Claude 可能會在輸出適合做成頁面時自動發布, 你也可以直接要求。用一般語言描述你想要的視覺輸出即可。

# 範例提示 1
"Make an artifact that walks through this PR with the diff annotated inline."

# 範例提示 2
"Build a dashboard artifact of last week's deploy failures by service and keep it updated as you investigate."
流程

Claude 會把頁面寫成專案中的 HTML 或 Markdown 檔案, 然後發布。發布新 artifact 前, Claude Code 會先請求許可。選擇 Yes 後, Claude 印出網址並自動開啟瀏覽器; 之後可隨時按 Ctrl+] 重新開啟最近的 artifact。設定環境變數 CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0 可停止自動開啟瀏覽器。

更新 Artifact

請 Claude 修改頁面, 或讓長時間執行的任務在有進度時自動重新發布。Claude 會編輯底層檔案, 並發布到同一個網址。

"Add a per-region breakdown below the summary chart and republish."

# 從不同工作階段更新, 需附上 artifact 網址
"Update https://claude.ai/code/artifact/5fbea6f3-... with today's numbers."

每次發布都會成為一個新版本, 你可以在頁面標頭的 Share 控制項中選擇讓檢視者看到哪個版本。沒有附上網址時, 新的工作階段一律會建立新的 artifact, 而不是更新既有的。

分享 Artifact

新的 artifact 預設只有你能看到。用瀏覽器打開它, 並使用頁面標頭的 Share 控制項, 授權給組織內特定成員或所有人。

分享範圍
僅止於你的組織, 沒有對外公開的選項
檢視者要求
必須以同組織成員身分登入 claude.ai
共編權限
僅可檢視, 不可共同編輯, 你是唯一的寫入者
組織外分享
需向 Claude 索取 HTML 檔案並直接分享該檔案

可以建立什麼

Artifact 是單一 HTML 頁面, 只要能用 HTML, CSS 與內嵌 JavaScript 表達的內容都在範圍內。點選下方標籤查看常見用法與範例提示。

用途
走查變更
比較方案
互動調整
帶回工作階段
追蹤進度
走查一項變更

請求一個頁面, 在相關程式碼旁渲染 diff 或設計變更並附上註解, 讓審查者可以直接在程式碼旁閱讀你的推理過程。

"Make an artifact that walks through this PR. Render the diff with margin annotations and color-code findings by severity."
比較方案

把數個變體放在同一頁面上以便互相評估, 適用於版面配置, 文案, API 形狀或實作計畫。

"Make an artifact with four distinctly different layouts for the settings panel. Vary density and grouping, and lay them out as a grid with a one-line tradeoff under each."
用互動控制項微調

請求滑桿, 開關或輸入欄位綁定你想調整的值, 讓你直接嘗試數值而不是用文字描述。

"Build an artifact with sliders for the easing curve, duration, and delay so I can try values on this transition. Show the animation live as I move them."
把結果帶回工作階段

Artifact 可以作為決策的輕量編輯器, 之後再交還給 Claude。請求一個匯出控制項, 產生可貼回終端機的文字。

"Make a triage board artifact with each open issue as a draggable card across Now, Next, Later, and Cut columns. Add a 'Copy as prompt' button that gives me the final ordering to paste back here."
追蹤進行中的工作

請 Claude 在長任務執行期間持續更新 artifact, 讓任何有連結的人不必閱讀終端機也能追蹤進度。

"Turn this migration plan into a checklist artifact. Check items off as you complete them and add a note for anything you skip."

改善視覺設計

Claude 建立 artifact 時會套用內建的設計技能, 讓頁面在沒有額外提示的情況下也具備明確的配色, 字型與版面。它也會優先尋找專案內既有的設計系統。

# CLAUDE.md 中的設計系統範例
## Design system

- Colors: primary #1a4d8f, accent #f59e0b, surface #f8fafc
- Typography: Inter for body, JetBrains Mono for code
- Spacing: 8px scale, 6px border radius
優先順序

Claude 會把你的設計系統看得比它自己的選擇更重要, 而你的提示又比兩者都優先。

頁面限制

每個 artifact 都是一個自包含頁面。Claude Code 會把你發布的檔案包進 HTML 文件外殼, 並以嚴格的內容安全政策 (CSP) 提供服務, 這決定了頁面能做什麼。

無外部請求CSP 封鎖來自其他主機的 script, stylesheet, font, image, 以及 fetch, XHR, WebSocket。CSS 與 JS 需全部內嵌, 圖片以 data URI 嵌入
無後端Artifact 是靜態頁面, 無法儲存表單提交的資料, 也無法在檢視當下驗證身分或呼叫 API
單一頁面相對連結無法解析, 因為沒有其他頁面與它一起部署, 多段落內容需用頁內錨點
來源檔案類型發布的檔案必須是 .html, .htm 或 .md, Markdown 檔會渲染成有樣式的 HTML
渲染後大小渲染後的頁面必須小於等於 16 MiB, 內嵌的大型圖片是發布失敗最常見的原因
降低 Token 成本

圖表優先使用 SVG 或 HTML/CSS 而非嵌入的點陣圖, 省略不需要的互動性, 並讓頁面摘要大型資料集而非完整內嵌。

可用性

Artifacts 需要以下每一項條件都成立, 其中任一項未滿足時, Claude 會改寫一份本機 HTML 檔案, 或直接說明無法發布。

方案
Team 或 Enterprise。Team 預設開啟, Enterprise 需 Owner 在後台啟用
身分驗證
以 /login 登入 claude.ai, API key 或閘道權杖無法發布
模型供應商
僅限 Anthropic API, 不支援 Bedrock, Vertex AI 或 Microsoft Foundry
組織政策
組織未啟用 CMEK, HIPAA 或 Zero Data Retention
使用介面
Claude Code CLI 或 Desktop 1.13576.0 以上, Agent SDK 等情境預設關閉

停用 Artifacts

不論組織設定為何, 都可以用以下任一方式停用自己工作階段中的 artifacts。

設定檔
"disableArtifact": true
環境變數
CLAUDE_CODE_DISABLE_ARTIFACT=1
權限規則
在 permissions.deny 中加入 Artifact

為組織管理 Artifacts

Team 與 Enterprise 方案的 Owner 可以透過 claude.ai 後台管理設定來控制 artifacts。內容儲存在 Anthropic 維運的基礎設施上, 僅發布組織的成員可見。

1 · 啟用停用
2 · 保留政策
3 · 稽核紀錄
4 · 網域允許清單
5 · Compliance API

前往 Settings > Claude Code > Capabilities, 使用 Artifacts 開關。Enterprise 方案若啟用角色權限控制, 還能到 Settings > Roles 針對特定角色設定 Artifacts 權限。

前往 Settings > Data & privacy controls, 可分別設定尚未分享的私有 artifact 與已分享的 artifact 的保留期限。

發布, 分享與刪除 artifact 的動作都會出現在組織的稽核紀錄中, 事件類型為 claude_artifact_*, 與 claude.ai 對話中建立的 artifact 共用同一系列。

claude.ai 上的檢視器會從沙盒化的 *.claudeusercontent.com 來源載入每個 artifact。若組織限制對外網路存取, 需把此網域與 claude.ai 一併加入允許清單。

GET/v1/compliance/code/artifacts
GET/v1/compliance/code/artifacts/{artifact_id}/versions/{version_id}
DELETE/v1/compliance/code/artifacts/{artifact_id}
