法律協議

授權條款

Commercial Terms: 適用於 Team, Enterprise, Claude API 使用者

Consumer Terms of Service: 適用於 Free, Pro, Max 使用者

商業協議

無論直接使用 Claude API (1P) 或透過 Amazon Bedrock, Google Vertex (3P) 存取, 既有商業協議都適用於 Claude Code 使用情境, 除非雙方另有約定。

合規

醫療合規 BAA

若客戶已與 Anthropic 簽署 Business Associate Agreement (BAA), 且啟用了 Zero Data Retention (ZDR), 該 BAA 會自動延伸涵蓋 Claude Code, 適用於透過 Claude Code 流動的該客戶 API 流量。ZDR 是逐組織啟用, 因此每個組織都須各自啟用 ZDR 才能受 BAA 涵蓋。

使用政策

Claude Code 的使用受 Anthropic Usage Policy 規範。Pro 與 Max 方案公告的使用額度, 假設是一般個人使用 Claude Code 與 Agent SDK 的情境。

開發者若建構與 Claude 能力互動的產品或服務 (包含使用 Agent SDK), 應透過 Claude Console 或受支援的雲端供應商使用 API key 驗證。Anthropic 不允許第三方開發者代表其使用者提供 Claude.ai 登入或透過 Free, Pro, Max 方案憑證路由請求。

重點: Anthropic 保留執行這些限制的權利, 且可能不會事先通知。若對使用情境的驗證方式有疑問, 應聯繫業務團隊確認。
