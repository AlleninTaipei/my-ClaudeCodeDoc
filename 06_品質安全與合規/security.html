Claude Code 的核心即以安全性為出發點打造, 依照 Anthropic 完整的安全計畫開發。可於 Anthropic Trust Center 取得 SOC 2 Type 2 報告, ISO 27001 證書等資源。

Claude Code 預設採用嚴格的唯讀權限。需要額外動作 (編輯檔案, 執行測試, 執行指令) 時, 會明確請求權限, 使用者可選擇單次核准或自動允許。執行可能修改系統的 Bash 指令前需要核准, 內建的唯讀指令集 (如 ls, cat, git status) 則不會提示。

沙箱化 Bash 工具
以檔案系統與網路隔離沙箱化 Bash 指令, 減少權限提示同時維持安全性, 用 /sandbox 啟用
寫入存取限制
Claude Code 只能寫入啟動時所在的資料夾及其子資料夾, 無法修改父層目錄的檔案
提示疲勞緩解
支援針對使用者, 程式碼庫或組織允許清單常用安全指令
Accept Edits 模式
自動核准檔案編輯與固定集合的檔案系統 Bash 指令如 mkdir, touch, rm, mv, cp, sed

Claude Code 只擁有你授予的權限。使用者有責任在核准前審查所提出的程式碼與指令是否安全。

防範提示注入 (Prompt Injection)

提示注入是攻擊者試圖插入惡意文字, 藉此覆寫或操縱 AI 助理指令的技術。Claude Code 內建多項防範措施:

選擇防護類別:
核心防護
隱私防護
額外防護
權限系統
敏感操作需要明確核准
情境感知分析
透過分析完整請求偵測潛在有害指令
輸入清理
處理使用者輸入以防止指令注入
網路指令核准
curl, wget 等抓取網路內容的指令預設不會自動核准, 會像其他非唯讀 Bash 指令一樣提示
有限保留期
敏感資訊的保留期限受限, 詳見 Privacy Center
限制存取
限制對使用者 session 資料的存取
訓練偏好控制
消費者使用者可隨時變更隱私設定
網路請求核准
發出網路請求的工具預設需要使用者核准
隔離的 context window
Web fetch 使用獨立的 context window, 避免注入潛在惡意提示
信任驗證
首次執行的程式碼庫與新的 MCP 伺服器需要信任驗證
指令注入偵測
可疑的 bash 指令即使先前已允許, 仍需人工核准
安全憑證儲存
API 金鑰與 token 在 macOS 存於 Keychain, Windows/Linux 以檔案權限保護
Windows WebDAV 安全風險

在 Windows 上執行 Claude Code 時, 建議不要啟用 WebDAV 或允許 Claude Code 存取可能含有 WebDAV 子目錄的路徑如 \\*。啟用 WebDAV 可能讓 Claude Code 觸發對遠端主機的網路請求, 繞過權限系統。

處理不受信任內容的最佳實踐

1
核准前先審查建議的指令
2
避免將不受信任的內容直接傳入 Claude
3
驗證對關鍵檔案的變更提案
4
使用虛擬機執行腳本與工具呼叫, 特別是與外部網路服務互動時
5
使用 /feedback 回報可疑行為

重點: 這些防護大幅降低風險, 但沒有任何系統能完全免於所有攻擊, 使用任何 AI 工具時都應維持良好的安全習慣。

MCP 安全性

MCP

Claude Code 允許使用者設定 Model Context Protocol (MCP) 伺服器, 允許清單是設定在原始碼中, 屬於工程師會檢查進版控的 Claude Code 設定。建議自行撰寫 MCP 伺服器或使用信任供應商提供的伺服器。Anthropic 在將連接器加入 Anthropic Directory 前會依 listing criteria 審查, 但不會對任何 MCP 伺服器進行安全稽核或管理。

雲端執行安全性

使用 Claude Code on the web 時, 會套用以下額外安全控制:

隔離虛擬機
每個雲端 session 都在隔離的, Anthropic 管理的 VM 中執行
網路存取控制
網路存取預設受限, 可設定為停用或僅允許特定網域
憑證保護
驗證透過安全代理處理, 使用範圍受限的憑證, 再轉換為實際的 GitHub 驗證 token
分支限制
Git push 操作限制在目前工作分支
稽核記錄
雲端環境中的所有操作都會記錄, 用於合規與稽核
自動清理
雲端環境在 session 完成後自動終止

Remote Control session 運作方式不同: 網頁介面連接到你本機執行的 Claude Code 行程, 所有程式碼執行與檔案存取都留在本機, 資料透過 TLS 經由 Anthropic API 傳輸, 不涉及雲端 VM 或沙箱, 且使用多組短生命週期, 範圍狹窄的憑證各自獨立過期, 降低單一憑證外洩的影響範圍。
