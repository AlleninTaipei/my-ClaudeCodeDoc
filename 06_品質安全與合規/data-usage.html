訓練政策

資料存取

存取範圍

本機 Claude Code 的資料存取遵循本機資料流; 遠端 (Remote Control) session 因為執行都在你的機器上, 同樣遵循本機資料流。對於遠端 Claude Code, Claude 只能存取你「已啟動 session」的儲存庫, 對於已連接但尚未啟動 session 的儲存庫則不會存取。

本地 Claude Code: 資料流與相依性

Claude Code 在本機執行, 透過網路將所有使用者提示與模型輸出以 TLS 1.2+ 加密傳輸。靜態加密方式則依模型供應商而異:

Anthropic API
基礎架構層級磁碟加密 (AES-256), 可啟用 Zero Data Retention 達成無伺服器端留存
Amazon Bedrock
AES-256, 使用 AWS 管理金鑰; 可透過 AWS KMS 使用客戶自管金鑰
Google Cloud Vertex AI
Google 管理加密金鑰; 支援 CMEK
Microsoft Foundry
請求路由至 Anthropic 基礎架構, 採 AES-256 磁碟加密

DISABLE_TELEMETRY

第三方供應商 fallback
使用 Bedrock, Vertex 或無 Anthropic 憑證時, /feedback 改寫入本機 ~/.claude/feedback-bundles/ 封存檔

WebFetch 網域安全檢查

抓取網址前, WebFetch 工具會將主機名稱送至 api.anthropic.com 比對安全封鎖清單, 只送出主機名稱, 不含完整網址, 路徑或頁面內容, 結果依主機名稱快取 5 分鐘。此檢查不受供應商影響, 也不受 CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC 影響; 可用 settings 中的 skipWebFetchPreflight: true 停用。

重點: 只有 Session 品質調查與 WebFetch 安全檢查在所有供應商都預設開啟, 其餘遙測與回報項目在第三方雲端供應商上都預設關閉, 須手動設定對應環境變數才會啟用。
