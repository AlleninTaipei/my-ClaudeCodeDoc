Claude Code 搭配 GitHub Enterprise Server

把 Claude Code 連接到你自架的 GitHub Enterprise Server, 支援網頁 session, 程式碼審查與外掛市集

GHES 支援哪些功能

功能支援備註
Claude Code on the web支援Owner 連接一次, 開發者用 --remote 或 claude.ai/code
Code Review支援與 github.com 相同的自動 PR 審查
Claude Security支援Enterprise 方案的公開 beta
Teleport sessions支援用 --teleport 在網頁與終端機間搬移 session
Plugin marketplaces支援使用完整 git URL 而非 owner/repo 簡寫
GitHub Actions支援需手動設定 workflow, /install-github-app 僅限 github.com
GitHub MCP server不支援不適用於 GHES 實例

管理員設定流程

Owner 只需連接一次 GHES 實例, 之後開發者無需額外設定即可使用。

1 · 開啟設定
2 · 開始引導設定
3 · 建立 GitHub App
4 · 安裝到儲存庫
5 · 啟用功能

前往 claude.ai/admin-settings/claude-code, 找到 GitHub Enterprise Server 區塊。

點擊 Connect, 輸入顯示名稱與 GHES 主機名 (例如 github.example.com)。若使用自簽憑證, 貼上 CA 憑證。

點擊 Continue to GitHub Enterprise, 瀏覽器會導向 GHES 實例並帶入預填的 app manifest, 確認後點擊 Create GitHub App。

從 GitHub App 頁面把 App 安裝到想要的儲存庫或組織, 可先從一部分開始, 之後再加入更多。

回到 admin-settings 頁面, 用與 github.com 相同的方式啟用 Code Review, Claude Security, 與 contribution metrics。

步驟 1 / 5
網路需求

GHES 實例必須能被 Anthropic 基礎設施存取; 若在防火牆後, 需將 Anthropic API IP 位址加入白名單。

GitHub App 權限

Contents讀寫, 用於 clone 儲存庫與推送分支
Pull requests讀寫, 用於建立 PR 與發表審查留言
Issues讀寫, 用於回應 issue 提及
Checks讀寫, 用於發布 Code Review check runs
Actions唯讀, 用於讀取 CI 狀態以自動修正
Repository hooks讀寫, 用於接收 contribution metrics 的 webhook

開發者工作流程

Owner 完成連接後, 開發者不需要任何額外設定。Claude Code 會自動從工作目錄的 git remote 偵測 GHES 主機名。

git clone git@github.example.com:platform/api-service.git
cd api-service
claude --remote "Add retry logic to the payment webhook handler"

Session 執行於 Anthropic 基礎設施, 從 GHES clone 儲存庫並推送變更回分支。用 /tasks 或 claude.ai/code 監控進度。

Teleport

用 claude --teleport 把網頁 session 拉回本機終端機; 會先確認你位於相同 GHES 儲存庫的 checkout 中。

GHES 上的外掛市集

owner/repo 簡寫只會解析成 github.com, GHES 市集需使用完整 git URL。

/plugin marketplace add git@github.example.com:platform/claude-plugins.git

在受控設定中, 用 hostPattern 來源類型允許整個 GHES 主機名下的所有市集, 不需逐一列舉。

{
  "strictKnownMarketplaces": [
    {
      "source": "hostPattern",
      "hostPattern": "^github\\.example\\.com$"
    }
  ]
}

限制與疑難排解

/install-github-app不適用於 GHES, 改用管理員設定流程
GitHub MCP server不支援, 改用設定好 GHES host 的 gh CLI
Clone 失敗確認 Owner 已完成設定且 App 已安裝到該儲存庫
市集新增被政策擋下請管理員在受控設定加入 hostPattern 項目

大多數 GHES 疑難排解都指向同一個核對點: Owner 是否已完成連接設定, 以及 App 是否已安裝在正確的儲存庫上。
