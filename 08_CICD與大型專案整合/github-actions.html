Claude Code GitHub Actions

把 AI 驅動的自動化帶進你的 GitHub workflow, 只要在 PR 或 issue 中提及 @claude

為什麼使用 Claude Code GitHub Actions

Instant PR creation
描述需求, Claude 建立完整包含所有變更的 PR
Automated implementation
一個指令把 issue 轉成可運作的程式碼
Follows your standards
遵循 CLAUDE.md 準則與既有程式碼模式
Secure by default
程式碼留在 GitHub 的執行環境中
基礎

此 Action 建構於 Claude Agent SDK 之上, 你也可以用 SDK 打造超越 GitHub Actions 的自訂自動化工作流程。

設定方式

1 · 快速設定
2 · 手動設定
3 · 測試

在 Claude Code 終端機執行 /install-github-app, 互動式安裝 Claude GitHub App 並引導加入 workflow 與 API key secret。

需求

需要是儲存庫管理員; App 會請求 Contents, Issues, Pull requests 的讀寫權限; 此方式僅適用直接使用 Claude API 的使用者。

若 /install-github-app 失敗或偏好手動設定:

1. 安裝 Appgithub.com/apps/claude, 需要 Contents/Issues/PR 讀寫權限
2. 加入密鑰將 ANTHROPIC_API_KEY 加入儲存庫 secrets
3. 複製 workflow從 examples/claude.yml 複製到 .github/workflows/

使用情境範例

選擇範例: 基本 workflow 使用 skills 排程自動化 
on:
  issue_comment:
    types: [created]
jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
with:
  anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
  plugin_marketplaces: "https://github.com/anthropics/claude-code.git"
  plugins: "code-review@claude-code-plugins"
  prompt: "/code-review:code-review ${{ github.repository }}/pull/${{ github.event.pull_request.number }}"
on:
  schedule:
    - cron: "0 9 * * *"
jobs:
  report:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          prompt: "Generate a summary of yesterday's commits and open issues"

啟用 Vertex AI 相關 API

建立僅有 Vertex AI User 角色的服務帳號

建議

建議建立自己的 GitHub App 以取得更好的控制與安全性, 而非使用官方 Anthropic App。

成本與最佳實踐

CLAUDE.md定義程式碼風格, 審查標準與專案規則, 讓 Claude 遵循
Secrets永遠使用 GitHub Secrets, 絕不硬編碼 API key
GitHub Actions 成本消耗你的 GitHub Actions 分鐘數
API 成本依提示詞與回應長度消耗 token, 依任務複雜度與程式碼庫大小而異

用具體的 @claude 指令減少不必要呼叫, 設定 --max-turns 上限, 並設定 workflow 層級的 timeout 避免失控任務。
