全部指令

下表列出 Claude Code 內含的代表性指令; 標示 Skill 的是 bundled skill, 標示 Workflow 的是可在雲端分派多個 subagent 的動態工作流程。點選分類篩選。

分類: Session 與 context 模型與效能 代理人與平行工作 審查與 PR 外掛與設定 其他
/clear [name]以空 context 開始新對話, 別名 /reset, /new
/compact [instructions]摘要壓縮目前對話, 可加上聚焦說明
/context [all]以色塊方格視覺化目前 context 用量
/resume [session]依 ID 或名稱恢復對話, 或開啟選擇器
/branch [name]建立目前對話的分支
/rewind倒回對話或程式碼到先前的檢查點
/export [filename]將對話匯出為純文字
/model [model]切換模型並設為預設值
/effort [level|auto]設定推理努力等級, 支援 ultracode
/fast [on|off]切換 fast mode
/usage顯示 session 花費, 方案用量與活動統計
/cost, /stats/usage 的別名
/agents管理 agent 設定
/batch <instruction>Skill. 將大規模變更拆解為 5 到 30 個獨立單元平行執行
/background [prompt]將目前 session 分離為背景代理人, 別名 /bg
/fork <directive>產生繼承完整對話的背景 subagent
/tasks檢視並管理背景執行的一切, 也可用 /bashes
/goal [condition|clear]設定目標, Claude 會持續工作直到條件達成
/code-review [level] [--fix] [--comment]Skill. 審查目前 diff 的正確性錯誤與清理機會
/simplify [target]Skill. 四個審查 agent 平行檢查重用性, 簡化, 效率與抽象層級
/review [PR]依編號審查 GitHub PR, 使用與 /code-review 相同引擎
/security-review分析目前分支的待處理變更是否有安全漏洞
/ultrareview [PR]在雲端沙箱執行深入的多代理人程式碼審查
/diff開啟互動式 diff 檢視器
/plugin [subcommand]管理 Claude Code 外掛
/mcp [...]管理 MCP 伺服器連線與 OAuth 驗證
/config [key=value ...]開啟設定介面, 也可直接指定 key=value
/permissions管理 allow, ask, deny 規則, 別名 /allowed-tools
/hooks檢視工具事件的 hook 設定
/theme變更色彩主題
/deep-research <question>Workflow. 展開網路搜尋並綜合出附引用的報告
/runSkill. 啟動並驅動專案應用程式以實際觀察變更效果
/verifySkill. 透過實際建置與執行確認變更符合預期
/schedule [description]建立, 更新, 列出或執行 routines
/insights分析 session 產生互動模式與摩擦點報告
/doctor診斷並驗證安裝與設定
說明

並非每個使用者都會看到所有內建指令, 是否顯示取決於平台, 方案與環境, 例如 /desktop 僅在 macOS 與 Windows 且已登入 Claude 訂閱時顯示。

MCP 提示

MCP Prompts

MCP 伺服器可以公開以指令形式呈現的提示, 格式為 /mcp__<server>__<prompt>, 並從已連線的伺服器動態探索。
