Customize your status line

Configure a custom status bar to monitor context window usage, costs, and git status in Claude Code.

Set up a status line

The status line is a customizable bar at the bottom of Claude Code that runs any shell script you configure. It receives JSON session data on stdin and displays whatever your script prints.

Method:
/statusline command
Manual settings.json
/statusline show model name and context percentage with a progress bar

Claude Code generates a script file in ~/.claude/ and updates your settings automatically.

{
  "statusLine": {
    "type": "command",
    "command": "~/.claude/statusline.sh",
    "padding": 2
  }
}
padding
Extra horizontal spacing in characters, default 0
refreshInterval
Re-runs the command every N seconds, minimum 1
hideVimModeIndicator
Suppresses the built-in -- INSERT -- text
DISABLE

Run /statusline and ask it to remove or clear your status line, or manually delete the statusLine field from settings.json.

Build a status line step by step

This walkthrough shows what's happening under the hood by manually creating a status line that displays the current model, working directory, and context window usage percentage.

1 · Write script
2 · Make executable
3 · Add to settings
#!/bin/bash
# Read JSON data that Claude Code sends to stdin
input=$(cat)

MODEL=$(echo "$input" | jq -r '.model.display_name')
DIR=$(echo "$input" | jq -r '.workspace.current_dir')
PCT=$(echo "$input" | jq -r '.context_window.used_percentage // 0' | cut -d. -f1)

echo "[$MODEL] 📁 ${DIR##*/} | ${PCT}% context"

Save to ~/.claude/statusline.sh.

chmod +x ~/.claude/statusline.sh
{
  "statusLine": {
    "type": "command",
    "command": "~/.claude/statusline.sh"
  }
}

Settings reload automatically, but changes won't appear until your next interaction.

How status lines work

Claude Code runs your script and pipes JSON session data to it via stdin. Your script reads the JSON, extracts what it needs, and prints text to stdout.

Trigger eventsAfter each new assistant message, /compact finishing, permission mode change, vim toggle
Debounce300ms, rapid changes batch together
Multiple linesEach echo/print statement displays as a separate row
ColorsANSI escape codes like \033[32m for green
LinksOSC 8 escape sequences for clickable text
NOTE

Claude Code captures your script's output, so tput cols cannot read terminal size. Read the COLUMNS and LINES environment variables instead (v2.1.153+). The status line runs locally and does not consume API tokens.

Available data

Claude Code sends a JSON object to your script via stdin. Key fields:

model.display_name
Current model display name
workspace.current_dir
Current working directory
cost.total_cost_usd
Estimated session cost in USD
cost.total_duration_ms
Wall-clock time since session started
context_window.used_percentage
Pre-calculated context window usage
effort.level
Current reasoning effort level
rate_limits.five_hour.used_percentage
5-hour rate limit consumed, Pro/Max only
pr.number, pr.url
Open pull request for the current branch
vim.mode
NORMAL, INSERT, VISUAL, or VISUAL LINE
session_id
Unique session identifier, stable across invocations
May be absent
session_name, prompt_id, workspace.git_worktree, effort, vim, agent, pr, worktree, rate_limits
May be null
context_window.current_usage before first API call or right after /compact

Context window fields

used_percentage is calculated from input tokens only: input_tokens + cache_creation_input_tokens + cache_read_input_tokens, not including output tokens.

Examples

Common status line patterns, all reading JSON from stdin via jq.

PCT=$(echo "$input" | jq -r '.context_window.used_percentage // 0' | cut -d. -f1)
BAR_WIDTH=10
FILLED=$((PCT * BAR_WIDTH / 100))
# build bar from filled ▓ and empty ░ blocks
echo "[$MODEL] $BAR $PCT%"
GREEN='\033[32m'; YELLOW='\033[33m'; RESET='\033[0m'
STAGED=$(git diff --cached --numstat | wc -l)
MODIFIED=$(git diff --numstat | wc -l)
echo -e "[$MODEL] 🌿 $BRANCH ${GREEN}+${STAGED}${RESET}${YELLOW}~${MODIFIED}${RESET}"
COST=$(echo "$input" | jq -r '.cost.total_cost_usd // 0')
DURATION_MS=$(echo "$input" | jq -r '.cost.total_duration_ms // 0')
echo "[$MODEL] 💰 $COST_FMT | ⏱️ ${MINS}m ${SECS}s"
# each echo prints a separate row
echo -e "${CYAN}[$MODEL]${RESET} 📁 ${DIR##*/}$BRANCH"
echo -e "${BAR_COLOR}${BAR}${RESET} ${PCT}% | ${YELLOW}${COST_FMT}${RESET}"

Threshold-based colors: green under 70%, yellow 70-89%, red 90%+.

REMOTE=$(git remote get-url origin | sed 's/git@github.com:/https:\/\/github.com\//')
# OSC 8 format: \e]8;;URL\a then TEXT then \e]8;;\a
printf '%b' "[$MODEL] 🔗 \e]8;;${REMOTE}\a${REPO_NAME}\e]8;;\a\n"
FIVE_H=$(echo "$input" | jq -r '.rate_limits.five_hour.used_percentage // empty')
WEEK=$(echo "$input" | jq -r '.rate_limits.seven_day.used_percentage // empty')
echo "[$MODEL] | 5h: $FIVE_H% 7d: $WEEK%"

CACHING

git status or git diff can be slow. Cache git info to a temp file keyed by session_id, and only refresh every 5 seconds. Use session_id, not process PID, since the PID changes on every invocation.

Subagent status lines

The subagentStatusLine setting renders a custom row body for each subagent shown in the agent panel below the prompt.

{
  "subagentStatusLine": {
    "type": "command",
    "command": "~/.claude/subagent-statusline.sh"
  }
}

The command runs once per refresh tick with all visible subagent rows passed as JSON on stdin. Write one JSON line per row to override: {"id": "<task id>", "content": "<row body>"}.

Tips

Test with mock input piped directly to your script. Keep output short since the status bar has limited width. Cache slow operations like git status, since your script runs frequently during active sessions. Community projects like ccstatusline and starship-claude provide pre-built configurations.

Troubleshooting

Symptom:
Not appearing
Shows -- or empty
Links not clickable
Workspace trust

Verify the script is executable with chmod +x, outputs to stdout not stderr, and run claude --debug to log the exit code and stderr from the first invocation.

Fields may be null before the first API response completes. Handle null values with fallbacks such as // 0 in jq, and restart Claude Code if values remain empty.

Verify your terminal supports OSC 8 hyperlinks (iTerm2, Kitty, WezTerm). Terminal.app does not. Set FORCE_HYPERLINK=1 to override detection.

The status line command only runs after you've accepted the workspace trust dialog for the current directory. If not accepted, you'll see "statusline skipped · restart to fix".
