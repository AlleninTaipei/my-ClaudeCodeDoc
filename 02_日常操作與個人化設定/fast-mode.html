Fast Mode

用更高費率換取更快的 Opus 回應速度研究預覽

切換 Fast Mode

Fast mode 是 Claude Opus 的高速設定, 讓模型最高快 2.5 倍, 但每個 token 的費用較高。它不是不同的模型, 而是用不同的 API 設定, 優先考慮速度而非成本效率, 品質與能力完全相同。

支援模型: Opus 4.8 Opus 4.7 (即將淘汰)
/fast輸入並按 Tab 切換開關
setting在使用者設定檔設定 "fastMode": true
啟用時會發生

若目前在不同模型, Claude Code 會自動切換到 Opus; 出現 "Fast mode ON" 確認訊息; 提示旁出現小圖示; 再次執行 /fast 可檢查目前狀態。停用後仍停留在 Opus, 不會回到先前的模型。

已淘汰

Opus 4.7 的 fast mode 已於 2026 年 6 月 25 日淘汰, 將於 2026 年 7 月 24 日移除, 屆時該模型的 fast mode 請求會回傳錯誤且不會退回標準版本, 建議遷移至 Opus 4.8。

理解成本取捨

Fast mode 每個 token 的定價高於標準 Opus, 倍率依模型而異, 且定價在完整 1M token context window 中維持一致。

Opus 4.8
輸入 $10 / MTok, 輸出 $50 / MTok
Opus 4.7
輸入 $30 / MTok, 輸出 $150 / MTok
第一次開啟的成本

在對話中第一次啟用 fast mode, 需為整段對話 context 支付完整未快取的 fast mode 輸入價格。對話進行得越深, 開啟成本越高, 因此從一開始就啟用最省錢。此成本每個對話只收一次, 之後再切換開關不會重複收費。

Fast Mode 對比 Effort Level

Fast mode
模型品質相同, 延遲較低, 成本較高
較低 effort level
思考時間較少, 回應較快, 複雜任務品質可能下降

兩者可以合併使用: 搭配較低的 effort level 使用 fast mode, 在簡單任務上達到最高速度。

使用需求

Fast mode 需要滿足以下所有條件:

帳號僅限 Anthropic API 或訂閱方案, 不支援 Bedrock, Vertex AI, Azure Foundry 或 Claude Platform on AWS
用量額度帳號須開啟 usage credits, 個人帳號於 Console 帳單設定開啟, Team/Enterprise 需管理員開啟
組織啟用Team 與 Enterprise 預設停用, 須由 Owner 明確啟用後使用者才能開啟

為組織啟用 Fast Mode

Console (API 客戶)
管理員於 Claude Code preferences 啟用
Claude AI (Team/Enterprise)
Owner 於 Admin Settings > Claude Code 啟用
每 Session 選擇加入

預設 fast mode 會跨 session 保留。管理員可在 Team 或 Enterprise 方案設定 fastModePerSessionOptIn 為 true, 讓每個 session 都以關閉狀態開始, 需使用者以 /fast 明確開啟。

處理速率限制

Fast mode 有獨立的速率限制, Opus 4.8 與 4.7 共用同一個限制池。當達到限制或用量額度用盡時:

1Fast mode 自動退回標準速度
2圖示轉為灰色表示冷卻中
3以標準速度與價格繼續工作
4冷卻結束後 fast mode 自動重新啟用
