管理 Session

命名, 恢復, 分支, 切換 Claude Code 對話, 涵蓋 --continue, --resume, /resume, session 命名, 匯出逐字稿與儲存位置

恢復 Session

Session 會持續儲存到本機逐字稿檔案, 因此離開或執行 /clear 後都能回到原本的對話。

claude --continue
恢復目前目錄中最近的 session
claude --resume
開啟 session 選擇器
claude --resume <name>
直接恢復指定名稱的 session
claude --from-pr <number>
恢復與該 PR 連結的 session
/resume
在 session 中切換到另一個對話
注意

用 claude -p 或 Agent SDK 建立的 session 不會出現在 session 選擇器中, 但仍可用 claude --resume <session-id> 恢復, 且必須在建立 session 的目錄中執行, 因為 session ID 查找範圍限定在目前專案目錄與其 git worktrees。

Session 選擇器的搜尋範圍

Session 依專案目錄儲存。預設 session 選擇器顯示目前 worktree 的互動式 session, 加上以 /add-dir 加入目前目錄的其他 session。

Ctrl+W
擴大顯示範圍到儲存庫的所有 worktrees
Ctrl+A
擴大顯示範圍到這台機器上的所有專案

為 Session 命名

為 session 取有意義的名稱, 讓它在 session 選擇器中容易尋找, 也能用名稱恢復, 在並行處理多個任務時特別重要。

啟動時claude -n auth-refactor
Session 進行中/rename auth-refactor, 名稱也會顯示在提示欄
從 session 選擇器反白 session 後按 Ctrl+R
計畫核准時在 plan 模式核准計畫會依計畫內容自動命名 session

從未命名的互動式 session 啟動時仍會取得預設顯示名稱 (工作目錄名稱加兩碼後綴, 例如 my-app-3f), 但預設名稱不是恢復代號, 只有你自己設定的名稱才能用來恢復。

使用 Session 選擇器

在 session 中執行 /resume, 或不帶參數執行 claude --resume, 開啟互動式 session 選擇器。

Enter恢復反白的 session
Space / Ctrl+V預覽 session 內容
Ctrl+R重新命名反白的 session
/ 或任意可列印字元進入搜尋模式篩選 session, 也可貼上 PR/MR 網址找出建立它的 session
Ctrl+A顯示這台機器上所有專案的 session
Ctrl+W顯示目前儲存庫所有 worktrees 的 session
Ctrl+B篩選出目前 git 分支的 session
Esc離開選擇器或搜尋模式

用 /branch, /rewind, 或 --fork-session 建立的分支 session 會分組顯示在根 session 之下。

分支一個 Session

分支會複製目前為止的對話並切換進去, 保留原本的對話不受影響, 用來在不失去原本路徑的情況下嘗試不同做法。

1 · 在 Session 中分支
2 · 從命令列分支
/branch try-streaming-approach

分支確認訊息會印出兩個 session ID: 你現在所在的新分支, 以及原本的 session。

claude --continue --fork-session

原本的 session 不受影響, 仍在 session 選擇器中可用。

Step 1 of 2
注意

用「本 session 允許」核准的權限不會帶入新分支。若在兩個終端機不用分支恢復同一個 session, 兩邊的訊息會交錯進同一份逐字稿。單一 session 內的倒轉請改用 Checkpointing。

管理 Session 中的上下文

不離開 session 就能控制上下文視窗內容的指令:

/clear以空白上下文重新開始, 先前對話已儲存可恢復
/compact [instructions]用摘要取代歷史紀錄, 可選擇聚焦於指定內容
/context顯示目前消耗上下文的內容

匯出與定位 Session 資料

執行 /export 開啟選單, 可將目前對話複製到剪貼簿, 或存成純文字檔, 訊息與工具輸出都會轉為可讀文字。傳入檔名可跳過選單直接寫入該檔案。

從腳本存取對話

/export 產出給人閱讀的逐字稿。下方介面則產出給腳本解析的結構化資料, 依觸發腳本的方式挑選:

claude -p --resume <session-id> --output-format json "summarize what we changed" | jq -r '.result'

逐字稿儲存位置

預設情況下, 逐字稿以 JSONL 格式儲存於 ~/.claude/projects/<project>/<session-id>.jsonl, 每一行是一則訊息, 工具使用, 或中繼資料的 JSON 物件。此格式為內部格式, 版本間可能變動, 直接解析的腳本可能因任何版本更新而失效。

CLAUDE_CONFIG_DIR
將儲存位置移出 ~/.claude
cleanupPeriodDays
變更 30 天的保留期限
CLAUDE_CODE_SKIP_PROMPT_HISTORY
在所有模式下停止寫入逐字稿
--no-session-persistence
單次非互動執行時停止寫入
