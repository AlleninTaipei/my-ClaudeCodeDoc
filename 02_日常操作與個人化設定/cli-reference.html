CLI Reference

Claude Code 命令列介面的完整參考: 指令與旗標的互動導覽

CLI 指令

以下指令用來啟動 session, 管理背景代理人, 設定驗證, 以及進行維運操作。點選分類篩選對應指令。

分類: Session 啟動與續接 驗證 背景代理人 MCP / 外掛 其他維運
claude啟動互動式 session
claude "query"帶初始提示啟動互動式 session
claude -p "query"透過 SDK 查詢後結束, 適合腳本呼叫
cat file | claude -p "query"處理管線輸入的內容
claude -c在目前目錄中繼續最近一次對話
claude -r "<session>" "query"依 ID 或名稱恢復指定 session
claude update更新至最新版本
claude install [version]安裝或重新安裝原生執行檔, 可指定版本, stable 或 latest
claude auth login登入 Anthropic 帳號, 支援 --email, --sso, --console
claude auth logout登出 Anthropic 帳號
claude auth status以 JSON 顯示驗證狀態, 加 --text 可讀輸出
claude setup-token產生長效 OAuth token, 供 CI 與腳本使用
claude agents開啟 agent view 監控並派送背景 session
claude attach <id>在此終端機附加至背景 session
claude respawn <id>重啟背景 session, 對話內容保留
claude rm <id>從清單移除背景 session, 對話紀錄仍保留在本機
claude stop <id>停止背景 session, 也可用 claude kill
claude daemon status列印背景 session 監督程序狀態
claude daemon stop --any停止監督程序與其托管的 session
claude mcp設定 Model Context Protocol 伺服器
claude mcp login <name>執行已設定 MCP 伺服器的 OAuth 流程
claude mcp logout <name>清除已儲存的 MCP OAuth 憑證
claude plugin管理 Claude Code 外掛, 別名 claude plugins
claude gateway啟動自架 Claude apps gateway 伺服器
claude auto-mode defaults列印內建 auto mode 分類規則 JSON
claude logs <id>列印背景 session 最近輸出
claude project purge [path]刪除專案的本機狀態: 逐字稿, 任務清單, 除錯紀錄等
claude remote-control啟動 Remote Control 伺服器, 從 claude.ai 或 Claude app 控制
claude ultrareview [target]以非互動方式執行 ultrareview
提示

若打錯子指令, Claude Code 會建議最接近的指令並結束執行, 例如 claude udpate 會印出 "Did you mean claude update?"。

CLI 旗標

旗標可自訂 Claude Code 的行為。claude --help 不會列出所有旗標, 未出現在 --help 中不代表不可用。

分類: 模型與效能 權限與工具 輸入輸出 MCP 與外掛 進階與除錯
--model
設定 session 使用的模型, 接受別名如 sonnet, opus, haiku, fable
--effort
設定推理努力等級: low, medium, high, xhigh, max
--fallback-model
主模型過載或無法使用時自動切換的備援模型清單
--agent
為目前 session 指定一個 agent, 覆寫 agent 設定
--max-turns
限制代理式回合數, 僅限 print mode
--max-budget-usd
在花費達到指定金額前停止, 僅限 print mode
--permission-mode
以指定模式啟動: default, acceptEdits, plan, auto, dontAsk, bypassPermissions
--allowedTools
列出不經確認即可執行的工具
--disallowedTools
拒絕規則, 可移除或限制特定工具呼叫
--dangerously-skip-permissions
跳過權限提示, 等同 --permission-mode bypassPermissions
--tools
限制可用的內建工具集合
--add-dir
新增額外可讀寫的工作目錄
--print, -p
以非互動方式印出回應
--output-format
print mode 輸出格式: text, json, stream-json
--input-format
print mode 輸入格式: text, stream-json
--include-partial-messages
輸出中包含部分串流事件, 需搭配 --print 與 stream-json
--verbose
顯示完整逐回合輸出
--json-schema
依 JSON Schema 取得結構化輸出, 僅限 print mode
--mcp-config
從 JSON 檔案或字串載入 MCP 伺服器
--strict-mcp-config
只使用 --mcp-config 指定的伺服器, 忽略其他設定
--plugin-dir
從目錄或 .zip 載入外掛, 僅限本次 session
--plugin-url
從 URL 抓取外掛壓縮檔, 僅限本次 session
--debug
啟用除錯模式, 可用類別篩選, 例如 "api,hooks"
--bare
最小模式: 跳過 hooks, skills, plugins, MCP 等自動探索, 啟動更快
--safe-mode
停用所有自訂項目以排除設定問題
--session-id
使用指定的 session ID, 須為合法 UUID
--worktree, -w
在獨立 git worktree 中啟動 Claude
--fork-session
恢復時建立新 session ID 而非沿用原本的

系統提示旗標

Claude Code 提供四種旗標來自訂系統提示, 在互動與非互動模式下皆可使用。

附加型 (Append)

--append-system-prompt: 附加自訂文字到預設提示尾端

--append-system-prompt-file: 從檔案附加文字

保留預設的工具指引, 安全指示與程式撰寫慣例, 適合仍是程式助理但需要額外規則的情境。

替換型 (Replace)

--system-prompt: 完全取代預設系統提示

--system-prompt-file: 以檔案內容取代

會捨棄預設提示的所有內容, 包括工具指引與安全指示, 適合身分或權限模型與 Claude Code 不同的情境。

--system-prompt 與 --system-prompt-file 互斥; 附加旗標可與任一替換旗標搭配使用。
