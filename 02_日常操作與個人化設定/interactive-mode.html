鍵盤快捷鍵

鍵盤快捷鍵可能因平台與終端機而異。點選分類查看對應快捷鍵。

分類: 一般控制 文字編輯 多行輸入 快速指令 逐字稿檢視器 語音輸入

Ctrl+O切換逐字稿檢視器, 顯示詳細工具使用與執行

Esc中斷 Claude 目前的回應或工具呼叫

Shift+Tab循環切換權限模式

Alt+Y貼上後循環貼上歷史

\ + Enter快速跳脫, 適用所有終端機
Option+EntermacOS 啟用 Option as Meta 後可用
Shift+EnteriTerm2, WezTerm, Ghostty, Kitty, Warp 等原生支援

直接貼上適合貼上程式碼區塊或日誌

指令歷史

Claude Code 為目前 session 維護指令歷史, 依工作目錄儲存, 執行 /clear 後歷史會重置。

用 Ctrl+R 反向搜尋

1按 Ctrl+R 啟動反向歷史搜尋
2輸入查詢文字, 符合處會反白
3再按 Ctrl+R 循環瀏覽較舊的符合項
4按 Ctrl+S 切換範圍: session, 專案, 全部
5Tab 或 Esc 接受並繼續編輯, Enter 直接接受並執行

背景 Bash 指令

運作方式

Claude Code 會非同步執行指令, 立即回傳背景任務 ID

輸出寫入檔案, Claude 可用 Read 工具取得

輸出超過 5GB 會自動終止任務

Shell 模式 (! 前綴)

直接執行指令而不經 Claude 判斷或核准

將指令與輸出加入對話 context

支援基於歷史的自動完成, 輸入部分指令按 Tab 補全

說明

v2.1.186 起, Shell 模式指令的輸出送達逐字稿後 Claude 會自動回應, 例如執行 ! npm test 後可直接取得失敗原因說明, 無需再送出第二個提示。

提示語建議

說明

第一次開啟 session 時, 輸入框會顯示灰色範例指令, 依專案 git 歷史挑選。Claude 回應後, 建議會依對話歷史持續出現。按 Tab 或右方向鍵套用建議, 開始輸入即可略過。

重用快取建議以背景請求執行, 重用父對話的 prompt cache, 額外成本很低
跳過條件Cache 未預熱時跳過建議產生, 對話第一回合後與 plan mode 中自動略過

用 /btw 提出側問

用 /btw 快速詢問目前工作相關問題, 不會加入對話歷史。

/btw what was the name of that config file again?
Space / Enter / Escape
關閉答案並回到提示
Up / Down
捲動答案內容
c
將答案以 Markdown 複製到剪貼簿
f
分岔成新 session, 繼承完整對話並保有完整工具存取權

/btw 是 subagent 的反面: 它能看見完整對話但沒有工具, subagent 有完整工具但從空 context 開始。

任務清單

說明

處理複雜多步驟工作時, Claude 會建立任務清單追蹤進度, 顯示在終端機狀態區。按 Ctrl+T 切換任務清單檢視, 最多顯示 5 個任務。任務在 context 壓縮後仍會保留。

Session 回顧

說明

離開終端機一段時間後回來, Claude Code 會顯示一行摘要說明 session 目前的進度。摘要在最後一次完成的回合後至少三分鐘且終端機失去焦點時於背景產生。執行 /recap 可隨時手動產生摘要。
