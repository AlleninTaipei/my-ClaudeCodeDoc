Fullscreen Rendering

更流暢, 不閃爍的渲染模式, 支援滑鼠並在長對話中維持穩定記憶體用量

啟用 Fullscreen Rendering

在任何 Claude Code 對話中執行 /tui fullscreen。CLI 會儲存 tui 設定並重新啟動進入 fullscreen, 對話內容保留, 因此可在 session 中途切換而不遺失 context。

CLAUDE_CODE_NO_FLICKER=1 claude
說明

執行 /tui default 切回傳統渲染器, 或執行 /tui (不帶參數) 印出目前使用的渲染器。此模式需要 Claude Code v2.1.89 以上版本。

改變了什麼

Fullscreen rendering 改變 CLI 繪製到終端機的方式。輸入框固定在畫面底部, 只有可見訊息會保留在渲染樹中, 因此記憶體用量不受對話長度影響。

Cmd+f 或 tmux 搜尋文字
改用 Ctrl+o 進入逐字稿模式, 再用 / 搜尋或 [ 寫回 scrollback
終端機原生拖曳選取複製
改用內建選取, 放開滑鼠即自動複製
Cmd 點擊開啟 URL
macOS 用 Cmd, 其他平台用 Ctrl 點擊

使用滑鼠

點擊輸入框將游標定位到輸入文字的任意位置
點擊建議項目在 / 或 @ 清單中接受該項目, 滑鼠懸停會高亮列
點擊選單選項選擇權限提示, /model, /config 等對話框中的選項
點擊收合的工具結果展開查看完整輸出, 再點一次收合
Cmd/Ctrl + 點擊開啟 URL 或檔案路徑, 檔案在預設應用程式開啟
點擊拖曳在對話中選取文字, 雙擊選字, 三擊選整行
滾輪在對話中上下移動
複製

選取的文字會在放開滑鼠時自動複製到剪貼簿。若關閉此行為, 可用 Ctrl+Shift+c 手動複製, 支援 kitty 鍵盤協定的終端機也可用 Cmd+c。

捲動對話

PgUp / PgDn以半個畫面為單位上下捲動
Ctrl+Home跳到對話開頭
Ctrl+End跳到最新訊息並重新啟用自動跟隨
滑鼠滾輪每次捲動數行

自動跟隨 (Auto-follow)

說明

向上捲動會暫停自動跟隨, 避免新輸出把畫面拉回底部。按 Ctrl+End 或捲到底部即可恢復。要完全關閉自動跟隨, 到 /config 將 Auto-scroll 設為 off。

滑鼠滾輪捲動速度

說明

設定 CLAUDE_CODE_SCROLL_SPEED 環境變數可調整捲動距離倍率, 數值 3 符合 vim 等應用程式的預設值, 支援 1 到 20 之間或小於 1 的小數。也可執行 /scroll-speed 互動式調整。

JetBrains IDE 終端機中的捲動

說明

在 JetBrains IDE 終端機中, Claude Code 會套用自己的捲動處理並忽略 CLAUDE_CODE_SCROLL_SPEED, 因為該終端機送出捲動事件的頻率遠高於其他模擬器。建議升級到 2025.3 以上版本以獲得最佳捲動體驗。

搜尋與檢閱對話

Ctrl+o 在一般提示與逐字稿模式之間切換。逐字稿模式提供 less 風格的導覽與搜尋:

/開啟搜尋, 輸入以尋找符合項目, Enter 接受, Esc 取消
n / N跳到下一個或上一個符合項目
j / k捲動一行
g / G跳到頂端或底部
[將完整對話寫入終端機原生 scrollback, 供 Cmd+f 等原生工具搜尋
v將對話寫入暫存檔並在 $VISUAL 或 $EDITOR 中開啟

清除對話

快捷鍵

在兩秒內按兩次 Ctrl+L 即可執行 /clear 開始新對話, 第一次按下會重繪畫面並顯示提示, 第二次才會清除。macOS 上雙按 Cmd+K 也會執行 /clear。

搭配 tmux 使用

Fullscreen rendering 可在 tmux 中運作, 但有三個注意事項。

# ~/.tmux.conf set -g mouse on
注意事項

沒有滑鼠模式時滾輪事件會傳給 tmux 而非 Claude Code。與 iTerm2 的 tmux 整合模式 (tmux -CC) 不相容, 請勿在該模式下啟用。tmux 不支援同步輸出, 重繪時可能比直接在終端機執行時更容易閃爍, 尤其透過 SSH。

保留原生文字選取

滑鼠擷取是最常見的摩擦點, 尤其透過 SSH 或在 tmux 中。要臨時使用原生選取, 依終端機按住對應按鍵並拖曳:

終端機: Terminal.app iTerm2 VS Code / Cursor 其他多數終端機
按住的按鍵
Fn
完全停用

若一律依賴原生選取, 可設定 CLAUDE_CODE_DISABLE_MOUSE=1 停用滑鼠擷取, 同時保留不閃爍渲染與穩定記憶體。若只想保留滾輪但關閉點擊處理, 設定 CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1。

研究預覽

研究預覽

Fullscreen rendering 為研究預覽功能, 已在常見終端機模擬器上測試, 但在較少見的終端機或特殊設定上可能遇到渲染問題。執行 /feedback 回報問題, 並附上終端機名稱與版本。
