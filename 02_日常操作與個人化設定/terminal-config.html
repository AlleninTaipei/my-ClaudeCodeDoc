設定終端機

修正 Shift+Enter 換行, 取得完成通知, 設定 tmux, 配色主題, 啟用 Vim 模式

症狀速查

Claude Code 在任何終端機都能開箱即用, 本頁針對特定不如預期的行為。點選你遇到的症狀查看對應解法。

注意

本頁是關於讓終端機送出正確訊號給 Claude Code。要改變 Claude Code 本身回應哪些按鍵, 請改看 keybindings 頁面。

輸入多行提示

按 Enter 會送出訊息, 要換行而不送出, 按 Ctrl+J, 或輸入 \ 後按 Enter, 兩者在所有終端機都不需設定即可運作。

Ghostty/Kitty/iTerm2/WezTerm/Warp/Apple Terminal/Windows Terminal
不需設定即可用 Shift+Enter
VS Code/Cursor/Devin Desktop/Alacritty/Zed
執行一次 /terminal-setup
gnome-terminal/JetBrains IDE
不支援, 改用 Ctrl+J 或 \ 加 Enter

/terminal-setup 會把 Shift+Enter 等按鍵綁定寫入終端機的設定檔, 既有綁定會保留不動。要換掉 Enter 與 Shift+Enter 的行為, 可在 keybindings 檔案中對應 chat:newline 與 chat:submit 動作。

在 macOS 啟用 Option 按鍵快捷方式

部分 Claude Code 快捷鍵使用 Option 鍵, 例如 Option+Enter 換行或 Option+P 切換模型, macOS 上多數終端機預設不會送出 Option 作為修飾鍵。

取得終端機提示音或通知

Claude 完成任務或暫停等待權限提示時會觸發通知事件。預設只有 Ghostty, Kitty, iTerm2 會送出桌面通知, 其他終端機可設定 preferredNotifChannel 為 "terminal_bell" 改用終端機鈴聲, 或設定 Notification hook 自訂音效。

{
  "hooks": {
    "Notification": [
      {
        "hooks": [{ "type": "command", "command": "afplay /System/Library/Sounds/Glass.aiff" }]
      }
    ]
  }
}

桌面通知能透過 SSH 傳到本機, 遠端 session 也能提醒你; Ghostty 與 Kitty 會自動轉發到系統通知中心, iTerm2 需要在 Settings → Profiles → Terminal 手動啟用 alerts。

設定 tmux

在 tmux 中執行 Claude Code 時, 預設有兩件事會壞掉: Shift+Enter 會變成送出而非換行, 桌面通知與進度條無法傳到外層終端機。

set -g allow-passthrough on
set -s extended-keys on
set -as terminal-features 'xterm*:extkeys'

加入 ~/.tmux.conf 後執行 tmux source-file ~/.tmux.conf 套用到執行中的 server。

配色主題

用 /theme 指令或 /config 中的主題選擇器挑選符合終端機的配色, 選擇 auto 會偵測終端機的明暗背景並隨系統外觀改變。

建立自訂主題

每個自訂主題是 ~/.claude/themes/ 中的一個 JSON 檔案, 檔名 (不含副檔名) 即為主題代號。

name
在 /theme 中顯示的名稱, 預設為檔名代號
base
起始的內建主題: dark, light, dark-daltonized 等, 預設 dark
overrides
色彩代碼名稱對應色彩值的映射表
{
  "name": "Dracula",
  "base": "dark",
  "overrides": {
    "claude": "#bd93f9",
    "error": "#ff5555",
    "success": "#50fa7b"
  }
}

切換至全螢幕渲染模式

若顯示閃爍或捲動位置跳動, 切換到全螢幕渲染模式。此模式繪製於終端機保留給全螢幕應用的獨立畫面, 而非附加到一般的捲動歷史, 讓記憶體用量維持平穩, 並加入滑鼠捲動與選取支援。

/tui fullscreen
Bash / Zsh
CLAUDE_CODE_NO_FLICKER=1 claude
PowerShell
$env:CLAUDE_CODE_NO_FLICKER = "1"; claude

貼上大量內容

貼上超過 10,000 字元時, Claude Code 會將輸入框摺疊為 [Pasted text] 佔位符, 讓輸入框保持可用, 完整內容仍會在送出時傳給 Claude。

注意

VS Code 內建終端機在貼上非常大量內容時可能遺失字元, 建議改用檔案式流程: 將內容寫入檔案, 請 Claude 讀取檔案而非直接貼上。

用 Vim 快捷鍵編輯提示

透過 /config → Editor mode, 或在 ~/.claude/settings.json 設定 editorMode 為 "vim" 啟用。Vim 模式支援 NORMAL 與 VISUAL 模式的部分動作與運算子, 例如 hjkl 導覽, v/V 選取, 以及搭配文字物件的 d/c/y。

在 INSERT 模式按 Enter 仍會送出提示, 這與標準 Vim 不同; 要插入換行請在 NORMAL 模式用 o 或 O, 或使用 Ctrl+J。
