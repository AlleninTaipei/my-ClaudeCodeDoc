即時串流回應

了解如何從 Agent SDK 即時接收文字與工具呼叫的串流更新, 而不是等待完整回應.

啟用串流輸出

預設情況下, Agent SDK 會在 Claude 產生完每則回應後才回傳完整的 AssistantMessage. 將 include_partial_messages (Python) 或 includePartialMessages (TypeScript) 設為 true, 即可接收增量更新的文字與工具呼叫.

處理步驟

1. 判斷訊息類型是否為 StreamEvent
2. 取出 StreamEvent 的 event 欄位並檢查其 type
3. 尋找 delta.type 為 text_delta 的 content_block_delta 事件, 其中含有實際文字片段

Python
TypeScript
from claude_agent_sdk import query, ClaudeAgentOptions from claude_agent_sdk.types import StreamEvent import asyncio async def stream_response(): options = ClaudeAgentOptions( include_partial_messages=True, allowed_tools=["Bash", "Read"], ) async for message in query(prompt="List the files in my project", options=options): if isinstance(message, StreamEvent): event = message.event if event.get("type") == "content_block_delta": delta = event.get("delta", {}) if delta.get("type") == "text_delta": print(delta.get("text", ""), end="", flush=True) asyncio.run(stream_response())
import { query } from "@anthropic-ai/claude-agent-sdk"; for await (const message of query({ prompt: "List the files in my project", options: { includePartialMessages: true, allowedTools: ["Bash", "Read"] } })) { if (message.type === "stream_event") { const event = message.event; if (event.type === "content_block_delta") { if (event.delta.type === "text_delta") { process.stdout.write(event.delta.text); } } } }

StreamEvent 參考

啟用 partial messages 後, 你會收到包裝在物件中的原始 Claude API 串流事件. 此類型在兩個 SDK 中名稱不同.

Python: StreamEvent

uuid: 此事件的唯一識別碼

session_id: session 識別碼

event: 原始 Claude API 串流事件 (dict)

parent_tool_use_id: 若來自 subagent 則為其父工具 ID

TypeScript: SDKPartialAssistantMessage

type: "stream_event"

event: BetaRawMessageStreamEvent (來自 Anthropic SDK)

parent_tool_use_id, uuid, session_id

ttft_ms: 首個 token 花費時間 (僅 message_start 事件才有)

常見事件類型

message_start
新訊息開始
content_block_start
新內容區塊開始 (文字或工具使用)
content_block_delta
內容的增量更新
content_block_stop
內容區塊結束
message_delta
訊息層級更新 (停止原因, 使用量)
message_stop
訊息結束

訊息流程順序

啟用 partial messages 後, 你會依照以下順序收到訊息:

message_start
StreamEvent
content_block_start
StreamEvent, 文字區塊開始
content_block_delta ×N
StreamEvent, 文字片段陸續抵達
content_block_stop
StreamEvent
content_block_start
StreamEvent, tool_use 區塊開始
content_block_delta ×N
StreamEvent, 工具輸入片段陸續抵達
content_block_stop
StreamEvent
message_delta / message_stop
StreamEvent
AssistantMessage
包含所有內容的完整訊息
ResultMessage
最終結果 (工具執行, 下一輪串流事件之後)
未啟用時

若未啟用 partial messages, 你只會收到除了 StreamEvent 以外的所有訊息類型, 包含 SystemMessage, AssistantMessage, ResultMessage, 以及壓縮邊界訊息.

串流工具呼叫

工具呼叫也會以增量方式串流. 你可以追蹤工具何時開始, 接收其輸入被逐步產生, 並看到它何時完成. 使用以下三種事件類型:

content_block_start
工具開始
content_block_delta (input_json_delta)
輸入片段陸續抵達
content_block_stop
工具呼叫完成
選擇語言:
Python
TypeScript
current_tool = None tool_input = "" async for message in query(prompt="Read the README.md file", options=options): if isinstance(message, StreamEvent): event_type = message.event.get("type") if event_type == "content_block_start": block = message.event.get("content_block", {}) if block.get("type") == "tool_use": current_tool = block.get("name") print(f"Starting tool: {current_tool}") elif event_type == "content_block_delta": delta = message.event.get("delta", {}) if delta.get("type") == "input_json_delta": tool_input += delta.get("partial_json", "") elif event_type == "content_block_stop": if current_tool: print(f"Tool {current_tool} called with: {tool_input}")
let currentTool: string | null = null; let toolInput = ""; for await (const message of query({ prompt: "Read the README.md file", options })) { if (message.type === "stream_event") { const event = message.event; if (event.type === "content_block_start" && event.content_block.type === "tool_use") { currentTool = event.content_block.name; console.log(`Starting tool: ${currentTool}`); } else if (event.type === "content_block_delta" && event.delta.type === "input_json_delta") { toolInput += event.delta.partial_json; } else if (event.type === "content_block_stop" && currentTool) { console.log(`Tool ${currentTool} called with: ${toolInput}`); } } }

打造串流 UI

結合文字與工具串流成一個完整的 UI. 用 in_tool 旗標追蹤是否正在執行工具, 在工具執行時顯示狀態指示 (例如 [Using Read...]), 未執行工具時正常串流文字, 工具完成時顯示 done 訊息. 適合需要顯示多步驟 agent 任務進度的聊天介面.

已知限制

結構化輸出 (structured output) 的 JSON 結果只會出現在最終 ResultMessage.structured_output 中, 不會以串流增量的形式出現.

串流輸出讓使用者在等待期間就能看到進度, 是打造即時聊天介面與多步驟 agent 任務可視化的關鍵能力. 搭配 [串流輸入模式] 使用效果最佳.
