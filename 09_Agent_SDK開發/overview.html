Agent SDK Overview

用 Claude Code 作為函式庫, 打造能自主讀檔, 執行指令, 搜尋網頁, 編輯程式碼的正式環境 AI 代理

簡介

Agent SDK 提供與 Claude Code 相同的工具, agent loop 與上下文管理能力, 讓你能以 Python 或 TypeScript 撰寫程式來驅動代理。內建工具已經處理好執行細節, 不需要自己實作工具執行邏輯。

選擇語言查看範例:
Python
TypeScript
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    async for message in query(
        prompt="Find and fix the bug in auth.py",
        options=ClaudeAgentOptions(allowed_tools=["Read", "Edit", "Bash"]),
    ):
        print(message)  # Claude 讀檔, 找出錯誤, 修改它

asyncio.run(main())
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Find and fix the bug in auth.ts",
  options: { allowedTools: ["Read", "Edit", "Bash"] }
})) {
  console.log(message); // Claude 讀檔, 找出錯誤, 修改它
}

注意

除非事先取得核准, Anthropic 不允許第三方開發者為以 Agent SDK 建置的產品提供 claude.ai 登入或速率限制, 請使用本頁所述的 API 金鑰驗證方式。

import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    async for message in query(
        prompt="What files are in this directory?",
        options=ClaudeAgentOptions(allowed_tools=["Bash", "Glob"]),
    ):
        if hasattr(message, "result"):
            print(message.result)

asyncio.run(main())

可用 hooks: PreToolUse, PostToolUse, Stop, SessionStart, SessionEnd, UserPromptSubmit 等。

Claude Code 檔案系統設定

SDK 也支援 Claude Code 以檔案系統為基礎的設定, 預設從工作目錄下的 .claude/ 與 ~/.claude/ 載入, 可用 setting_sources 限制來源。

Skills
.claude/skills/*/SKILL.md — Claude 自動使用或以 /name 呼叫的專門能力
Commands
.claude/commands/*.md — 舊格式自訂指令, 新指令建議改用 skills
Memory
CLAUDE.md 或 .claude/CLAUDE.md — 專案情境與指示
Plugins
透過 plugins 選項以程式化方式擴充 skills, agents, hooks, MCP 伺服器

Compare the Agent SDK to other Claude tools

Claude Platform 提供多種建置方式, 以下說明 Agent SDK 在其中的定位。

vs Client SDK
vs Claude Code CLI
vs Managed Agents

Client SDK 給你直接的 API 存取: 自己傳送提示並實作工具執行邏輯。Agent SDK 則內建工具執行能力。

Client SDK

需要自行實作 tool loop, 手動處理 stop_reason === "tool_use" 的迴圈。

Agent SDK

Claude 自主處理工具呼叫, 只需疊代 query() 傳回的訊息串流。

相同能力, 不同介面。

互動式開發
CLI
CI/CD 流程
SDK
自訂應用程式
SDK
一次性任務
CLI
正式環境自動化
SDK

許多團隊兩者並用: CLI 用於日常開發, SDK 用於正式環境, 工作流程可以直接互轉。

Managed Agents 是託管的 REST API, 由 Anthropic 執行代理與沙盒；Agent SDK 是在自己的行程中執行 agent loop 的函式庫。

Agent SDK

執行於自己的行程與基礎設施, Python/TypeScript 函式庫, 適合本機原型與需要直接操作檔案系統的代理。

Managed Agents

執行於 Anthropic 管理的基礎設施, REST API 介面, 每個 session 有獨立管理的沙盒, 適合不想自行維運沙盒或 session 基礎設施的正式環境代理。

常見路徑: 先用 Agent SDK 在本機做原型, 再轉移到 Managed Agents 上線。
