SDK 中的 Slash Commands

學習如何透過 Claude Agent SDK 使用 slash commands 來控制 Claude Code session, 包含發現指令, 傳送指令與建立自訂指令.

探索可用的 Slash Commands

Claude Agent SDK 會在系統初始化訊息 (system/init) 中提供可用 slash commands 的資訊. 只有不需要互動式終端機就能執行的指令才能透過 SDK 呼叫.

選擇語言:
TypeScript
Python
import { query } from "@anthropic-ai/claude-agent-sdk"; for await (const message of query({ prompt: "Hello Claude", options: { maxTurns: 1 } })) { if (message.type === "system" && message.subtype === "init") { console.log("Available slash commands:", message.slash_commands); // 包含內建指令與內附的 skills, 例如: // ["clear", "compact", "context", "usage", "code-review", "verify", ...] } }
import asyncio from claude_agent_sdk import query, ClaudeAgentOptions, SystemMessage async def main(): async for message in query(prompt="Hello Claude", options=ClaudeAgentOptions(max_turns=1)): if isinstance(message, SystemMessage) and message.subtype == "init": print("Available slash commands:", message.data["slash_commands"]) # 包含內建指令與內附的 skills asyncio.run(main())
重點

回傳的清單包含內建指令加上已內附的 skills 與你自訂的指令, 建議在 session 一開始就讀取這份清單以確認可用指令.

傳送 Slash Commands

將 slash command 像一般文字一樣放入 prompt 字串中即可傳送. 像 /compact 這類作用於對話歷史的指令, 需要先有對話內容才能運作, 因此範例會先進行一次問答, 再以 follow-up 的方式送出指令.

選擇語言:
TypeScript
Python
// 先建立對話歷史 try { for await (const message of query({ prompt: "What does the README in this directory cover?", options: { maxTurns: 2 } })) { if (message.type === "result" && message.subtype === "success") { console.log(message.result); } } } catch (error) { // 單次 query() 在產出錯誤結果後會拋出例外, 後續指令仍會執行 console.error(`Session ended with an error: ${error}`); } // 以 follow-up 方式送出 slash command for await (const message of query({ prompt: "/compact", options: { continue: true, maxTurns: 1 } })) { if (message.type === "result") { console.log("Command executed, result subtype:", message.subtype); } }
import asyncio from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage async def main(): try: async for message in query( prompt="What does the README in this directory cover?", options=ClaudeAgentOptions(max_turns=2), ): if isinstance(message, ResultMessage) and message.subtype == "success": print(message.result) except Exception as error: print(f"Session ended with an error: {error}") async for message in query( prompt="/compact", options=ClaudeAgentOptions(continue_conversation=True, max_turns=1), ): if isinstance(message, ResultMessage): print("Command executed, result subtype:", message.subtype) asyncio.run(main())
注意

query 可能以錯誤結果結束, 例如達到 maxTurns 上限. 最終結果訊息會帶有 is_error: true 與 error_max_turns 等 subtype, 且 SDK 會在此之後拋出例外 (因為 CLI 行程以非零狀態碼結束), 記得用 try/catch 包住.

常用 Slash Commands

1 · /compact
2 · /clear

/compact 會透過摘要較舊的訊息來縮減對話歷史大小, 同時保留重要脈絡. 執行 compaction 需要至少已有兩輪先前交流.

compact_boundary
只有在真的執行了壓縮時才會出現的 system 訊息
pre_tokens
壓縮前的 token 數量, 例如 1842
trigger
觸發方式, 例如 manual
邊界情況

若沒有可摘要的內容, /compact 不會拋出錯誤, 而是以 success 結束並在結果文字中說明原因, 例如 "Not enough messages to compact." 全新的 query() 呼叫每次都是空白脈絡, 因此此模式建議搭配串流輸入模式或 resume session 使用.

/clear 會把對話重設為空白脈絡, 讓後續 prompt 從無先前歷史開始. 舊對話仍保存在磁碟上, 可透過 session ID 搭配 resume 選項回到該對話.

適用情境

此指令在串流輸入模式下最有用, 因為該模式會在單一連線上傳送多個 prompt. 對單次 query() 呼叫而言, 每次呼叫本來就是空白脈絡, 所以送出 /clear 沒有實際效果, 直接開新的 query() 即可.

版本需求

SDK 中的 /clear 需要 Claude Code v2.1.117 以上版本, 較早版本的 slash_commands 清單中不會包含它.

Step 1 of 2

建立自訂 Slash Commands

除了內建指令外, 你也可以建立自己的自訂指令, 以 markdown 檔案定義, 存放位置與 subagent 設定方式類似.

格式演進

.claude/commands/ 是舊格式. 建議格式是 .claude/skills/<name>/SKILL.md, 支援相同的 slash command 呼叫方式 (/name), 並額外支援 Claude 自主呼叫. CLI 持續支援兩種格式.

存放位置

專案指令

.claude/commands/

只在目前專案中可用 (舊格式, 建議改用 .claude/skills/)

個人指令

~/.claude/commands/

在你所有的專案中都可用 (舊格式, 建議改用 ~/.claude/skills/)

Frontmatter 可用欄位

allowed-tools
限定此指令可使用的工具, 例如 Read, Grep, Glob
description
指令的簡短描述
model
覆寫此指令使用的模型, 例如 claude-opus-4-8
argument-hint
提示此指令接受的參數, 例如 [issue-number] [priority]

進階功能

參數與佔位符
用 $0, $1 或 $ARGUMENTS 接收動態參數, 例如 /fix-issue 123 high
執行 Bash 指令
用 !`git status` 這類語法在指令內嵌入 shell 輸出
檔案參照
用 @package.json 這類語法在指令內引用檔案內容
子目錄命名空間
將指令放入子目錄以利組織, 子目錄只影響描述, 不影響指令名稱本身
.claude/commands/ ├── frontend/ │ ├── component.md // 建立 /component (project:frontend) │ └── style-check.md // 建立 /style-check (project:frontend) ├── backend/ │ ├── api-test.md // 建立 /api-test (project:backend) │ └── db-migrate.md // 建立 /db-migrate (project:backend) └── review.md // 建立 /review (project)
名稱衝突

Claude Code 內附 code-review 與 verify skills. 若自訂指令與其同名, 例如 .claude/commands/code-review.md, 你的指令會覆蓋內附的 skill, slash_commands 只會列出一次該名稱.

自訂指令一旦定義在檔案系統中, 就會自動出現在 SDK 的 slash_commands 清單中並可直接於 prompt 中呼叫, 是將團隊常用工作流程封裝成可重用指令的最簡單方式.
