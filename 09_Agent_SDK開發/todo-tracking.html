Todo Lists 待辦事項追蹤

使用 Claude Agent SDK 追蹤與顯示待辦事項, 讓複雜工作流程井然有序, 並持續向使用者回報進度。

核心概念與生命週期

Todo 追蹤提供一種結構化方式來管理任務, 並向使用者顯示進度。Claude Agent SDK 內建 Todo 功能, 協助組織複雜工作流程, 並持續讓使用者掌握任務進展。

版本說明

自 TypeScript Agent SDK 0.3.142 與 Claude Code v2.1.142 起, session 改用結構化的 Task 工具 TaskCreate, TaskUpdate, TaskGet, TaskList, 取代原本的 TodoWrite。若要讓尚未遷移的 session 仍顯示 TodoWrite, 範例中會設定 CLAUDE_CODE_ENABLE_TASKS=0。

Todo 生命週期

pending識別出任務時建立
in_progress開始執行工作時啟動
completed任務成功完成時標記
removed群組內所有任務都完成後移除

1 · 監控 Todo 變更

在訊息串中攔截 tool_use 區塊, 找出 TodoWrite 呼叫, 即可取得每次更新的完整待辦清單。

語言: 
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Optimize my React app performance and track progress with todos",
  // 重新啟用 TodoWrite, 讓此範例可以監聽到它
  options: { maxTurns: 15, env: { ...process.env, CLAUDE_CODE_ENABLE_TASKS: "0" } }
})) {
  if (message.type === "assistant") {
    for (const block of message.message.content) {
      if (block.type === "tool_use" && block.name === "TodoWrite") {
        const todos = block.input.todos;
        todos.forEach((todo, index) => {
          const status = todo.status === "completed" ? "done" : todo.status;
          console.log(`${index + 1}. ${status} ${todo.content}`);
        });
      }
    }
  }
}
from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, ToolUseBlock

async for message in query(
    prompt="Optimize my React app performance and track progress with todos",
    options=ClaudeAgentOptions(max_turns=15, env={"CLAUDE_CODE_ENABLE_TASKS": "0"}),
):
    if isinstance(message, AssistantMessage):
        for block in message.content:
            if isinstance(block, ToolUseBlock) and block.name == "TodoWrite":
                todos = block.input["todos"]
                for i, todo in enumerate(todos):
                    status = "done" if todo["status"] == "completed" else todo["status"]
                    print(f"{i + 1}. {status} {todo['content']}")

建立一個 TodoTracker 類別, 每次收到 TodoWrite 更新時重新計算已完成/進行中的數量, 並印出目前進度。

語言: 
class TodoTracker {
  todos: any[] = [];

  displayProgress() {
    if (this.todos.length === 0) return;
    const completed = this.todos.filter(t => t.status === "completed").length;
    const total = this.todos.length;
    console.log(`Progress: ${completed}/${total} completed`);
  }

  async trackQuery(prompt: string) {
    for await (const message of query({
      prompt,
      options: { maxTurns: 20, env: { ...process.env, CLAUDE_CODE_ENABLE_TASKS: "0" } }
    })) {
      if (message.type === "assistant") {
        for (const block of message.message.content) {
          if (block.type === "tool_use" && block.name === "TodoWrite") {
            this.todos = block.input.todos;
            this.displayProgress();
          }
        }
      }
    }
  }
}
class TodoTracker:
    def __init__(self):
        self.todos = []

    def display_progress(self):
        if not self.todos:
            return
        completed = len([t for t in self.todos if t["status"] == "completed"])
        total = len(self.todos)
        print(f"Progress: {completed}/{total} completed")

    async def track_query(self, prompt):
        async for message in query(
            prompt=prompt,
            options=ClaudeAgentOptions(max_turns=20, env={"CLAUDE_CODE_ENABLE_TASKS": "0"}),
        ):
            if isinstance(message, AssistantMessage):
                for block in message.content:
                    if isinstance(block, ToolUseBlock) and block.name == "TodoWrite":
                        self.todos = block.input["todos"]
                        self.display_progress()

遷移至 Task 工具版本相依

Task 工具將單一的 TodoWrite 呼叫拆分成 TaskCreate (每個新項目) 與 TaskUpdate (每次狀態變更), 並提供 TaskList 與 TaskGet 供模型讀回目前清單。監控程式碼仍是攔截 assistant 串流中的 tool_use 區塊, 但要改用以 task ID 為鍵的 map, 而不是每次都整個取代清單。

使用 TodoWrite

一次工具呼叫重寫整個 todos 陣列

比對 block.name === "TodoWrite"

項目結構: { content, status, activeForm }

直接渲染 block.input.todos

使用 Task 工具

TaskCreate 新增一項, TaskUpdate 依 taskId 更新一項

比對 block.name === "TaskCreate" 或 "TaskUpdate"

狀態為 pending / in_progress / completed, 設為 deleted 可刪除項目

需跨呼叫累積項目, 或從 TaskList 結果讀取快照

TaskCreate 輸入
{ subject, description, activeForm?, metadata? }
TaskUpdate 輸入
{ taskId, status?, subject?, description?, activeForm?, addBlocks?, addBlockedBy?, owner?, metadata? }
task ID 取得方式
不在 TaskCreate 輸入中, 而是從對應的 tool_result 的 { task: { id, subject } } 取得

Claude Code 會在執行前修正部分接近正確但錯誤的鍵名, 例如把 id 或 task_id 映射成 taskId, 把 active_form 映射成 activeForm, 但這個修正不會反映在串流中。讀取 TaskUpdate 欄位時應防禦性地同時檢查這些別名, 而不是假設一定存在正規名稱。

最小改動範例

語言: 
for await (const message of query({ prompt: "Optimize my React app performance" })) {
  if (message.type !== "assistant") continue;
  for (const block of message.message.content) {
    if (block.type !== "tool_use") continue;
    if (block.name === "TaskCreate") {
      console.log(`+ ${block.input.subject}`);
    } else if (block.name === "TaskUpdate") {
      const taskId = block.input.taskId ?? block.input.id ?? block.input.task_id;
      if (taskId && block.input.status) console.log(`  ${taskId} -> ${block.input.status}`);
    }
  }
}
async for message in query(prompt="Optimize my React app performance"):
    if not isinstance(message, AssistantMessage):
        continue
    for block in message.content:
        if not isinstance(block, ToolUseBlock):
            continue
        if block.name == "TaskCreate":
            print(f"+ {block.input['subject']}")
        elif block.name == "TaskUpdate" and block.input.get("status"):
            task_id = block.input.get("taskId") or block.input.get("id") or block.input.get("task_id")
            if task_id:
                print(f"  {task_id} -> {block.input['status']}")
