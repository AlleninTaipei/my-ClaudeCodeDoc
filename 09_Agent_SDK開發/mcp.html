Connect to External Tools with MCP

設定 MCP 伺服器來擴充代理的外部工具, 涵蓋傳輸類型, 大量工具下的 tool search, 驗證方式與錯誤處理

Quickstart

Model Context Protocol (MCP) 是連接 AI 代理到外部工具與資料來源的開放標準。以下範例透過 HTTP 傳輸連接 Claude Code 文件 MCP 伺服器, 並用萬用字元允許該伺服器的所有工具。

語言:
TypeScript
Python
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Use the docs MCP server to explain what hooks are",
  options: {
    mcpServers: { "claude-code-docs": { type: "http", url: "https://code.claude.com/docs/mcp" } },
    allowedTools: ["mcp__claude-code-docs__*"]
  }
})) { /* ... */ }
options = ClaudeAgentOptions(
    mcp_servers={"claude-code-docs": {"type": "http", "url": "https://code.claude.com/docs/mcp"}},
    allowed_tools=["mcp__claude-code-docs__*"],
)
async for message in query(prompt="...", options=options):
    # ...

Add an MCP server

在程式碼中設定
從設定檔載入

直接在 mcpServers 選項傳入伺服器設定:

options: {
  mcpServers: { filesystem: { command: "npx", args: ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/projects"] } },
  allowedTools: ["mcp__filesystem__*"]
}

在專案根目錄建立 .mcp.json, 當 project 設定來源啟用時會自動載入:

{
  "mcpServers": {
    "filesystem": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/projects"] }
  }
}

Allow MCP tools

MCP 工具需要明確授權才能被 Claude 呼叫。沒有授權時, Claude 能看到工具存在, 但無法呼叫。

命名規則

MCP 工具遵循 mcp__<server-name>__<tool-name> 格式, 例如名為 github 的伺服器中的 list_issues 工具會變成 mcp__github__list_issues。

allowedTools: [
  "mcp__github__*",       // github 伺服器全部工具
  "mcp__db__query",       // 只允許 db 伺服器的 query
  "mcp__slack__send_message" // 只允許 slack 的 send_message
]

優先用 allowedTools 而非權限模式來控管 MCP 存取: acceptEdits 不會自動核准 MCP 工具, bypassPermissions 會核准但範圍過廣, 萬用字元 allowedTools 才是精準授權特定伺服器。

Transport types

MCP 伺服器透過不同傳輸協定溝通, 依伺服器文件挑選對應方式。

1 · stdio
2 · HTTP / SSE
3 · SDK MCP servers

本機行程, 透過 stdin/stdout 溝通, 適合在同一台機器上執行的 MCP 伺服器。文件若給的是「執行指令」就用這種。

mcpServers: {
  github: { command: "npx", args: ["-y", "@modelcontextprotocol/server-github"], env: { GITHUB_TOKEN: process.env.GITHUB_TOKEN } }
}

用於雲端託管的 MCP 伺服器與遠端 API。文件若給的是「網址」就用這種。streamable HTTP 傳輸用 "type": "http"。

mcpServers: {
  "remote-api": { type: "sse", url: "https://api.example.com/mcp/sse", headers: { Authorization: `Bearer ${process.env.API_TOKEN}` } }
}

直接在應用程式碼中定義自訂工具, 不需另外執行伺服器行程。適合自行建置工具的情境, 詳見自訂工具指南。

MCP tool search

預設啟用

設定大量 MCP 工具時, 工具定義會佔用大量上下文視窗。Tool search 預設啟用, 會保留工具定義不進入上下文, 只在 Claude 需要時才載入對應工具。

Authentication

多數 MCP 伺服器需要驗證才能存取外部服務, 透過伺服器設定中的環境變數傳遞憑證。

環境變數
HTTP Headers
OAuth2
mcpServers: { github: { command: "npx", args: [...], env: { GITHUB_TOKEN: process.env.GITHUB_TOKEN } } }

.mcp.json 中可用 ${GITHUB_TOKEN} 語法在執行時展開環境變數。

對於 HTTP 與 SSE 伺服器, 直接在伺服器設定中傳遞驗證 headers:

mcpServers: { "secure-api": { type: "http", url: "...", headers: { Authorization: `Bearer ${process.env.API_TOKEN}` } } }

MCP 規範支援 OAuth 2.1 授權。SDK 不會自動處理 OAuth 流程, 但完成流程後可將存取權杖透過 headers 傳入。

Examples

列出 repo 的 issues
查詢資料庫

連接 GitHub MCP 伺服器列出最近的 issues, 需先建立具備 repo 權限的 GitHub personal access token。

system / init驗證 MCP 伺服器是否連線成功
assistant記錄 Claude 何時呼叫以 mcp__ 開頭的工具
result / success印出最終結果

使用 Postgres MCP 伺服器查詢資料庫, 連線字串以參數傳入伺服器。代理會自動探索資料庫結構, 撰寫 SQL 查詢, 並回傳結果。

allowedTools: ["mcp__postgres__query"] // 只允許讀取查詢, 不允許寫入

Error handling 與 Troubleshooting

MCP 伺服器可能因多種原因連線失敗: 伺服器行程未安裝, 憑證無效, 或遠端伺服器無法連線。每次查詢開始時的 system / init 訊息包含每個伺服器的連線狀態。

缺少環境變數確認所需的權杖與憑證已設定, stdio 伺服器需檢查 env 欄位
伺服器未安裝npx 指令需確認套件存在且 Node.js 在 PATH 中
連線字串無效資料庫伺服器需確認連線字串格式與資料庫可連線
網路問題遠端 HTTP/SSE 伺服器需確認網址可連線且防火牆允許連線
工具未被呼叫確認已用 allowedTools 授權對應伺服器的工具
連線逾時MCP SDK 預設 60 秒逾時, 啟動較慢的伺服器可考慮預先暖機
