Modifying System Prompts

在 claude_code 預設提示與自訂系統提示之間做選擇, 並用 CLAUDE.md, output styles, append 或完全自訂提示來客製化行為

How system prompts work

系統提示是形塑 Claude 整個對話行為的初始指令集。Agent SDK 有三種起點:

Minimal default
不設定 systemPrompt 時的最小提示, 只涵蓋工具呼叫, 省略程式碼規範與專案情境
claude_code preset
Claude Code CLI 使用的完整系統提示, 含工具使用, 程式碼風格, 回覆語氣, 安全性指示
Custom string
自己撰寫的提示, SDK 只會送出你提供的內容

Decide on a starting point

決定因素在於代理與 Claude Code 有多相似: 在儲存庫中操作, 由人類觀看串流輸出並引導工作的程式碼代理。差異越大, 越需要自己撰寫提示。

CLI / IDE 工具, 人類主導
claude_code preset
同類工具 + 產品專屬規則
claude_code preset + append
不同介面, 身分或權限模型
Custom prompt string
純工具呼叫迴圈
不設定 systemPrompt
何謂不同

不同介面 (輸出不是在終端機被觸發者閱讀), 不同身分 (不應以 Claude Code 自稱), 不同權限模型 (無人在場逐步核准), 或非程式碼任務。

Customize agent behavior

Output styles, append, 與自訂提示字串都會直接改變系統提示。CLAUDE.md 則不同: SDK 會將其內容注入對話作為專案情境, 而非系統提示本身。

CLAUDE.md
Output styles
Append
自訂提示字串

提供持久的專案情境與指示。SDK 會在對應設定來源啟用時讀取: project 載入 CLAUDE.md 或 .claude/CLAUDE.md, user 載入 ~/.claude/CLAUDE.md。

options: {
  systemPrompt: { type: "preset", preset: "claude_code" },
  settingSources: ["project"] // 載入專案的 CLAUDE.md
}

CLAUDE.md 跨所有 session 持續生效, 透過 git 與團隊共享, 自動被發現無需改程式碼。

Output styles 是儲存下來的設定, 會修改 Claude 的系統提示, 以 markdown 檔案儲存, 可跨 session 與專案重複使用。

---
name: Code Reviewer
description: Thorough code review assistant
keep-coding-instructions: true
---
You are an expert code reviewer.

預設會取代 claude_code preset 的軟體工程指示, 設定 keep-coding-instructions: true 可保留並疊加自己的指示。啟用方式: CLI 執行 /config, 設定檔設定 outputStyle, 或 TypeScript SDK 在 settings 物件中設定 (Python SDK 不支援以程式方式選擇)。

使用 claude_code preset 搭配 append 加入自訂指示, 同時保留所有內建功能。

systemPrompt: {
  type: "preset", preset: "claude_code",
  append: "Always include detailed docstrings and type hints in Python code."
}
快取優化

設定 excludeDynamicSections: true 可把工作目錄等逐 session 情境移到第一則使用者訊息, 讓不同機器與使用者的相同設定能共用快取。

提供自訂字串作為 systemPrompt, 完全取代預設提示。

systemPrompt: `You are a Python coding specialist.
Follow these guidelines:
- Write clean, well-documented code
- Use type hints for all functions`

Use cases and best practices

CLAUDE.md 適用每個 session 都適用的指示: 程式碼規範, 常用指令, 架構情境, 團隊慣例
Output styles 適用想在 CLI 與 SDK 間重用、不改應用程式碼的人格設定, 例如程式碼審查員, 資料科學家助理
append 適用claude_code preset 已經合適, 只需要疊加額外指示時
自訂 systemPrompt 適用介面, 身分, 權限模型與 Claude Code 不同時, 需要完全掌控行為

Combine approaches

這些方法可以組合使用。持久的 output style 或 CLAUDE.md 設定長期行為, append 則在其上疊加 session 專屬指示, 不影響已儲存的設定。

systemPrompt: {
  type: "preset", preset: "claude_code",
  append: `For this review, prioritize:
  - OAuth 2.0 compliance
  - Token storage security`
}

假設已啟用 Code Reviewer output style, append 區塊可在單次 review session 中聚焦 OAuth 與權杖儲存, 而不需更動已儲存的 output style。
