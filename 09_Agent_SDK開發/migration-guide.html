Migrate to Claude Agent SDK

Claude Code TypeScript 與 Python SDK 更名遷移指南

Overview 與 What's Changed

Claude Code SDK 已更名為 Claude Agent SDK, 文件也已重新整理, 反映 SDK 已從單純的程式碼任務擴展為建置各類 AI 代理的更廣泛能力。

Package Name (TS/JS)
@anthropic-ai/claude-code → @anthropic-ai/claude-agent-sdk
Python Package
claude-code-sdk → claude-agent-sdk
Documentation Location
Claude Code docs → API Guide → Agent SDK 專區
注意

Agent SDK 文件已從 Claude Code docs 移至 API Guide 底下的 Agent SDK 專區, Claude Code docs 現在專注於 CLI 工具與自動化功能。

Step 1 of 5

Breaking changes

警告

為改善隔離性與明確設定, Claude Agent SDK v0.1.0 針對從 Claude Code SDK 遷移的使用者引入了破壞性變更, 遷移前請仔細檢視本節。

Python: ClaudeCodeOptions 更名為 ClaudeAgentOptions

# BEFORE (claude-code-sdk)
from claude_code_sdk import query, ClaudeCodeOptions
options = ClaudeCodeOptions(model="claude-opus-4-7", permission_mode="acceptEdits")

# AFTER (claude-agent-sdk)
from claude_agent_sdk import query, ClaudeAgentOptions
options = ClaudeAgentOptions(model="claude-opus-4-7", permission_mode="acceptEdits")

System prompt no longer default

SDK 預設不再使用 Claude Code 的系統提示。若要恢復舊行為, 需明確設定 systemPrompt: { type: "preset", preset: "claude_code" }。

Settings sources default

此預設值在 v0.1.0 曾短暫變更後又恢復, 不需要遷移動作。省略 settingSources 時會載入 user, project, local 檔案系統設定, 與 CLI 一致。若要與檔案系統設定隔離, 傳入空陣列 settingSources: []。

隔離對 CI/CD 流程, 部署後的應用程式, 測試環境, 以及多租戶系統特別重要, 可避免本機自訂設定滲入。

Why the Rename 與 Getting Help

Claude Code SDK 原本為程式碼任務設計, 現已演變為建置各類 AI 代理的強大框架:

商業代理法務助理, 財務顧問, 客戶支援
專門程式碼代理SRE bot, 安全審查員, 程式碼審查代理
任意領域自訂代理工具使用, MCP 整合等
