Agent SDK 快速上手

使用 Python 或 TypeScript 版 Agent SDK, 打造能自主閱讀程式碼, 找出錯誤並修正的 AI 代理人。

事前準備

PREREQUISITES

需要 Node.js 18 以上或 Python 3.10 以上, 以及一組 Anthropic 帳號用來取得 API 金鑰。

建立一個有錯誤的檔案

在 my-agent 目錄下建立 utils.py, 貼上以下含有兩個錯誤的程式碼:

def calculate_average(numbers):
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)


def get_user_name(user):
    return user["name"].upper()
calculate_average([])
除以零而當機
get_user_name(None)
觸發 TypeError 而當機

建立能找出並修正錯誤的代理人

建立 agent.py 或 agent.ts (既有 CommonJS 專案請用 agent.mts):

語言
Python
TypeScript
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, ResultMessage


async def main():
    # Agentic loop: streams messages as Claude works
    async for message in query(
        prompt="Review utils.py for bugs that would cause crashes. Fix any issues you find.",
        options=ClaudeAgentOptions(
            allowed_tools=["Read", "Edit", "Glob"],
            permission_mode="acceptEdits",
        ),
    ):
        if isinstance(message, AssistantMessage):
            for block in message.content:
                if hasattr(block, "text"):
                    print(block.text)
                elif hasattr(block, "name"):
                    print(f"Tool: {block.name}")
        elif isinstance(message, ResultMessage):
            print(f"Done: {message.subtype}")


asyncio.run(main())
import { query } from "@anthropic-ai/claude-agent-sdk";

// Agentic loop: streams messages as Claude works
for await (const message of query({
  prompt: "Review utils.py for bugs that would cause crashes. Fix any issues you find.",
  options: {
    allowedTools: ["Read", "Edit", "Glob"],
    permissionMode: "acceptEdits"
  }
})) {
  if (message.type === "assistant" && message.message?.content) {
    for (const block of message.message.content) {
      if ("text" in block) {
        console.log(block.text);
      } else if ("name" in block) {
        console.log(`Tool: ${block.name}`);
      }
    }
  } else if (message.type === "result") {
    console.log(`Done: ${message.subtype}`);
  }
}
query
建立代理迴圈的主要進入點, 回傳非同步疊代器, 以 async for 串流訊息
prompt
要 Claude 完成的任務, Claude 會依任務自行決定使用哪些工具
options
代理人設定, 例如 allowedTools 與 permissionMode, 也支援 systemPrompt, mcpServers 等
async for 迴圈
在 Claude 思考, 呼叫工具, 觀察結果並決定下一步時持續執行, 直到任務完成或發生錯誤
NOTE

本範例使用串流方式即時顯示進度。若不需要即時輸出 (例如背景工作或 CI 流程), 也可以一次收集所有訊息, 詳見串流與單次模式的比較。

代理人執行時會印出推理過程與每個呼叫的工具, 最後顯示 Done: success。執行後檢查 utils.py, 會看到已加入處理空陣列與 null 使用者的防禦性程式碼: 代理人自主讀取檔案, 分析出會當機的邊界情況, 並直接修改檔案。這正是 Agent SDK 的核心差異, Claude 直接執行工具, 而不是要求你自己實作。

NOTE

若看到 "API key not found", 請確認已在執行代理人的 shell 中設定 ANTHROPIC_API_KEY 環境變數, SDK 不會自動載入 .env 檔案。

關鍵概念

工具決定代理人能做什麼

Read, Glob, Grep
唯讀分析
Read, Edit, Glob
分析並修改程式碼
Read, Edit, Bash, Glob, Grep
完整自動化

權限模式決定人工監督程度

acceptEdits
自動核准檔案編輯與常見檔案系統指令, 其他動作仍會詢問; 適合信任的開發流程
plan
只執行唯讀工具, 檔案編輯一律交給 canUseTool 回呼; 適合在核准執行前先評估任務
dontAsk
拒絕所有不在 allowedTools 中的動作; 適合鎖定的無人值守代理人
auto (僅 TypeScript)
由模型分類器逐一核准或拒絕工具呼叫; 適合具安全防護的自主代理人
bypassPermissions
除非符合明確的 ask 規則, 否則不詢問直接執行所有工具; 適合沙箱化 CI 或完全信任環境
default
需要 canUseTool 回呼處理核准; 適合自訂核准流程

上方範例使用 acceptEdits 模式, 自動核准檔案操作以便代理人可在無互動提示下執行。若想讓使用者核准, 可改用 default 模式並提供收集使用者輸入的 canUseTool 回呼。
