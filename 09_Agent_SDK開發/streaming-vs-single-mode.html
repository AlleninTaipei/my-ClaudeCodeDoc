串流輸入 vs 單次訊息輸入

了解 Claude Agent SDK 兩種輸入模式的差異, 學會依應用情境選擇合適的方式.

概觀

Claude Agent SDK 支援兩種截然不同的輸入模式.

串流輸入模式 (預設且建議)

一個持續存在的互動式 session

完整存取 agent 的所有能力

單次訊息輸入

使用 session 狀態與 resume 的一次性查詢

較簡單但功能較受限

串流輸入模式

串流輸入模式是使用 Claude Agent SDK 的首選方式. 它讓 agent 能以長時間執行的行程運作, 接收使用者輸入, 處理中斷, 呈現權限請求, 並管理 session.

運作方式

初始化
App 以 AsyncGenerator 初始化 Agent
訊息 1
App 送出訊息, Agent 執行工具讀寫檔案系統, 並串流回傳部分與完整回應
訊息 2 + 圖片
App 送出含圖片的訊息, Agent 處理圖片並存取檔案系統, 串流回應
訊息 3 + 中斷
App 佇列訊息 3 後又送出中斷/取消, Agent 處理該中斷
Session 持續存活
整個過程中檔案系統狀態持續維持

優點

圖片上傳
直接在訊息中附加圖片供視覺分析與理解
佇列訊息
傳送多則依序處理的訊息, 並可中途中斷
工具整合
session 期間完整存取所有工具與自訂 MCP servers
即時回饋
邊產生邊看到回應, 而非只等最終結果
脈絡持續性
自然地在多輪對話間維持對話脈絡

錯誤處理注意

TypeScript 中若 message generator 拋出例外, 串流會以 "Claude Code process aborted by user" 結束而非原始錯誤訊息, 請先檢查 generator 內部程式碼. Python 中 generator 例外只會以 debug 層級記錄, session 會卡住而不拋出, 若串流 session 無輸出卡住, 請啟用 debug 記錄並檢查你的 generator.

單次訊息輸入

單次訊息輸入較簡單但限制較多.

適用時機

一次性回應
你只需要單次回應
不需圖片或中途控制
不需要圖片附件或 session 中途控制方法
無狀態環境
例如需要在 lambda function 這類無狀態環境中運作
限制

單次訊息輸入模式不支援: 訊息中直接附加圖片, 動態訊息佇列, 即時中斷, 自然的多輪對話.

若 query 以錯誤結果結束 (例如 error_max_turns), 單次 query() 呼叫會在產出最終結果訊息後拋出包含失敗文字的例外, 若程式需要繼續執行請用 try 區塊包住.

import { query } from "@anthropic-ai/claude-agent-sdk"; // 簡單的單次查詢 for await (const message of query({ prompt: "Explain the authentication flow", options: { maxTurns: 1, allowedTools: ["Read", "Grep"] } })) { if (message.type === "result" && message.subtype === "success") { console.log(message.result); } } // 用 session 管理延續對話 for await (const message of query({ prompt: "Now explain the authorization process", options: { continue: true, maxTurns: 1 } })) { if (message.type === "result" && message.subtype === "success") { console.log(message.result); } }
from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage import asyncio async def single_message_example(): async for message in query( prompt="Explain the authentication flow", options=ClaudeAgentOptions(max_turns=1, allowed_tools=["Read", "Grep"]), ): if isinstance(message, ResultMessage): print(message.result) async for message in query( prompt="Now explain the authorization process", options=ClaudeAgentOptions(continue_conversation=True, max_turns=1), ): if isinstance(message, ResultMessage): print(message.result) asyncio.run(single_message_example())

大多數應用建議優先採用串流輸入模式, 因為它能完整存取 agent 能力並支援即時互動. 只有在明確需要無狀態的單次回應時, 才選擇單次訊息輸入.
