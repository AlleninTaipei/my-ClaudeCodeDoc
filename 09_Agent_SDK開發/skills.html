Agent Skills in the SDK

在 Claude Agent SDK 中用 Agent Skills 擴充 Claude 的專門能力

Overview 與 How Skills Work

Agent Skills 讓 Claude 具備會被自主呼叫的專門能力, 以包含指示, 描述與可選附加資源的 SKILL.md 檔案封裝。

定義為檔案系統物件建立於 .claude/skills/ 目錄下的 SKILL.md 檔案
從檔案系統載入受 settingSources / setting_sources 控管
自動被發現啟動時發現 metadata, 觸發時才載入完整內容
由模型呼叫Claude 依情境自主決定何時使用
透過 skills 選項篩選可傳入名稱清單, "all", 或 [] 控制哪些可用
與 Subagents 的差異

Subagents 可用程式方式定義, Skills 則必須建立為檔案系統物件, SDK 沒有提供以程式註冊 Skills 的 API。

Using Skills with the SDK

透過 query() 的 skills 選項控制哪些 Skills 可用於該 session。省略時, 已發現的 Skills 會被啟用, 與 CLI 行為一致。

啟用全部
只啟用特定幾個
options = ClaudeAgentOptions(
    cwd="/path/to/project",
    setting_sources=["user", "project"],  # 從檔案系統載入 Skills
    skills="all",  # 啟用所有已發現的 Skill
    allowed_tools=["Read", "Write", "Bash"],
)
options = ClaudeAgentOptions(skills=["pdf", "docx"])

名稱需對應 SKILL.md 的 name 欄位或 Skill 的目錄名稱, plugin 提供的 Skill 用 plugin:skill 格式。

注意

skills 選項是情境過濾器, 不是沙盒。未列出的 Skill 對模型隱藏且會被 Skill 工具拒絕, 但檔案仍在磁碟上, Read 與 Bash 仍可存取。

Skill Locations

Project Skills
.claude/skills/ — 透過 git 與團隊共享, setting_sources 含 "project" 時載入
User Skills
~/.claude/skills/ — 跨所有專案的個人 Skills, setting_sources 含 "user" 時載入
Plugin Skills
隨已安裝的 Claude Code 外掛一併提供

Creating Skills

Skills 定義為包含帶有 YAML frontmatter 與 Markdown 內容的 SKILL.md 檔案的目錄, description 欄位決定 Claude 何時呼叫該 Skill。

.claude/skills/processing-pdfs/
└── SKILL.md

Tool Restrictions

注意

SKILL.md 中的 allowed-tools frontmatter 欄位只在直接使用 Claude Code CLI 時支援, 透過 SDK 使用 Skills 時不適用。SDK 中請用主要的 allowedTools 選項控制工具存取。

options = ClaudeAgentOptions(
    setting_sources=["user", "project"],
    skills="all",
    allowed_tools=["Read", "Grep", "Glob"],
)

Discovering 與 Testing Skills

要查看 SDK 應用程式中有哪些 Skills 可用, 直接詢問 Claude 即可; Claude 會依目前工作目錄與已安裝外掛列出可用 Skills。

測試方式是提出符合 Skill 描述的問題, 例如詢問「Extract text from invoice.pdf」會自動觸發 PDF 處理 Skill。

Claude 會依 description 是否符合請求, 自動呼叫相關 Skill, 不需要額外指令。

Troubleshooting

Skills Not Found檢查 settingSources 是否包含 user/project, 以及 cwd 是否指向含 .claude/skills/ 的目錄或其父目錄
Skill Not Being Used確認 skills 清單有包含該名稱 (傳入 [] 會停用全部), 並檢查 description 是否夠具體
# 檢查 Skills 是否存在
ls .claude/skills/*/SKILL.md
ls ~/.claude/skills/*/SKILL.md
