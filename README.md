# Claude Code 中文學習手冊

本專案整理並轉譯 Anthropic 官方 Claude Code 文件, 依主題劃分為十二個學習階段, 每個主題皆保留官方原文 (Markdown) , 並額外製作一份繁體中文互動式單頁課程 (HTML) , 方便循序閱讀與查閱.

## 專案簡介

Claude Code 官方文件涵蓋範圍廣, 主題間彼此獨立, 初學者不易掌握閱讀順序.
本專案的作法是先讀取官方文件清單 (見 `llms.txt`) , 依內容性質重新分類與排序 (見 `all.txt`) , 再依此順序建立資料夾, 逐篇製作對應的中文互動課程.

`index.html` 為整份手冊的導覽首頁, 可作為閱讀起點.

## 檔案格式說明

每個主題皆包含兩份檔案:

- `*.md`: 官方原文文件 (英文) , 直接對應 Claude Code 官方文件站的內容, 作為原始資料保留.
- `*.html`: 依據原文內容改寫的繁體中文互動式單頁課程, 包含說明, 重點提示與範例, 可直接以瀏覽器開啟閱讀.

根目錄另有三份輔助檔案:

- `index.html`: 整份手冊的導覽首頁, 依十二個階段列出所有主題連結.
- `llms.txt`: 官方文件站提供的完整文件清單與簡介 (原始未分類版本) .
- `all.txt`: 依學習階段重新排序後的分類規劃, 為建立資料夾結構的依據.

## 如何使用

1. 以瀏覽器開啟 `index.html`, 作為整份手冊的入口.
2. 依十二個階段的順序, 點選各主題的中文互動課程 (`.html`) 閱讀.
3. 若需查閱官方原文用詞或連結, 對照同名的 `.md` 檔案.
