Sign in with Vertex AI 登入精靈

擁有 Google Cloud 憑證時, 登入精靈會引導完成整個流程。GCP 端前置作業每個專案只需完成一次, 後續由精靈處理 Claude Code 端設定。

版本需求

Vertex AI 設定精靈需要 Claude Code v2.1.98 以上版本, 執行 claude --version 確認。

1 · 啟用模型
2 · 啟動並選擇
3 · 依精靈提示
Enable Claude models in your GCP project

先啟用 Vertex AI API, 再到 Vertex AI Model Garden 申請想要的 Claude 模型存取權。所需的 IAM 權限詳見下方 IAM configuration 段落。

Start Claude Code and choose Vertex AI

執行 claude, 在登入畫面選擇 3rd-party platform, 再選擇 Google Vertex AI。

Follow the wizard prompts

選擇驗證方式: gcloud 的 Application Default Credentials, 服務帳戶金鑰檔案, 或環境中既有的憑證。精靈會偵測專案與區域, 驗證可呼叫的模型並讓你釘選版本, 結果會寫入使用者設定檔的 env 區塊。

Step 1 of 3

登入完成後, 隨時執行 /setup-vertex 即可重新開啟精靈, 變更憑證, 專案, 區域或釘選的模型。

Region configuration 區域設定

Claude Code 支援 Vertex AI 的 global, 多區域與特定區域端點。將 CLOUD_ML_REGION 設為 global, 多區域位置如 eu 或 us, 或特定區域如 us-east5。Claude Code 會為每種形式選擇正確的 Vertex AI 主機名稱。

注意

Vertex AI 未必在每種端點類型都支援 Claude Code 的預設模型, 模型可用性依區域, 多區域位置與 global 端點而異, 可能需要切換到支援的位置或指定支援的模型。

Set up manually 手動設定

若要透過環境變數設定 Vertex AI, 例如在 CI 或自動化企業部署腳本中, 依下列步驟操作。

1 · 啟用 API
2 · 申請模型存取
3 · 設定憑證
4 · 設定 Claude Code
5 · 釘選模型版本
# 設定你的專案 ID
gcloud config set project YOUR-PROJECT-ID

# 啟用 Vertex AI API
gcloud services enable aiplatform.googleapis.com
  • 前往 Vertex AI Model Garden
  • 搜尋 "Claude" 模型
  • 申請所需 Claude 模型的存取權, 例如 Claude Sonnet 4.6
  • 等待核准 (可能需要 24 到 48 小時)

Claude Code 使用標準的 Google Cloud 驗證方式。Claude Code v2.1.121 以上支援透過相同的 Application Default Credentials 鏈結進行 X.509 憑證式 Workload Identity Federation, 將 GOOGLE_APPLICATION_CREDENTIALS 設為憑證設定檔路徑。

專案 ID 解析順序

Claude Code 使用 ANTHROPIC_VERTEX_PROJECT_ID 作為 Vertex AI 請求的專案 ID。GCLOUD_PROJECT, GOOGLE_CLOUD_PROJECT 與 GOOGLE_APPLICATION_CREDENTIALS 指向的憑證檔案優先權更高, 若都未設定, 則從 gcloud 設定或已附掛的服務帳戶解析。

Advanced credential configuration

透過 gcpAuthRefresh 設定支援 GCP 憑證自動更新, 當偵測到憑證過期或無法載入時, 會執行此指令取得新憑證後重試。

{
  "gcpAuthRefresh": "gcloud auth application-default login",
  "env": {
    "ANTHROPIC_VERTEX_PROJECT_ID": "your-project-id"
  }
}

指令的輸出會顯示給使用者, 但不支援互動式輸入, 適合瀏覽器驗證流程。更新指令逾時時間為三分鐘。若在專案設定如 .claude/settings.json 中設定, 只有在使用者接受工作區信任提示後才會執行。

# 啟用 Vertex AI 整合
export CLAUDE_CODE_USE_VERTEX=1
export CLOUD_ML_REGION=global
export ANTHROPIC_VERTEX_PROJECT_ID=YOUR-PROJECT-ID

# 選用: 覆寫自訂端點或閘道的 Vertex 端點網址
# export ANTHROPIC_VERTEX_BASE_URL=https://aiplatform.googleapis.com

# 選用: 停用 prompt caching
export DISABLE_PROMPT_CACHING=1

# 選用: 要求 1 小時 prompt cache TTL, 取代預設 5 分鐘
export ENABLE_PROMPT_CACHING_1H=1

# 當 CLOUD_ML_REGION=global 時, 為不支援 global 端點的模型覆寫區域
export VERTEX_REGION_CLAUDE_HAIKU_4_5=us-east5
export VERTEX_REGION_CLAUDE_4_6_SONNET=europe-west1

大部分模型版本都有對應的 VERTEX_REGION_CLAUDE_* 變數。Prompt caching 預設自動啟用, 停用請設 DISABLE_PROMPT_CACHING=1。使用 Vertex AI 時, /logout 指令無法使用, 因為驗證透過 Google Cloud 憑證處理。Claude Code 在 Vertex AI 上預設停用 MCP tool search, 讓 MCP 工具定義預先載入; Vertex AI 對 Claude Sonnet 4.5 以上與 Claude Opus 4.5 以上支援 tool search, 設定 ENABLE_TOOL_SEARCH=true 即可啟用。

Warning

部署給多位使用者時務必釘選特定模型版本。未釘選時, 模型別名如 sonnet 與 opus 會解析為 Claude Code 針對 Vertex AI 的內建預設值, 可能落後最新版本, 也可能尚未在你的專案啟用。

export ANTHROPIC_DEFAULT_OPUS_MODEL='claude-opus-4-8'
export ANTHROPIC_DEFAULT_SONNET_MODEL='claude-sonnet-5'
export ANTHROPIC_DEFAULT_HAIKU_MODEL='claude-haiku-4-5@20251001'
Primary model
claude-sonnet-4-5@20250929 (未釘選時的預設值)
Small/fast model
與 primary model 相同

背景任務 (如 session 標題產生) 使用小型快速模型, 通常是 Haiku 等級。在 Vertex AI 上, Claude Code 預設將其導向 primary model, 因為每個專案或區域未必都啟用 Haiku。

1M token context window VERTEX-SPECIFIC

Claude Sonnet 5, Opus 4.6 以上, 以及 Sonnet 4.6 在 Vertex AI 上支援 1M token 情境視窗。Sonnet 5 永遠以 1M 視窗執行, 沒有 [1m] 變體可選。其他模型則在選擇 1M 模型變體時自動啟用延伸情境視窗。

設定精靈會在釘選模型時提供 1M 情境選項; 若要為手動釘選的模型啟用, 在模型 ID 後方加上 [1m] 即可。

Troubleshooting 疑難排解

選擇錯誤類型:
憑證錯誤
配額問題
模型 404
429 錯誤
Could not load the default credentials

執行 gcloud auth application-default login 設定 Application Default Credentials, 或將 GOOGLE_APPLICATION_CREDENTIALS 設為服務帳戶金鑰檔案路徑。

配額問題

透過 Cloud Console 檢查目前配額或申請提高配額。

model not found 404 錯誤

確認模型已在 Model Garden 啟用; 確認模型在指定位置可用, 部分模型僅在 global 或 eu, us 等多區域提供; 若使用 CLOUD_ML_REGION=global, 確認模型支援 global 端點, 否則改用 ANTHROPIC_MODEL 指定支援的模型, 或用 VERTEX_REGION_<MODEL_NAME> 設定區域。

429 錯誤

對於特定區域端點, 確認 primary model 與 small/fast model 在所選區域皆受支援; 考慮改用 CLOUD_ML_REGION=global 以獲得更好的可用性。
