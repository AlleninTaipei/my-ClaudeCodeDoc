Claude Code 透過管理設定 (managed settings) 強制執行組織政策, 其優先權高於開發者本機的個人設定. 管理員可透過 Claude 管理主控台, 行動裝置管理系統 (MDM), 或磁碟上的檔案來傳遞這些設定, 藉此控制 Claude 可以使用哪些工具, 命令, 伺服器與網路目的地.

選擇你的 API 供應商

Claude Code 透過多個 API 供應商之一連接 Claude. 你的選擇會影響計費, 身分驗證, 你繼承的合規姿態, 以及開發者可使用哪些 Claude Code 功能.

TIP

部分功能如 Claude Code on the web, Routines, Code Review, Remote Control 與 Chrome 擴充功能, 需要 claude.ai 帳戶, 純 Console API 金鑰或雲端供應商憑證無法使用. 若透過 Bedrock, Vertex 或 Foundry 部署, 也要規劃開發者是否同時需要 Claude for Teams/Enterprise 席次.

決定設定如何送達裝置

管理設定定義的政策優先權高於本機開發者設定. Claude Code 依優先順序檢查以下四個來源, 並套用第一個回傳非空設定的來源.

Server-managed最高優先權, 全平台. 來自 claude.ai 管理主控台或自架 Claude apps gateway
plist / registry policy高優先權, macOS/Windows. 例如 HKLM\SOFTWARE\Policies\ClaudeCode
File-based managed中優先權, 全平台. 例如 /etc/claude-code/managed-settings.json
Windows user registry最低優先權, 僅 Windows. HKCU\SOFTWARE\Policies\ClaudeCode

Array 型設定 (如 permissions.allow / permissions.deny) 會合併所有來源的項目, 因此開發者可以擴充管理清單但無法移除項目. fallbackModel 與 availableModels 是例外, 管理值會直接取代較低層級而非合併.

決定要強制執行什麼

管理設定可以鎖定工具, 沙盒執行環境, 限制 MCP 伺服器與外掛來源, 並控制哪些 hooks 會執行. 每一列都是一個控制面, 附帶驅動它的設定鍵.

permissions.allow / .deny
允許, 詢問或拒絕特定工具與命令
allowManagedPermissionRulesOnly
僅套用管理權限規則, 停用 --dangerously-skip-permissions
sandbox.enabled
OS 層級的檔案系統與網路隔離, 搭配網域允許清單
allowedMcpServers / deniedMcpServers
限制使用者可新增或連線的 MCP 伺服器
strictPluginOnlyCustomization
封鎖來自使用者與專案來源的技能, 代理, hooks 與 MCP 伺服器
allowManagedHooksOnly
僅載入管理的 hooks, 限制 HTTP hook URL
availableModels / enforceAvailableModels
篩選選擇器中出現的模型, 並可約束自動選取的預設模型
minimumVersion / requiredMinimumVersion
防止自動更新安裝低於組織版本下限, 或直接拒絕啟動
重要區別

權限規則與沙盒涵蓋不同層面: 拒絕 WebFetch 只會封鎖 Claude 的 fetch 工具, 但若 Bash 被允許, curl 與 wget 仍能連到任何 URL. 沙盒用網域允許清單在 OS 層級補上這個缺口.

建立使用情況可視性

依據你要回報的內容選擇監控方式.

使用量監控

透過 OpenTelemetry 匯出 session, 工具與 token 使用量.

適用: 所有供應商

Analytics 儀表板

每位使用者的指標, 貢獻追蹤, 排行榜.

適用: 僅 Anthropic

成本追蹤

花費上限, 速率限制, 使用量歸因. 在 Anthropic 上原生支援; 在第三方雲端上, 自架 Claude apps gateway 可提供每位使用者的歸因與花費限制.

檢閱資料處理

在 Team, Enterprise, Claude API 與雲端供應商方案上, Anthropic 不會用你的程式碼或提示詞訓練模型. 你的 API 供應商決定保存與合規姿態.

資料使用政策
Anthropic 收集什麼, 保留多久, 絕不用於訓練的內容
Zero Data Retention (ZDR)
請求完成後不儲存任何內容, 適用於符合資格的 Enterprise 帳戶
安全架構
網路模型, 加密, 身分驗證, 稽核軌跡

驗證與上線
