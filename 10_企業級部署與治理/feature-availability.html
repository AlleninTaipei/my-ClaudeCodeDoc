模型可用性

說明

各供應商與地區可用的 Claude 模型與 context window 大小, 需另見 Model configuration 與 Models overview。視覺輸入, PDF 輸入與 extended thinking 屬於模型能力而非 Claude Code 功能, 只要供應商提供該模型就能使用。Prompt caching 在多數供應商上運作方式相同, 在 Bedrock 上則依模型而異。

判斷一個功能能不能用, 先確認你的驗證方式屬於哪一欄; 如果是用 claude.ai 帳號登入, 還要再對照方案等級, 兩層條件同時滿足才代表功能真正可用。
