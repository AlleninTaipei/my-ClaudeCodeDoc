Gateway Protocol Reference

Claude Code 與 LLM gateway 之間的 API 契約: 端點, 需轉發的表頭與欄位, 功能降級行為, 歸屬表頭與 model discovery

API 格式

Gateway 至少要提供下表其中一種格式. 客戶端說哪種格式, 由設定的變數決定.

Anthropic Messages
由 ANTHROPIC_BASE_URL 選用, 端點為 /v1/messages, 需轉發 anthropic-beta 與 anthropic-version 表頭
Bedrock InvokeModel
由 ANTHROPIC_BEDROCK_BASE_URL + CLAUDE_CODE_USE_BEDROCK=1 選用, 需轉發 anthropic_beta 與 anthropic_version 請求欄位
Agent Platform rawPredict
由 ANTHROPIC_VERTEX_BASE_URL + CLAUDE_CODE_USE_VERTEX=1 選用
Foundry / Claude Platform on AWS
實作 Anthropic Messages 格式, 但透過各自的 base URL 變數路由
NOTE

回應必須串流, 緩衝完整回應再轉發會使客戶端卡住. Token 計數端點是唯一可選的, 缺少時 Claude Code 會在本地估算 context 用量.

請求表頭

表頭名稱在傳輸中不分大小寫. anthropic-version 與 anthropic-beta 必須原樣轉發, 其餘可供 gateway 消費做路由或追蹤.

Authorization / x-api-key開發者的 gateway 憑證
anthropic-versionAPI 版本, 目前為 2023-06-01, 必須轉發
anthropic-beta逗號分隔的能力值, 必須逐字轉發, 不要白名單個別值
x-claude-code-session-id目前 session 的唯一識別碼, 可用來聚合同一 session 的所有請求
x-claude-code-agent-id產生請求的 subagent 識別碼, 僅在 Claude Code 生成的 agent 請求上出現

把表頭與請求主體欄位視為開放清單而非封閉清單. Claude Code 每次發布都會新增能力, 釘選觀察到的清單會在下一個能力上線時就漏轉發.

系統提示歸屬區塊

Claude Code 會在系統提示前加上一段簡短的歸屬區塊, 內含版本與對話指紋. api.anthropic.com 端點會在處理前剝除此區塊, 其他上游則會收到它作為提示的一部分.

v2.1.181+

此後區塊在整個對話生命週期保持穩定, 讓 gateway 端以完整請求主體為 key 的提示快取可以正常運作, 不需要停用歸屬表頭.

功能轉發表

點選功能查看轉發需求與異常時的症狀.

功能:
Adaptive reasoning
Context management
Extended context / interleaved thinking
Beta tool fields
Effort / structured outputs

無 beta 表頭. Claude Code 對 Claude 4.6 以上模型送出 thinking: adaptive. 若上游不支援, 會回傳 400 並提及 thinking 或 adaptive 欄位.

修復方式: 升級上游, 或在 Opus 4.6 / Sonnet 4.6 上設定 CLAUDE_CODE_DISABLE_ADAPTIVE_THINKING=1.

beta 表頭與 context_management 請求欄位成對出現. 若 gateway 轉發到 Bedrock 卻沒有橋接欄位, 會出現 400 Extra inputs are not permitted.

修復方式: 兩者都轉發, 或設定 CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1.

只有 beta 表頭, 沒有請求主體欄位. 表頭被剝除時會悄悄地無法使用, 上游永遠不會看到能力請求.

修復方式: 逐字轉發 anthropic-beta.

工具相關 beta 表頭與 strict, defer_loading 等工具結構欄位成對. 主體通過但表頭被剝除時, 會出現命名該欄位的 400.

修復方式: 兩者都轉發, 或 CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1.

output_config 請求欄位帶有 effort, 結構化輸出格式與任務預算設定, 各自搭配自己的 beta 表頭. 在 Bedrock 與 Agent Platform 上游常見 400 提及 output_config.

修復方式: 欄位與表頭一起轉發.

Model Discovery

當 ANTHROPIC_BASE_URL 指向支援 Anthropic Messages 格式的 gateway 時, Claude Code 可以在啟動時查詢 gateway 的 /v1/models 端點.

1 · 啟用
2 · 請求與回應
3 · 選單與快取

開發者設定 CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1 才會啟用, 預設關閉, 避免共用金鑰把每個模型都曝露給每位使用者. 需要 v2.1.129 以上.

GET /v1/models?limit=1000  // 3 秒逾時, 任何重新導向都視為失敗

{
  "data": [
    { "id": "claude-sonnet-4-6", "display_name": "Claude Sonnet 4.6" }
  ]
}

每個發現到的項目標示為 From gateway, 結果快取到 ~/.claude/cache/gateway-models.json, 每次啟動時重新整理. 查詢失敗則回退到快取清單或內建模型清單.
