Enterprise Network Configuration

了解如何透過環境變數為 Claude Code 設定企業網路環境, 包含 proxy, 自訂憑證與 mTLS 驗證。

Proxy configuration

Claude Code 支援標準的 proxy 環境變數, 也可以在 settings.json 中設定同樣的值。

選擇要查看的設定:
環境變數
基本驗證
# HTTPS proxy (recommended)
export HTTPS_PROXY=https://proxy.example.com:8080

# HTTP proxy (if HTTPS not available)
export HTTP_PROXY=http://proxy.example.com:8080

# Bypass proxy for specific requests - space-separated format
export NO_PROXY="localhost 192.168.1.1 example.com .example.com"
# Bypass proxy for specific requests - comma-separated format
export NO_PROXY="localhost,192.168.1.1,example.com,.example.com"
# Bypass proxy for all requests
export NO_PROXY="*"
NOTE

Claude Code 不支援 SOCKS proxy。

若 proxy 需要基本驗證, 可將帳密直接包含在 proxy URL 中:

export HTTPS_PROXY=http://username:password@proxy.example.com:8080
WARNING

避免將密碼硬編在腳本中, 建議改用環境變數或安全的憑證儲存機制。

TIP

若 proxy 需要進階驗證方式 (NTLM, Kerberos 等), 可考慮使用支援該驗證方式的 LLM Gateway 服務。

CA certificate store

Claude Code 預設同時信任內建的 Mozilla CA 憑證與作業系統的憑證存放區。讀取 OS 存放區需要支援 tls.getCACertificates 的執行環境: 原生安裝程式一律支援, npm 安裝則需要 Node 22.15 以上版本。

CLAUDE_CODE_CERT_STORE 接受以逗號分隔的來源清單, 預設值為 bundled,system:

選擇信任來源:
bundled
system

只信任 Claude Code 內建的 Mozilla CA 憑證集合:

export CLAUDE_CODE_CERT_STORE=bundled

只信任作業系統的憑證存放區:

export CLAUDE_CODE_CERT_STORE=system
NOTE

CLAUDE_CODE_CERT_STORE 沒有專屬的 settings.json schema 鍵, 需透過 ~/.claude/settings.json 的 env 區塊或直接設定於行程環境中。

Custom CA certificates

若企業環境使用自訂 CA, 可直接設定 Claude Code 信任它:

export NODE_EXTRA_CA_CERTS=/path/to/ca-cert.pem

mTLS authentication

企業環境若需要用戶端憑證驗證, 可設定以下三個環境變數:

CLAUDE_CODE_CLIENT_CERT
用於驗證的客戶端憑證檔案路徑
CLAUDE_CODE_CLIENT_KEY
客戶端私鑰檔案路徑
CLAUDE_CODE_CLIENT_KEY_PASSPHRASE
選用, 加密私鑰的密語
# Client certificate for authentication
export CLAUDE_CODE_CLIENT_CERT=/path/to/client-cert.pem

# Client private key
export CLAUDE_CODE_CLIENT_KEY=/path/to/client-key.pem

# Optional: Passphrase for encrypted private key
export CLAUDE_CODE_CLIENT_KEY_PASSPHRASE="your-passphrase"

Network access requirements

Claude Code 需要存取以下網址, 請在 proxy 設定與防火牆規則中將它們加入允許清單, 特別是在容器化或受限的網路環境中。

api.anthropic.comClaude API 請求
claude.aiclaude.ai 帳戶驗證
platform.claude.comAnthropic Console 帳戶驗證
downloads.claude.ai外掛執行檔下載, 原生安裝程式與自動更新
storage.googleapis.com2.1.116 之前版本的原生安裝程式與自動更新
bridge.claudeusercontent.comClaude in Chrome 擴充功能的 WebSocket bridge
*.claudeusercontent.com於 claude.ai 檢視 artifacts, 僅瀏覽器端需要
raw.githubusercontent.com/release-notes 的變更紀錄與外掛市集安裝計數

若透過 npm 安裝 Claude Code 或自行管理二進位檔散布, 使用者可能不需要存取 downloads.claude.ai 或 storage.googleapis.com。

TIP

Claude Code 預設會傳送選用的操作遙測資料, 可透過環境變數停用。使用 Bedrock, Vertex AI, Foundry 或已登入的 Claude apps gateway 時, 模型流量與驗證會改連往你的提供者或 gateway, 而非 api.anthropic.com。
