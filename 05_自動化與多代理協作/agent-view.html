Agent View 多代理管理

在同一個畫面派發並管理多個 Claude Code session, 一眼看出哪個在工作, 哪個需要你介入, 哪個已完成。

# 從你的 shell 執行
claude agents

Agent view 會開啟一個底部輸入框和一張逐步填入的表格。隨時按 Esc 回到 shell, 你的 session 在你離開時仍持續執行, 下次開啟 agent view 會重新出現。

輸入描述任務的提示詞並按下 Enter。新的背景 session 會開始執行該任務, 並顯示為一列, 標示正在工作, 等待你, 或已完成。新 session 使用 agent view 表頭顯示的模型與權限模式。

注意

每個 session 各自消耗你的訂閱額度, 大量平行派發前請先參考限制章節。

用方向鍵選取一列, 按 Space 開啟窺看面板, 顯示 session 最新輸出或正在等待的問題。輸入回覆並按 Enter 即可送出, 不需要離開 agent view。

在選取的列上按 Enter 進入完整互動 session。附著時 Claude 會先簡述你離開期間發生的事。在空白輸入框按對應鍵可離開回到列表, session 仍會持續在背景執行。

要把現有的 session 移入 agent view, 在該 session 內執行 /bg, 或在空白輸入框按下對應鍵一步完成背景化並開啟 agent view。

Step 1 of 5

監控 Session 狀態

每一列開頭的圖示顏色與動畫顯示 session 狀態, 形狀則另外顯示底層行程是否存活。

Working動畫圖示, Claude 正在執行工具或產生回應
Needs input黃色, 正在等待你的問題或權限決定
Idle變暗, 已無事可做, 準備好接收下一個提示
Completed綠色, 任務成功結束
Failed紅色, 任務以錯誤結束
Stopped灰色, 以 Ctrl+X 或 claude stop 停止

組織與篩選

組織列表

Ready for review 與 Needs input 排在 Working 與 Completed 之前。按 Ctrl+S 改依目錄分組, 按 Ctrl+T 釘選 session 並保持其行程存活。

篩選

在派發輸入框輸入 a:<name> 篩選特定 subagent, s:<state> 篩選狀態, 或貼上 PR 網址直接定位該 session。

一列的摘要文字由 Haiku 級模型產生, 不用打開完整逐字稿就能知道 session 在做什麼, 需要什麼, 或已產出什麼。

派發新的 Agent

可以從 agent view 派發, 從既有 session 送到背景, 或直接從 shell 啟動。

選擇派發方式
從 Agent View
從 Session 內部
從 Shell

在 agent view 底部輸入框輸入提示詞並按 Enter。session 會依提示詞自動命名, 稍後可用 Ctrl+R 重新命名。貼上圖片即可附上截圖或圖表。

<agent-name> <prompt>
第一個字若符合自訂 subagent 名稱, 就以該 subagent 作為主要 agent
@<repo>
在提示詞中提及儲存庫, 讓 session 在該處執行
! <command>
以背景工作執行 shell 指令, 而非啟動 Claude session
Shift+Enter
派發並立即進入該 session
# 在 session 內執行, 移入背景並可先給一則額外指示
/bg run the test suite and fix any failures

背景化會啟動一個從已存檔對話恢復的全新行程, 進行中的背景 shell 指令, 已背景化的 subagent, 動態工作流程與排程任務都會一併帶過去繼續執行。

claude --bg "investigate the flaky SettingsChangeDetector test"

# 指定顯示名稱
claude --bg --name "flaky-test-fix" "investigate the flaky test"

從 Shell 管理 Session

每個背景 session 都有一組短 ID, 可用於腳本化操作或不想開啟 agent view 時使用。

claude agents
開啟 agent view
claude attach <id>
在此終端機附著到某個 session
claude logs <id>
印出該 session 最近的輸出
claude stop <id>
停止一個 session, 也接受 claude kill
claude respawn <id>
保留對話重新啟動 session
claude rm <id>
從列表移除 session
claude daemon status
印出監督行程的狀態, 版本與 worker 數

背景 Session 如何運作

所有背景 session 由每位使用者一個的監督行程 (supervisor) 代管, 與你的終端機和 agent view 分離, 首次背景化或開啟 agent view 時自動啟動。

保持存活的條件

正在工作, 等待輸入, 或有終端機附著的 session 會保持行程存活。背景 shell 指令, subagent, 動態工作流程或 monitor 都算作有效工作。

閒置回收

完成後閒置約一小時, 監督行程會停止其行程以釋放資源, 已釘選的 session 則不受影響, 下次附著時會從中斷處重新啟動。

狀態儲存位置

~/.claude/jobs/<id>/state.json 保存每個 session 的狀態, ~/.claude/daemon/roster.json 記錄執行中背景 session 清單, 用於重啟後重新連線。

限制

Agent view 目前為研究預覽階段, 有以下限制:

額度共用背景 session 與互動 session 一樣消耗訂閱額度, 十個平行執行約消耗十倍額度
僅限本機背景 session 在你的機器上執行, 可撐過睡眠但機器關機就會停止
刪除即清除 worktree刪除有 Claude 建立 worktree 的 session 前, 記得先合併或推送變更

把 agent view 想成任務調度台: 派發, 觀察, 只在真正需要你時才介入, 其餘時間讓 Claude 在背景自主工作。
