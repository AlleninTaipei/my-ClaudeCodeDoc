用 Channels 推送事件

透過 MCP server 把訊息, 警報, webhook 推入正在執行的 Claude Code session, 讓 Claude 在你不在時也能做出反應。

支援的頻道

每個受支援的頻道都是一個外掛, 需要 Bun。以下比較三種內建頻道的設定流程。

選擇頻道

Discord

Fakechat 快速體驗

fakechat 是官方支援的展示頻道, 在 localhost 執行聊天介面, 不需要任何驗證或外部服務。

# 安裝並啟用
/plugin install fakechat@claude-plugins-official
claude --channels plugin:fakechat@claude-plugins-official

開啟 http://localhost:8787 輸入訊息, 訊息會以 <channel source="fakechat"> 事件抵達你的 session, Claude 讀取, 完成工作後呼叫 fakechat 的 reply 工具, 答案顯示回聊天介面。

安全提醒

若 Claude 在你離開終端機時遇到權限提示, session 會暫停等待回應。宣告 permission relay 能力的頻道可以把提示轉發到你的手機。

安全機制

每個核准的頻道外掛都維護寄件人白名單, 只有你新增的 ID 能推送訊息, 其他一律被靜默丟棄。

Telegram / Discord
透過配對流程建立白名單: 傳訊息, 取得配對碼, 在 session 中核准
iMessage
傳訊息給自己會自動略過閘門, 其他聯絡人以 /imessage:access allow 加入

光是出現在 .mcp.json 裡還不夠, server 還必須被列在 --channels 中才能推送訊息。

企業控制

管理員透過兩個受管設定控制可用性, 使用者無法覆寫。

channelsEnabled
總開關, 必須為 true 才能讓任何頻道送出訊息
allowedChannelPlugins
哪些外掛可以在頻道啟用後註冊, 會取代 Anthropic 預設清單

研究預覽階段

Channels 目前處於研究預覽, 逐步推出中, --channels 的旗標語法與協定合約可能因回饋而調整。使用 --dangerously-load-development-channels 可測試自建頻道。

與其他功能的比較

Claude Code on the web

在全新雲端沙箱執行任務, 適合委派可自行完成的非同步工作。

Claude in Slack

從頻道或討論串的 @Claude 提及啟動網頁 session。

標準 MCP server

Claude 在任務中主動查詢, 不會有事件被推入 session。

Remote Control

從 claude.ai 或手機 App 遠端操控你本機的 session。

Channels 補上的缺口是把非 Claude 來源的事件推入你已經在執行的本機 session。
