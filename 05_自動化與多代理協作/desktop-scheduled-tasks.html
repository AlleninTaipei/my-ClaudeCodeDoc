Desktop 排程任務

在 Claude Code Desktop 設定週期性任務, 讓 Claude 定時自動執行每日程式碼審查, 依賴套件稽核, 或早晨簡報。

比較排程選項

不需要本機機器時用雲端任務, 需要存取本機檔案與工具時用 Desktop 任務, session 內快速輪詢時用 /loop。

建立排程任務

點擊側欄 Routines, 再點 New routine 並選擇 Local。

Name
任務識別名稱, 會轉為小寫連字號並作為磁碟上的資料夾名稱, 需唯一
Description
顯示在任務清單中的簡短摘要
Instructions
任務執行時 Claude 該做的事, 寫法就像在提示框中輸入訊息
Schedule
執行頻率, 見下方排程選項
提示

也可以直接在任何 session 中描述需求, 例如「設定每天早上 9 點的每日程式碼審查」自動建立週期性任務。

排程選項

Manual無排程, 只在點擊 Run now 時執行
Hourly每小時執行一次
Daily顯示時間選擇器, 預設當地時間上午 9 點
Weekdays同 Daily 但略過週六週日
Weekly顯示時間選擇器與星期選擇器

排程任務如何執行

Desktop 在應用程式開啟時每分鐘檢查一次排程, 任務到期時啟動全新 session。每個任務有幾分鐘的確定性延遲以分散 API 流量。

觸發後

你會收到桌面通知, 新 session 出現在側欄 Scheduled 區塊, Claude 可以編輯檔案, 執行指令, 建立提交或開啟 PR。

睡眠限制

只有應用程式執行中且電腦未睡眠時任務才會觸發, 開啟 Keep computer awake 可避免閒置睡眠。

錯過的執行

應用程式啟動或電腦喚醒時, Desktop 會檢查過去七天內是否有錯過的執行, 若有則啟動一次補跑, 只補最近一次錯過的時間, 更早的會被捨棄。

寫提示詞時注意

排定 9 點的任務若電腦整天睡眠, 可能在晚上 11 點才執行。可在提示詞加入防護, 例如「只審查今天的提交, 若已過下午 5 點就只回報摘要」。

排程任務的權限

每個任務有自己的權限模式, ~/.claude/settings.json 的允許規則也會套用到排程任務 session。若任務為 Ask 模式且需要未授權工具, 執行會停滯直到你核准。

建立任務後先點 Run now, 對每個權限提示選擇 always allow, 後續執行就會自動核准相同工具。
