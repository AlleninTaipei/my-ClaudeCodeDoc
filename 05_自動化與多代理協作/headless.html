用程式化方式執行 Claude Code

透過 Agent SDK 的 CLI 介面在腳本或 CI/CD 中非互動地執行 Claude Code。

基本用法

在任何 claude 指令加上 -p (或 --print) 旗標即可非互動執行, 所有 CLI 選項都能搭配 -p 使用。

claude -p "Find and fix the bug in auth.py" --allowedTools "Read,Edit,Bash"

用 Bare 模式加速啟動

加上 --bare 可跳過 hooks, skills, plugins, MCP servers, auto memory, CLAUDE.md 的自動探索, 縮短啟動時間, 適合需要每台機器結果一致的 CI 與腳本。

--append-system-prompt
載入系統提示附加內容
--settings
載入設定檔或 JSON
--mcp-config
載入 MCP servers
--plugin-dir
載入外掛
認證

Bare 模式會跳過 OAuth 與 keychain 讀取, Anthropic 認證必須來自 ANTHROPIC_API_KEY 或 --settings 中的 apiKeyHelper。

範例

以下範例展示常見的 CLI 用法, 為腳本化呼叫加上 --bare 可避免撿到本機恰好設定的內容。

管線資料
建置腳本

延續對話
cat build-error.txt | claude -p 'concisely explain the root cause' > output.txt

非互動模式讀取 stdin, 可像其他命令列工具一樣管線輸入輸出。piped stdin 上限為 10MB。

{
  "scripts": {
    "lint:claude": "git diff main | claude -p \"you are a typo linter...\""
  }
}

管線傳入 diff 讓 Claude 不需要 Bash 權限讀取檔案, 逸出雙引號讓腳本可跨 Windows 使用。

claude -p "Extract the main function names from auth.py" \
  --output-format json \
  --json-schema '{"type":"object","properties":{"functions":{"type":"array"}}}'

--output-format text/json/stream-json 三種格式, 搭配 --json-schema 可取得符合特定結構的 structured_output 欄位。

claude -p "Write a poem" --output-format stream-json --verbose --include-partial-messages

每行是一個代表事件的 JSON 物件, 可用 jq 篩選 text_delta 即時顯示生成中的文字。

claude -p "Run the test suite and fix any failures" \
  --allowedTools "Bash,Read,Edit"

--permission-mode acceptEdits 可設定整個 session 的基準模式, 自動核准常見檔案系統指令。

claude -p "Look at my staged changes and create an appropriate commit" \
  --allowedTools "Bash(git diff *),Bash(git commit *)"

尾端的空格加 * 啟用前綴比對, Bash(git diff *) 允許任何以 git diff 開頭的指令。

claude -p "Review this codebase for performance issues"
claude -p "Now focus on the database queries" --continue

--continue 延續最近一次對話, --resume <id> 延續指定的對話。

結束時的背景任務

若 Claude 在 claude -p 執行期間啟動背景 Bash 任務, 該 shell 會在 Claude 回傳最終結果並關閉 stdin 後約五秒被終止, 讓剛好結束的任務仍能送出輸出。

背景 subagent 與工作流程豁免這五秒寬限, 因為它們的結果是最終輸出的一部分, claude -p 會等待它們完成, 預設上限十分鐘。
