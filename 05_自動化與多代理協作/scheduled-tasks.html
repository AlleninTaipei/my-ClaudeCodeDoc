比較三種排程方式

Claude Code 提供三種排程重複或一次性工作的方式, 各自適合不同情境。

選擇比較維度: 執行位置 持續性 存取與權限
Cloud (Routines)

執行於 Anthropic 雲端

不需要機器保持開機

不需要開啟 session

Desktop

執行於你自己的機器

需要機器開機

不需要開啟 session

Cloud / Desktop

重新啟動後仍持續存在

可透過 /schedule 自訂排程

/loop

在未過期前, --resume 可還原

最短間隔 1 分鐘

Cloud

無法存取本機檔案 (全新 clone)

不會出現權限提示, 自主執行

Desktop / /loop

可存取本機檔案與工具

權限提示可依設定或繼承 session

建議

需要不依賴機器穩定執行的工作用 Cloud tasks；需要本機檔案存取用 Desktop tasks；session 內快速輪詢用 /loop。

用 /loop 重複執行提示詞

/loop 是在 session 保持開啟時重複執行提示詞最快的方式。你提供的內容決定了 loop 的行為。

1 · 間隔+提示詞
2 · 只給提示詞
3 · 都不給
/loop 5m check the deploy

提示詞會依照固定排程 (cron) 執行。間隔可用 30m 這種前置寫法, 或 every 2 hours 這種子句寫法。支援單位: s, m, h, d。

/loop check whether CI passed and address any review comments

Claude 會依觀察動態選擇間隔 (1 分鐘到 1 小時之間), 建置中等待較短, 平靜時等待較長, 並在每次迭代結束時說明選擇的延遲與原因。

/loop

Claude 使用內建維護提示詞: 依序完成未完成工作, 處理目前分支 PR 的評論與失敗的 CI, 執行清理 (bug 排查, 簡化)。可用 .claude/loop.md 或 ~/.claude/loop.md 取代預設提示詞。

設定一次性提醒

對於一次性提醒, 用自然語言描述即可, 不需要 /loop。Claude 會排定一個單次觸發, 執行完自動刪除的任務。

// 範例一
remind me at 3pm to push the release branch

// 範例二
in 45 minutes, check whether the integration tests passed
機制

Claude 會把觸發時間釘在特定的分鐘與小時, 用 cron 表達式表示, 並確認何時會觸發。

管理排程任務

可以用自然語言請 Claude 列出或取消任務, 底層則是三個工具在運作。

CronCreate
建立新任務, 接受 5 欄位 cron 表達式, 要執行的提示詞, 以及是否重複
CronList
列出所有排程任務, 含 ID, 排程與提示詞
CronDelete
依 ID 取消任務

每個任務有 8 碼 ID, 一個 session 最多可保存 50 個排程任務。

排程任務如何執行

排程器每秒檢查一次到期任務, 並以低優先權排入佇列。所有時間以你的本機時區解讀。

觸發時機在你的回合之間觸發, 不會在 Claude 回應中途觸發; 若 Claude 忙碌, 提示詞等到當前回合結束才觸發
Jitter (重複任務)最多延後 30 分鐘觸發 (每小時多次執行的任務則延後至多半個間隔)
Jitter (一次性任務)整點或半點排定的任務, 最多提前 90 秒觸發
七天到期重複任務建立 7 天後自動到期, 最後觸發一次即自動刪除
技巧

若要精準控時, 選擇不是整點或半點的分鐘, 例如 3 9 * * * 而非 0 9 * * *, 就不會套用一次性 jitter。

Cron 表達式參考

CronCreate 接受標準 5 欄位 cron 表達式: 分 時 日 月 星期。

*/5 * * * *每 5 分鐘
0 * * * *每個整點
0 9 * * *每天本機時間上午 9 點
0 9 * * 1-5平日上午 9 點
30 14 15 3 *3 月 15 日下午 2:30

星期以 0 或 7 代表週日, 6 代表週六。不支援 L, W, ? 等擴充語法或 MON, JAN 等別名。

限制與替代方案

Session 範圍的排程有幾項固有限制。

僅在閒置時觸發關閉終端機或結束 session 就會停止觸發
不補跑錯過的觸發時間不會補跑, 只會在 Claude 閒置時觸發一次
新對話清除任務--resume 或 --continue 只會還原未過期的任務

需要真正不受人看管執行的自動化, 改用 Routines (雲端排程), GitHub Actions 的 schedule 觸發, 或 Desktop 排程任務。
