用 Ultraplan 在雲端規劃

從 CLI 啟動規劃, 在 Claude Code on the web 上草擬計畫, 再遠端或回到終端機執行

什麼是 Ultraplan

Ultraplan 把規劃工作從本機 CLI 交給雲端的 Claude Code on the web session, 以 plan mode 執行。Claude 在雲端草擬計畫, 你可以繼續在終端機工作。計畫完成後, 在瀏覽器開啟, 針對特定段落留言, 要求修改, 並選擇在哪裡執行。

Targeted feedback
針對計畫的特定段落留言, 而非回覆整份計畫
Hands-off drafting
計畫在遠端產生, 終端機保持空閒可做其他工作
Flexible execution
核准計畫後在網頁執行並開 PR, 或送回終端機
前提

需要 Claude Code on the web 帳號與 GitHub 儲存庫。因為執行於 Anthropic 雲端基礎設施, 不支援 Amazon Bedrock, Google Cloud Vertex AI, 或 Microsoft Foundry。

從 CLI 啟動 Ultraplan

三種啟動方式各自適合不同情境。

選擇啟動方式: 指令 關鍵字 本機計畫轉送 
/ultraplan migrate the auth service from sessions to JWTs

執行 /ultraplan 加上你的提示詞, 直接啟動雲端規劃 session。

// 在一般提示詞中包含 ultraplan 這個字即可觸發
use ultraplan to plan the migration

Claude 完成本機計畫並顯示核准對話框時, 選擇「No, refine with Ultraplan on Claude Code on the web」, 把草稿送到雲端繼續迭代。這個路徑會跳過確認對話框, 因為選擇本身已是確認。

注意

若 Remote Control 正在使用中, ultraplan 啟動時會斷線, 因為兩者共用 claude.ai/code 介面, 一次只能連接一個。

CLI 狀態指示器

雲端 session 啟動後, 終端機的提示詞輸入框會顯示狀態。

??ultraplanClaude 正在研究程式碼庫並草擬計畫
??ultraplan needs your inputClaude 有澄清問題, 需要開啟 session 連結回應
??ultraplan ready計畫已就緒, 可在瀏覽器中檢閱

執行 /tasks 並選擇 ultraplan 項目, 可打開詳細畫面: session 連結, agent 活動記錄, 與「Stop ultraplan」動作。

在瀏覽器中檢閱與修改計畫

狀態變成 ready 後, 開啟 session 連結在 claude.ai 檢視計畫, 有專屬的檢閱畫面。

Inline comments反白任何段落, 留言請 Claude 處理
Emoji reactions對段落表達贊同或疑慮, 不需完整留言
Outline sidebar在計畫各段落間快速跳轉

請 Claude 處理留言後, 會呈現修改後的草稿, 可反覆迭代直到滿意再選擇執行位置。

選擇在哪裡執行

計畫確認無誤後, 從瀏覽器選擇要在雲端 session 中實作, 或送回終端機。

在網頁執行

選擇「Approve Claude's plan and start coding」

Claude 在同一個雲端 session 中實作

完成後於網頁介面檢閱差異並建立 PR

送回終端機

選擇「Approve plan and teleport back to terminal」

本機實作, 完整存取你的環境

網頁 session 會被歸檔, 不會並行繼續工作

送回終端機後, 對話框「Ultraplan approved」提供三個選項: Implement here (注入目前對話繼續), Start new session (清空對話, 只用計畫作為上下文開始), Cancel (只把計畫存成檔案, 不執行)。

選擇 Start new session 時, Claude 會在最上方印出 claude --resume 指令, 方便之後回到先前的對話。
