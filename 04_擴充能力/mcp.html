Connect Claude Code to tools via MCP

Learn how to connect Claude Code to your tools with the Model Context Protocol.

What you can do with MCP

MCP servers give Claude Code access to your tools, databases, and APIs. Connect a server when you find yourself copying data into chat from another tool — Claude can then read and act on that system directly.

Implement features"Add the feature described in JIRA issue ENG-4521 and create a PR on GitHub."
Analyze monitoring data"Check Sentry and Statsig to check the usage of feature ENG-4521."
Query databases"Find emails of 10 random users who used ENG-4521, based on our PostgreSQL database."
Integrate designs"Update our email template based on new Figma designs posted in Slack."
Automate workflows"Create Gmail drafts inviting these 10 users to a feedback session."
React to external eventsAn MCP server can act as a channel pushing Telegram/Discord/webhook messages into your session

Find and build MCP servers

Browse reviewed connectors in the Anthropic Directory — add any remote server listed there with claude mcp add.

WARNING

Verify you trust each server before connecting it. Servers that fetch external content can expose you to prompt injection risk.

Have Claude scaffold a server with the official mcp-server-dev plugin:

/plugin install mcp-server-dev@claude-plugins-official
/reload-plugins
/mcp-server-dev:build-mcp-server

Installing MCP servers

Transport:
HTTP
SSE (deprecated)
stdio
WebSocket

Recommended for remote, cloud-based services.

claude mcp add --transport http notion https://mcp.notion.com/mcp

claude mcp add --transport http secure-api https://api.example.com/mcp \
  --header "Authorization: Bearer your-token"

In JSON config, type accepts streamable-http as an alias for http. A url with no type is an error: Claude Code reads it as stdio and skips it.

DEPRECATED

Use HTTP servers instead, where available.

claude mcp add --transport sse asana https://mcp.asana.com/sse

claude mcp add --transport sse private-api https://api.company.com/sse \
  --header "X-API-Key: your-key-here"

Run as local processes — ideal for tools needing direct system access. Claude Code sets CLAUDE_PROJECT_DIR in the server's environment.

claude mcp add [options] <name> -- <command> [args...]

claude mcp add --env AIRTABLE_API_KEY=YOUR_KEY --transport stdio airtable \
  -- npx -y airtable-mcp-server
SEPARATE WITH --

Everything after -- is passed to the server untouched. Without it, Claude Code would try to parse the server's own flags as its own options.

Persistent bidirectional connection for servers that push events unprompted. Use HTTP instead when the server only responds to requests (HTTP supports OAuth; WebSocket doesn't).

claude mcp add-json events-server \
  '{"type":"ws","url":"wss://mcp.example.com/socket","headers":{"Authorization":"Bearer YOUR_TOKEN"}}'

Managing your servers

claude mcp list
claude mcp get github
claude mcp remove github
/mcp   # within Claude Code

Project-scoped servers awaiting approval show as ⏸ Pending approval in claude mcp list. As of v2.1.196, approvals from an untracked-in-git settings file are required in an untrusted folder — a cloned repo can't approve its own servers.

Plugin-provided MCP servers

// .mcp.json at plugin root
{ "mcpServers": { "database-tools": {
  "command": "${CLAUDE_PLUGIN_ROOT}/servers/db-server",
  "args": ["--config", "${CLAUDE_PLUGIN_ROOT}/config.json"],
  "env": { "DB_URL": "${DB_URL}" } } } }

Tool callable name: mcp__plugin_<plugin-name>_<server-name>__<tool>. Server registers as plugin:<plugin-name>:<server-name>.

MCP installation scopes

Local (default)Current project only, not shared, stored in ~/.claude.json
ProjectCurrent project only, shared via .mcp.json in version control
UserAll your projects, not shared, stored in ~/.claude.json
claude mcp add --transport http stripe --scope local https://mcp.stripe.com
claude mcp add --transport http paypal --scope project https://mcp.paypal.com/mcp
claude mcp add --transport http hubspot --scope user https://mcp.hubspot.com/anthropic

Project-scoped servers from .mcp.json need approval before use; reset choices with claude mcp reset-project-choices.

Scope hierarchy and precedence

When the same server is defined more than once, the highest-precedence definition is used whole (fields aren't merged):

1. Local scopeHighest precedence
2. Project scope
3. User scope
4. Plugin-provided servers
5. claude.ai connectorsLowest precedence

The three scopes match by name; plugins and connectors match by endpoint URL/command.

Environment variable expansion in .mcp.json

{ "mcpServers": { "api-server": {
  "type": "http", "url": "${API_BASE_URL:-https://api.example.com}/mcp",
  "headers": { "Authorization": "Bearer ${API_KEY}" } } } }

Supported: ${VAR} and ${VAR:-default}, expandable in command, args, env, url, headers. Parsing fails if a required variable has no value and no default.

Authenticate with remote MCP servers

Claude Code supports OAuth 2.0. A server is marked as needing auth when it returns 401 or 403, flagged in /mcp.

Browser flow
CLI login
Fixed callback port
Pre-configured credentials
Override discovery / scopes
Dynamic headers
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
/mcp   # follow browser login

In non-interactive mode, Claude Code (v2.1.196+, with tool search) tells Claude the server's tools are unavailable until authorized, instead of responding as if it weren't configured.

claude mcp login sentry
claude mcp login sentry --no-browser
claude mcp logout sentry

v2.1.191+ detects no local browser (SSH, headless Linux) and prints the URL instead; needs an interactive terminal (ssh -t) for the paste step.

claude mcp add --transport http --callback-port 8080 my-server https://mcp.example.com/mcp

Fixes the OAuth callback port to match a pre-registered redirect URI http://localhost:PORT/callback. Usable alone (dynamic client registration) or with --client-id.

claude mcp add --transport http \
  --client-id your-client-id --client-secret --callback-port 8080 \
  my-server https://mcp.example.com/mcp

For servers without Dynamic Client Registration or Client ID Metadata Document support. Secret is stored in the system keychain or a credentials file.

{ "mcpServers": { "my-server": { "type": "http", "url": "https://mcp.example.com/mcp",
  "oauth": { "authServerMetadataUrl": "https://auth.example.com/.well-known/openid-configuration" } } } }
{ "oauth": { "scopes": "channels:read chat:write search:read" } }

authServerMetadataUrl bypasses default discovery (RFC 9728 → RFC 8414). oauth.scopes pins the requested scope set, taking precedence over discovered scopes.

{ "mcpServers": { "internal-api": { "type": "http", "url": "https://mcp.internal.example.com",
  "headersHelper": "/opt/bin/get-mcp-auth-headers.sh" } } }

For Kerberos, short-lived tokens, or internal SSO. The command must write a JSON object to stdout, runs in a shell with a 10-second timeout, and re-runs fresh on every connection.

Import MCP servers from Claude Desktop

claude mcp add-from-claude-desktop
claude mcp list

macOS and WSL only. Names with characters outside letters/numbers/hyphens/underscores are rejected and reported; others still import (before v2.1.205, one bad name stopped the whole import). Colliding names get a numeric suffix.

Use MCP servers from claude.ai

Servers added at claude.ai/customize/connectors (admin-only on Team/Enterprise) become available automatically when logged in with a claude.ai account. View in /mcp.

Connectors are fetched only when the active authentication method is your claude.ai subscription — not with ANTHROPIC_API_KEY, apiKeyHelper, Bedrock, or Google Cloud's Agent Platform.

{ "disableClaudeAiConnectors": true }

Any-source-true semantics: true anywhere disables connectors; a lower-scope false can't re-enable. Or set ENABLE_CLAUDEAI_MCP_SERVERS=false for a shell session.

Use Claude Code as an MCP server

claude mcp serve
{ "mcpServers": { "claude-code": { "type": "stdio", "command": "claude", "args": ["mcp", "serve"] } } }
WARNING

The command field must reference the Claude Code executable — use `which claude` to find the full path if `claude` is not in PATH, or you'll get `spawn claude ENOENT`.

Exposes Claude's tools (View, Edit, LS, etc.) to your MCP client; your client is responsible for user confirmation of individual tool calls.

MCP output limits and warnings

Warning threshold10,000 tokens
Default limit25,000 tokens (MAX_MCP_OUTPUT_TOKENS)
Per-tool override_meta["anthropic/maxResultSizeChars"], up to 500,000 chars, text content only
export MAX_MCP_OUTPUT_TOKENS=50000

Useful for servers querying large datasets, generating detailed reports, or processing extensive logs. Without the annotation, oversized results are persisted to disk and replaced with a file reference.

Tool input schemas with a root-level combinator

The Claude API rejects anyOf/oneOf/allOf at a tool schema's root (nested inside properties is fine). As of v2.1.195, Claude Code flattens the schema and prepends a description sentence instead of skipping the tool entirely:

allOfProperties from every branch merged; each branch's required list still applies
anyOf / oneOfProperties merged; required lists described in text, not enforced by schema

Before v2.1.195, every tool with a root-level combinator was skipped entirely.

Require approval for a specific tool

{ "name": "grant_access", "description": "Requests access to a protected resource",
  "_meta": { "anthropic/requiresUserInteraction": true } }

Server authors set this so the tool's permission prompt shows on every call, even in acceptEdits/auto/bypassPermissions modes, with no "don't ask again." In dontAsk mode, the call is denied. Requires v2.1.199+.

Respond to MCP elicitation requests

Servers can request structured input mid-task. No configuration is required — dialogs appear automatically.

Form mode

A dialog with server-defined fields (e.g. username/password). Fill in and submit.

URL mode

Opens a browser URL for authentication or approval; confirm in the CLI after completing.

Use the Elicitation hook to auto-respond without showing a dialog.

Scale with MCP tool search

Keeps MCP context usage low by deferring tool definitions until Claude needs them — only tool names and server instructions load at session start.

(unset, default)All deferred; falls back to upfront on Google Cloud Agent Platform or non-first-party ANTHROPIC_BASE_URL
trueAll deferred, forced even through proxies (may fail if unsupported)
auto / auto:NThreshold mode — load upfront if within 10% (or N%) of context window
falseAll tools loaded upfront, no deferral
ENABLE_TOOL_SEARCH=auto:5 claude

Requires a model supporting tool_reference blocks (not Haiku). Set alwaysLoad: true on a server config to exempt its tools from deferral — blocks startup until it connects (capped at 5s).
