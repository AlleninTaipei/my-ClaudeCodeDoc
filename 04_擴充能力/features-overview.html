擴充 Claude Code

了解何時該用 CLAUDE.md, Skills, 子代理, hooks, MCP 與 plugins, 打造分層擴充架構.

總覽

Claude Code 結合了能理解程式碼的模型, 以及檔案操作, 搜尋, 執行, 網頁存取等內建工具. 內建工具涵蓋大多數程式撰寫任務. 擴充層則是你用來自訂 Claude 所知內容, 連接外部服務, 並自動化工作流程的部分.

TIP

剛接觸 Claude Code, 先從 CLAUDE.md 建立專案慣例開始, 再依實際觸發情境逐步加入其他擴充功能.

CLAUDE.md加入 Claude 每個 session 都會看到的持久性內容
Skills加入可重複使用的知識與可呼叫的工作流程
Code intelligence連接語言伺服器, 進行符號層級導覽與即時型別錯誤檢查
MCP連接 Claude 到外部服務與工具
Subagents在獨立情境中執行自己的迴圈, 只回傳摘要
Agent teams協調多個獨立 session, 共享任務清單並互相傳訊
Hooks在生命週期事件觸發, 可執行腳本, HTTP 請求, prompt 或子代理
Plugins / Marketplaces打包並散布上述功能

依目標挑選對應功能

功能範圍從每個 session 都會看到的常駐情境, 到你或 Claude 可隨需呼叫的能力, 再到針對特定事件執行的背景自動化.

CLAUDE.md
每次對話都載入的持久性情境. 適合專案慣例, "永遠做 X" 的規則.
Skill
Claude 可用的指令, 知識與工作流程. 適合可重複使用的內容與參考文件.
Subagent
獨立執行情境, 只回傳摘要結果. 適合情境隔離, 平行任務.
Agent teams
協調多個獨立 Claude Code session. 適合平行研究, 新功能開發.
Code intelligence
語言伺服器導覽與診斷. 適合型別語言, grep 效率不佳的大型程式庫.
MCP
連接外部服務. 適合需要外部資料或動作的情境.
Hook
由事件觸發的腳本, HTTP 請求, prompt 或子代理. 適合必須每次都執行的自動化.
Artifact
將 session 輸出發布為私人互動網頁. 適合想以視覺化而非終端機文字檢視的輸出.

隨時間逐步建立你的設定

不需要一開始就設定好所有東西. 每個功能都有可辨識的觸發時機, 大多數團隊依序加入:

慣例或指令連續說錯兩次加入 CLAUDE.md
重複打相同的起始 prompt存成使用者可呼叫的 skill
第三次貼上相同的多步驟流程捕捉為 skill
重複從瀏覽器分頁複製資料以 MCP server 連接該系統
Claude 讀很多檔案才找到符號定義安裝該語言的 code intelligence plugin
附帶任務灌爆對話, 之後不再參考透過 subagent 處理
希望每次都自動發生, 不必詢問撰寫 hook
第二個儲存庫需要相同設定打包為 plugin

理解功能如何分層

RULE

CLAUDE.md 檔案是疊加的: 所有層級同時貢獻內容. Skills 與 subagents 依名稱覆蓋: managed > user > project (skills); managed > CLI flag > project > user > plugin (subagents). MCP servers 依名稱覆蓋: local > project > user. Hooks 則是合併: 所有已註冊的 hook 都會針對其符合的事件觸發.

組合使用功能

Skill + MCP
MCP 提供連接, skill 教 Claude 如何善用它
Skill + Subagent
skill 觸發 subagent 進行平行工作
CLAUDE.md + Skills
CLAUDE.md 放常駐規則, skills 放依需求載入的參考資料
Hook + MCP
hook 透過 MCP 觸發外部動作

理解情境成本

你加入的每個功能都會消耗 Claude 的情境. 過多的功能可能塞滿情境視窗, 也可能加入噪音讓 Claude 表現變差.

CLAUDE.mdSession 開始時載入完整內容, 每次請求都算成本
Skills開始時載入描述, 使用時載入完整內容, 成本低
MCP servers開始時載入工具名稱, 完整 schema 依需求載入, 未使用前成本低
Code intelligence編輯後與查詢時載入, 成本低且能減少其他地方的檔案讀取
Subagents產生時載入新情境, 與主 session 隔離
Hooks觸發時執行, 若無回傳額外情境則成本為零
NOTE

Skill 描述預設在 session 開始時載入, 讓 Claude 判斷何時使用. 在 skill frontmatter 設定 disable-model-invocation: true 可讓它對 Claude 完全隱形, 直到你手動呼叫, 將情境成本降到零.

時機: Session 開始時.

載入內容: managed, user, project 三個層級所有 CLAUDE.md 檔案的完整內容.

TIP

保持 CLAUDE.md 在 200 行以內, 把參考資料移到依需求載入的 skills.

時機: 依 skill 設定而異. 預設情況下描述在 session 開始時載入, 使用時載入完整內容.

載入內容: 對可由模型呼叫的 skill, Claude 每次請求都看得到名稱與描述; 呼叫 /name 或 Claude 自動載入時, 完整內容才進入對話.

在 subagent 中: subagent 的 skills 欄位所列的 skill, 會在啟動時完整預先載入.

時機: Session 開始時.

載入內容: 已連接伺服器的工具名稱. 完整 JSON schema 延後到 Claude 需要特定工具時才載入.

成本: Tool search 預設開啟, 閒置的 MCP 工具消耗的情境很少.

時機: 檔案編輯後, 以及 Claude 導覽程式碼時依需求觸發.

載入內容: 每次編輯後的型別錯誤與警告; 查詢符號時的定義, 參照與型別資訊.

成本: 低. 符號查詢常取代大範圍檔案讀取, 淨情境用量可能反而下降.

時機: 依需求, 由你或 Claude 產生任務時觸發.

載入內容: 全新且隔離的情境, 包含代理自己的系統 prompt, 其 skills: 欄位所列 skill 的完整內容, CLAUDE.md 與 git 狀態 (內建的 Explore 與 Plan 代理兩者都略過), 以及主代理傳入 prompt 中的任何情境.

時機: 觸發時. Hooks 在特定生命週期事件觸發, 如工具執行, session 邊界, prompt 送出, 權限請求與壓縮.

載入內容: 預設不載入任何內容. Hooks 在主要對話之外執行.

成本: 零, 除非 hook 回傳的輸出被加為對話中的訊息.
